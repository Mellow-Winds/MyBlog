再见，我的高考之年。

𝐅𝐚𝐫𝐞𝐰𝐞𝐥𝐥 𝟐𝟎𝟐𝟓 , 𝐖𝐞𝐥𝐜𝐨𝐦𝐞 𝟐𝟎𝟐𝟔!

# 一月·𝐉𝐚𝐧𝐮𝐚𝐫𝐲

元旦的第一缕阳光，迎来属于25届的高考年。一切都是新的，一切又似乎没有改变。仍记得九江一模作文的标答是『梦虽遥，追则能达。愿虽艰，持则可圆』，我却反其道而行之，意外收获不错的分数。考后无聊的三天里，体验了出试卷的爽感，以及在老师眼皮底下创造小说的快乐。

高三的寒假，被『高考』的正当理由封闭在家中复习，少了很多乐趣，但也获得了向下沉淀的力量。寒假的语文试卷里，竟意外地出现了和高考语文一样的原题，让我又惊又喜，也庆幸自己的付出。似乎正是那时起，心中才有了较为清晰的目标。这个春节对我来说注定不会太热闹。但好像，也没那么糟糕。



# 二月·𝐅𝐞𝐛𝐫𝐮𝐚𝐫𝐲

迎来了立春的气息，也同一天迎来了下学期的开学。寒冷的冬天无处不藏着夏天的盛大。无数个日夜里，悄然积累着进步，也酝酿着担心和焦虑。小小的脑袋里，装不下的可不只是知识。

接踵而至的是南昌一模，英语A篇全错历历在目。那个晚上，乐观主义者的我罕见地难过了。不过，深夜的赶路人，看到的绝非漆黑一片。总有漫天星光和皎洁的月色伴随着每一个夜晚。『在隆冬，我终于知道，我身上有一个不可战胜的夏天』

百日誓师那天，没有想象中的那么热血沸腾，但在心里默默立下承诺。那像传销组织一样的口号『考场就是我的家，我想回家就回家』似乎已经深深刻在DNA里面了。



# 三月和四月·𝐌𝐚𝐫𝐜𝐡 & 𝐀𝐩𝐫𝐢𝐥

日子像平静的河流一样流淌，可任谁都知道，这平静下面，是波涛汹涌的较量。很开心的是，在紧张的环境下，可爱的17班表现出来的是很轻松愉悦的环境以及共同进步的氛围。在此后的交谈中了解别的高中，别的班之后，才后知后觉明白，这很好，真的很好。

放学走过的路上，漂浮着闲聊亦或是争论题目的话语，如今应该早就随风而去了吧。最后几次课间的跑操，想逃，没逃掉，于是晚晚地去，慢慢地走。如果知道那是最后几次跑操，我想我会走的还要慢一点。

忙里偷闲的时光也有，偷偷看电影，抑或是写点什么，去留住时间。

三月二十一日，于桌上无意间收获纸笺一条，写着『好好学习』。此后的一段时间里，纸笺总是保持着每日一更。这一天又一天的鼓励和坚持，曾是我面对疲倦时所望向的缱绻。三月底，晚自习，闲来无事，送出几张明信片。『风花雪月之间，你是第五种不舍』作为玩笑送给了橙汁。说是玩笑，倒也确实不舍。

四月，去看了我的世界大电影，圆了童年的梦，就像又回到小时候一样。

倒计时越来越近，但是好像一切都似乎没有发生任何改变。九九八十一，八八六十四，七七四十九。广播里的歌，从《在故事的最终》到《小美满》再到《起风了》。感谢学校，至少课前，有那么五六分钟是属于我们少有的休憩。时间从指缝中溜去，只留下每天下午悠扬的课前歌曲旋律和课桌附近飘来的隐约的芬芳。窗外缓缓绽放夏天的气息，慢慢浸透了笔记的每一页，翻阅的每一次都带着独特的味道。

阳光越来越暖和，温度越来越高。无数次望着，盼着，少年的心跳越来越快，扑通，扑通，就像倒计时的滴答声。



# 五月·𝐌𝐚𝐲

备考的氛围竟意外地轻松起来。起晚了，那就悠闲的先吃早餐，再去转一转，慢慢走进教室；不想去了，那就请个假吧；不会的题目，那就算了吧；上课不想听，那就出去玩玩吧。至于作业不想写？其实早就不写了。

唯一不能偷懒的好像就只剩下语文了，不过这个时候，语文倒成了最诡异的学科，玄学的说法流传开来，认真与否貌似已难辨结果，时至今日再也无法看到如果认真学语文会是怎样了，但无论如何，落子无悔。

二楼的备课教室里面的一体机，不知承载多少上课期间偷偷溜出去爽的快乐。晚自习上学的路上，为霞尚满天，红里透白的云静静地飘着。红绿灯旁，三两行人纷纷驻足，掏出手机定格着。天气里是蝉鸣的燥热，索性在天桥处，买一两杯冰奶茶，再慢慢走到教室，努力静下心来开始一次又一次反复的刷题。

环湖走，美其名曰走，其实更像是一场盛大的逃亡。刚出校门便迫不及打车待去电影院了。高考前最后一次看电影，又在看完后匆匆去补课，那种惊险刺激的感觉，总是伴随着独一无二的，青春的气息。

月底迎来最后一次模拟考，和高一最开始的那一场联考一样是上进联考。它接住了我的整个青春。最后一次模拟考结果并不理想，但结果，也似乎没那么重要了。

少年多么希望时间慢一点，因为有好多好多题目还没完全掌握，有好多好多人和事还没好好珍惜。



# 六月·𝐉𝐮𝐧𝐞

陆陆续续要到了老师们的祈愿，那一天终究是越来越近了。最后一次晚自习，偷偷带了手机，拍下了弥足珍贵的照片；最后一节课仍然记忆犹新：语文，而且还在讲试卷，而且还有传纸条被批评的，而且还有像我这样看到有人被批评还敢偷偷传纸条而且没被发现的；最后一次布置考场……

然后，高考。三天，好像和平时差不多，又好像很不一样。

第一天上午语文差点紧张到笔都握不住，下午下了大雨，大到衣服裤子全部湿了。晚上还是忍不住偷偷看了数学的答案，遗憾怎么错了那么简单的一个填空，不过都过去了。第二天的物理焦头烂额，不断安慰自己没关系没关系，下午的英语考完又很有底气。第三天的化学很难，不断安慰自己赋分别怕，生物早早写完，最后十分钟留给了发呆，不敢相信高考已经结束。铃响，交卷；三年，圆满。考场外，被可爱的小表弟送了一束花，后来没舍得扔，但也不知最后它去哪了。

晚上第一次那么毫无顾虑地玩个畅快，好久没有过。上一次得追溯到中考结束，或者是更久远的小学毕业。

毕业典礼，回班，以及老万的比心。有的人，应该是见最后一面了。

六月的盛夏，剩下一群人的疯跑和疯玩，穿梭在九江这座小城里。天气热热的。

出分前一天晚上，朋友圈和QQ空间充斥着各种各样的祝福和祈愿，已经被刷屏。当天自然没睡好，心中是忐忑和不安，作为登分的一员往学校赶。原定于九点出的成绩，八点五十就可以查到了。紧张颤抖，在看到成绩的瞬间变成了激动。虽说不是高中三年最好的一次，但是有得有失，有遗憾错误的，也有侥幸猜对的，有这样的结果已经很满意了。语文终究是没有让老万失望，高中三年没怎么考过比115高的分数；英语也对得起自己几乎三年的辛苦付出；数理化生没有太大的感慨，失之东隅，收之桑榆。这就很好。好朋友们也大部分考的不错，不管怎样，也算是结束了。落子无悔。山高路远，江湖再见。

填报志愿，让人生第一次有了选择的重量。对于未来有些迷茫，也不知道会走向何方。在犹豫中选择了心中的清单。



# 七月·𝐉𝐮𝐥𝐲

找了点事干，也收获了属于自己的第一批弟子。当老师挺难的。不过辛苦一天，在下班后往小坝一走，所有的烦恼就烟消云散了。生活平静安宁，但是又似乎格外单调。

月底，录取通知书发放。阴阳差错之下，被录取到了南京大学。曾和橙汁说如果我去了上海，我们就继续一起玩，恐怕是去不成了。其实就差那一个数学填空题，这就是5分的距离。但是哪有那么多如果呢。生命是一场不回头的旅途，大胆向前走就好。

陆陆续续得知了不同好友的去向。北及哈尔滨，南至海南岛；东达长江口，西往长安城。这时才明白五湖四海的意义和距离。世界太大了，见一面需要跋山涉水的勇气；世界又好像很小，说去见你的话，可以马上出发。



# 八月·𝐀𝐮𝐠𝐮𝐬𝐭

终于结束课程，轰轰烈烈地玩了一趟。无数的快乐和举杯里藏着这个暑假独特的意义。升学宴一场接一场，一次次赴宴把我拉向这个意义非凡的夏天的尾声。一次次见面，一次次告别。日子就这样和人一样流走，用力抓也抓不住。

临行前夜，再次独自环湖走。像五月的那次一样，像2024年的最后一天那样。只是这次，脚步更慢，身边也再无他人。路灯把影子拉长又缩短，熟悉的景物在夜色中显得无比亲切。我知道，下次再见，至少是一个月后。我也知道，从此以后，九江对我来说不再是整个世界，而是更广阔的世界的起点。心情有些复杂，对自己立下默默的祝福。

收拾东西，准备出发。前方是陌生的南京和全新的故事，而身后，是这个漫长明亮，永远定格在回忆里的，最后的九江的夏。



# 九月·𝐒𝐞𝐩𝐭𝐞𝐦𝐛𝐞𝐫

分别总是在九月。

告别故乡，不由想起那句『孩儿立志出乡关，学不成名誓不还』来。

大学，军训，课程。遇到了很好的教官，说是军训，其实挺轻松。每天还没站累就听得见响亮的一句『坐！』，还有可口的酸梅汤。这个过程中认识了一些很好的朋友，也知道了很多异乡的故事。九月是新鲜的，一切都在等待着我的探索和发现。

选课，让自己做出的抉择又一次有了意义和重量。抽签就像把自己的决定交给了命运。这种神奇的经历，给了我面对不确定性的心理准备。

第一次坐在大学的教室里，感觉有些奇异。没有固定的同桌，没有堆积如山的试卷。还是会喜欢坐在第一排，总觉得有一种神圣的仪式感。也学会了翘课，时间终归是自己的，做自己认为正确的事情吧，为自己的所作所为承担责任就好。

夜晚的探索成了我最喜欢做的事情。和几个刚认识的好朋友，骑着共享单车，漫无目的地钻进南京的街巷。从颐和路的民国建筑群，到秦淮河畔的灯火；从先锋书店里安静阅读的人群，到新街口喧嚣的嘈杂。我们谈论着各自的高中，遥远的家乡，也在这种漫游中，一点点完善这座六朝古都模糊而迷人的地图。南京不再是一个地名，它开始有了具体的温度和意义。



# 十月·𝐎𝐜𝐭𝐨𝐛𝐞𝐫

国庆回去，久违的熟悉感扑面而来，看待九江的视角也发生了变化。曾经沧海难为水，除却巫山不是云。看过了更高的风景，才有了不一样的见解。我对这座小城的感觉，从此多了『乡愁』。

和高中同学们相聚又匆匆离开，以为过了很久实际上却是分开几个月。回到母校，那里沧海桑田，一切都有新的变化。学长对于母校，和学生对于学校，感情上终究是不同的。七天时间说来也短，倒像是夏天的尾声。好像自此以后，有关高考的一切戒断反应，才慢慢地也淡了下去。

十月依旧是适应期，很多的事情还是第一次，但是我也没有那么担心了。慢慢地，日子回归了平静，但是每一天都是不平凡的。几次辩论，几场团建，匀称地洒落在每一天。忙吗？没错，而且总是被小事情打发时间。有规律的计划总是赶不上变化，被无数个变量冲破得支离破碎。此时的我，确实挺乱的。于是心里萌生一些想法，觉得累了，就让自己休息一下吧。不去做精密的齿轮，而去做自由的风筝。



# 十一月·𝐍𝐨𝐯𝐞𝐦𝐛𝐞𝐫

秋天的氛围渐渐浓了起来。在秋高气爽中，期中考试如期而至，也带来了大学里的第一次真切的打击。看着并不理想的成绩， 先前那种『还不错』的自我感觉瞬间冰消瓦解。焦虑和自我怀疑一度袭来，深夜对着看不懂的习题，感到深深的无力。但这一次，我必须自己寻找原因。这个过程有些痛苦，却也让我清醒。最后想想还是别苛责自己了，自己平时也挺辛苦的（虽然玩的也不少）。

课程逐渐变得难了，总是有不懂的地方成为拦路虎。投入在学习上的时间也变多了。生活逐渐稳定下来。课翘的越来越多，感觉很多时候自己只是纯粹坐在教室发呆，那不如整理一下思绪，再重新出发。

南京的秋天很好看，一切的一切都那么宁静和美好，像九江一样。银杏叶铺满道路，踩下去，像踩在棉被上一样。

期中考试考完了犒劳一下自己，于是兑现了曾经暑假立下的诺言，前去上海见了橙汁一面。上海和南京是不同的，节奏快，时间紧，是另一种风格。再次见面，像才分开一天，又像阔别了几年。这次也联系到了了上交的学长，参观交大后又一次感慨鼓楼校区还是太小。不管怎么说，那个有外滩的世界，从此有了我的足迹。

冬月的凛冽里总是藏着温情，不时收到来自哈尔滨的问候。杨洋羊总是偷偷送出一杯杯温暖甘甜的奶茶，喝着喝着，渐渐暖和起来。此刻的他，会在干什么呢？一切都是那么可望而不可及。一切都像是被蒸汽模糊了，只剩下心中的暖意无比清晰。

可怜的生活，被学习压缩了，于是只能在缝隙中窥探着生命的美好。落叶，阳光。来自远方的雪，身处近处的秋。这是南京的深秋。



# 十二月·𝐃𝐞𝐜𝐞𝐦𝐛𝐞𝐫

学习上的事情逐渐复杂起来。学不会的指针现在终于是懂了一点点，接踵而至的链表又开始上强度；不定积分和定积分一出现有时候确实挺可怕也挺巧妙；微观经济学又多了一堆奇奇怪怪的英文字母……

五号迎来了19岁，也是第一个在外地过的生日。不在九江的生日，更有成长的感觉，在远离庇护的地方，学会为自己点燃庆祝的烛火。木叶和闻晚没有线下缺席，在这个特殊的时刻里默默祝福着；老朋友们从远方寄来各种各样的礼物，诉说着过往和如今。这个生日之后，心态似乎悄然转变，明白自己应该更像个『大人』，但对于如何成为『大人』，依旧模糊。

六号和闻晚前往栖霞山，又在回归途中被姑姑盛情接待。同学情，家人情，巧妙地融合在这一天。总是有这样的事，让我热泪盈眶。原来，南京从来不是异域，而是我未曾来过的故乡。他们的温暖，是这个冬天最明媚的光亮。

出去的时间少了，分配给学习的时间多了起来。开始沉浸于Skyblock，又一次感慨MC不愧是很适合被发掘的，很多时候对于存档的debug充满了惊喜和快乐。

十二月更像是一次与内心深处的自己交流的经历。想要什么，不想要什么，希望什么，喜欢什么……慢慢找，好像也找到了一点。

都说大学是自由的，但同样，自由就意味着抉择也是自由的，也就需要为此承担责任。从九月开始到此刻，反复咀嚼自由的滋味，倒也不失为一种独特的感觉。

月底收到了一份惊喜，正上着实验课，突然收到了来自法兰西的图片和来自武汉的问候。他们就这么来南京了。2025年的最后一个周末，不再有疯狂的复习和赶不完的DDL，而是数不尽的快乐。每一个在酒店的晚上里，都有我们交谈的余音。针砭时弊也好，吃瓜也罢，无数个闲言碎语又一次完善了高中的拼图和未来的方向。记得周六晚，我们一度聊到了凌晨四点半，而后我竟迷迷糊糊的睡着了，他俩后来则一直聊到了五点半。总有许多话说也说不完，想和你们细细道来。在南京的冬天里，与他们挥别，也与属于自己的2025年挥别。



# 写在最后

2025，被高考拆成了两半。

前半，是一群少年并肩跋涉，向外冲锋的轰轰烈烈。我们活在统一的规范里，有着相同的课表，相同的倒计时，相同的终点线。焦虑与希望都是集体的。那是一段有着标准答案的时光，目标高悬在天，他们结伴走完了最后一段无须独自寻路的岁月。

后半，是三两知己旷野奔行，向内探索的安安静静。世界忽然松开束缚的手，我们散作满天星斗，各自前去照亮陌生的夜。选择大学，选择城市，选择以后的人生方向，选择早八要不要去。自由第一次变得如此具体却沉重。它是选课系统里的眼花缭乱；是无人催促的自我安排；是面对一次次决策时知道再也没有借口的独立；是被赋予的无限可能，也是为每一种可能背负的全部责任。我也在丰富的大千世界里慢慢明白自己的喜好，在突如其来的孤独中了解自己以前不知道的一面。

我用一半的时间，与大家共跨一座桥；用另一半的时间，与自己渡过一片海。

前一半的我被赋予使命，后一半的我在寻找使命。又或者，不一定要有什么使命，选择是自己的，怎么走下去是自己决定的。至于要怎么往下走，就让时间和那个未被我看见的，时光深处的自己，给出答案吧。明年的自己，记得再安然一点。慷慨，大方，自由，浪漫。恰同学少年，风华正茂。书生意气，挥斥方遒。

老朋友们散落在不同的城市，他们从远方传来消息，那些消息夹杂在朋友圈里，酸甜苦辣，尽是生活。如果以后的日子里见不到我，就记好那些有趣的事，见面时记得互相倾诉，互相温暖。但愿我们各自忙碌的时候，都能照顾好自己，快乐充实地生活。新的一年，可以不见，但一定要更好。
