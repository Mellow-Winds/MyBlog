慢慢发现，思考也是一件有趣的事情。能够在大学阶段，捡回一些对于这个世界本身的好奇，挺难得的，也让我很珍惜。

先说对于这个世界本身的好奇。不知什么时候起，我开始总是突然想到一些神奇的问题。譬如『天文学，主要研究的是天体，为什么独独被赋予“文”的色彩？』『线性代数之名，什么是线性？为什么独独被赋予线性的含义』『车窗都是自上而下的。为什么不能从左到右』之类的问题。在之前，我似乎总是把他们当做理所当然，可是，一次次的追问，却收获了不少新的理解，勘正了原先很多错误的认知。随着反复和AI交流或是自己求索，这些问题都会得到一个较为满意的答案。而在此过程中，也体会到了一种可以被称为『知其所以然』的快乐。

此外呢，自然也有一些其他的思考。想到记录下来是因为昨天（2026年3月12日）中午和一位朋友的聊天。总结下来无非就是：『在大学阶段，谈恋爱是不是需要考虑未来呢？』以及由此衍生出来，一个程序员ta可能的未来，对于目前主流社会上爱情观自己的认知。

# 第一个问题：应当把谈恋爱作为积攒经验的手段吗？

如果把恋爱纯粹当作积攒经验的工具，会出现伦理和心理上的问题。感情毕竟不是打游戏。对方是一个真实的人。如果一开始的心态是积累经验，关系容易变成功利化，长期来看也很难建立真正的亲密感。但另一面，人几乎不可能在没有任何关系经验的情况下突然拥有成熟的亲密能力。

在我看来，对于一段感情，应当秉持着虔诚认真的态度；对于任何一种深度的关系，都需要承担这种深度带来的责任。若是用一个不恰当的比喻，那就是像在温暖的阳光与和煦的春风里穿上刚洗过的白衬衫一样的纯净。彼此之间不会利用对方，而是真正地去为了一段关系付出什么；不会相互猜忌，而是坦诚布公又允许隐私的存在。一段感情，或者是一段恋爱的经历，不应以『积累经验』为目的，而是应当真正获得去爱人的能力。这里的人，自然包括了恋人，但也必须包括了朋友，包括了家人，包括了陌生人等。

我并不认同那种快速确立恋爱关系的模式。因为在我看来，如果在缺乏了解的情况下就进入关系，可能因为三观不合无法坚持而导致分手，也可能因此对双方造成情感上的伤害，因此这是一种不负责任的行为。相比之下，我更倾向于一种自然形成的关系：先在接触中慢慢成为朋友，在长期互动中观察彼此的性格、价值观和相处方式，如果发现彼此志同道合、相处舒服，再逐渐加深关系，让关系在默契和好感中自然发展，可能进入一种暧昧或更亲密的状态。如果在这个过程中发现并不合适，关系也可以自然退回，重新成为朋友或者逐渐变淡，而不是经历激烈的情感破裂。这种方式既能减少不必要的伤害，也更符合我对“认真对待关系”的价值观。所以：恋爱不应该以『积攒经验』为目的，但经验一定会在恋爱中自然产生。

# 第二个问题：需要考虑未来吗？

享受当下固然是好的。考虑未来太多，无形之中给了自己压力。但是，一段亲密的关系，如果完全不考虑未来，关系很容易变成短期情绪消费。所以从理性角度，是必须考虑未来的。那么为了不让自己处于压力之中，考虑的时间点很重要。这就又回到了我之前思考的：每一个关系的深度都应该有它对应的责任。对于我自己的要求就是，做好自己应该做的。

# 第三个问题：为什么大家都不愿意等了？

当然我也意识到自己可能带有一点理想主义。在寻找友谊，抑或是进入恋爱之前确认彼此真正契合，而不是被快节奏的社会逻辑推动——这，在如今是一种何其艰苦的抉择。就像我的那位交流的朋友说的：现在大家都很累，没有人愿意为你而等待。现在不找，以后真的能找到吗？

自然，他的话是有道理的：愿意等的人，本身很少。在此之上契合的，又还剩下几多呢？但是，我倾向于认为，越是节奏快速的时代，一段愿意慢慢发展的关系，越需要双方更高的共识与耐心。我们需要主动，但也不能盲目。

# 札记

在如今这样一个快节奏的社会，我们似乎都被一种无形的压力压迫，往前走。套用三体的话，那黑暗森林就是『内卷森林』吧。GPA越卷越高，各种经历越卷越多等等。大学的学习，似乎再一次，变成了一种对于分数的追求。大学中对于新关系的寻求，似乎变成了一种不得不完成的任务。由此而来的，便是压力和无形之中的压抑。我们正在逐渐失去对于某个东西本身的好奇，或许可以概括为『童心』或者是『少年意气』的一种。

自然，我是不太愿意看到这样的。学习除了对于分数的追求，也应当含有对于知识本身的喜好。做出一道巧妙的证明，会慨叹一番逻辑的精巧；看到一个概念如何被定义，会尝试理解为什么我们如此定义了它。关系也一样，不在于为了获得什么而去寻找，而在于出发寻找之后，自然而然的收获什么。

是的。探索这件事情本身是充满意义的。可是为了去探索而探索，为了别的目的而出发，也许也就慢慢丧失了旅行的意义。
