
# 分配数组的规则
在main函数外分配数组，可以申请更大的内存，并且所有元素直接初始化为0，无需二重循环，更方便
# 在任意位置（如不在 `main` 函数中）直接退出程序：

```C
exit(EXIT_SUCCESS); // EXIT_SUCCESS equal to 0
```
不同于 `return`，它直接将整个程序正常结束。

# 如何查看指针对应的数组？
`(int(*)[100])a1`可以把`a1`当成长度为`100`的数组来显示
# 全局定义的数组如何在调试的时候看到？
选到那一行，右键添加到内联监视即可

# 如何输出固定对齐的字符数？
例如：
```c
Input
4

Output
    1    2    3    4
   12   13   14    5
   11   16   15    6
   10    9    8    7
```

考虑使用`printf("%5d")`以规范化输出。
