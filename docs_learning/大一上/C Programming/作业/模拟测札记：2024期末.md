# 第二题：选课
## 题目描述：子集最大覆盖问题
### 1. 问题背景
给定一个包含 $n$ 个元素的集合 $U = \{1, 2, \dots, n\}$，以及 $m$ 个给定的子集 $S_1, S_2, \dots, S_m$。你的任务是从这 $m$ 个子集中挑选出 **正好 $k$ 个** 子集，目标是使这 $k$ 个子集的**并集**所包含的元素个数尽可能多。
### 2. 算法流程
请按顺序执行以下逻辑，不得自行优化：
1. **初始化**：
    - 设集合 $C$ 为“已选子集的编号集合”，初始为空：$C = \emptyset$。
    - 设集合 $R$ 为“当前尚未被覆盖的元素集合”，初始为全集：$R = \{1, 2, \dots, n\}$。
2. **贪心迭代**（重复执行 $k$ 次）：
    - 在所有**尚未被选择**的子集中，寻找一个子集 $S_i$，使得它与当前未覆盖集合的交集大小最大，即：$\max |S_i \cap R|$。
    - **注意**：若存在多个子集满足交集大小相同且均为最大，你可以从中**任选其一**（本题支持多种正确输出）。
    - 将选中的子集编号 $i$ 加入 $C$。
    - 从 $R$ 中移除该子集包含的所有元素，即更新：$R = R \setminus S_i$。
3. **结果输出**：
    - 输出集合 $C$ 中的 $k$ 个子集编号。
### 3. 输入格式
- **第 1 行**：三个整数 $n, m, k$，分别表示全集元素个数、候选子集个数、需要选择的子集个数。
- **接下来的 $m$ 行**：每行代表一个子集 $S_i$（编号从 $1$ 到 $m$）。
    - 每行第一个整数 $c_i$ 表示该子集的大小。
    - 后面跟着 $c_i$ 个整数，表示子集中的具体元素。
### 4. 输出格式
- 输出一行，包含 $k$ 个整数，表示你选择的子集编号。编号之间以空格隔开，顺序不限。

```c
#include <stdio.h>  
#include <stdlib.h>  
#define N 100000  
int num[15][N];  
  
int cmp(int num[], int all[], int n, int len);  
  
int main() {  
    int n, m, k;  
    scanf("%d %d %d", &n, &m, &k);  
    int compare[15] = {0}; //比较数组  
    int ans[15] = {0};  
    int all[N] = {0};  
    //初始化最初的大数组  
    for (int i = 1; i <= n; i++) {  
        all[i] = i;  
    }  
    //读入其他的数字  
    for (int i = 0; i < m; i++) {  
        int len = 0;  
        scanf("%d", &len);  
        num[i][0] = len;  
        for (int j = 1; j <= len; j++) {  
            scanf("%d", &num[i][j]);  
        }  
    }  
    //比较  
    for (int i = 0; i < k; i++) {  
        int max = -1; //最多覆盖的数组  
        int maximum = -1;//最多重合的数字  
        for (int j = 0; j < m; j++) {  
            compare[j] = cmp(num[j], all, n, num[j][0]);  
            if (compare[j] >= maximum) {  
                max = j;  
                maximum = compare[j];  
            }  
        }  
        //得到最大的后，删除其他的  
        for (int q = num[max][0]; q >= 1; q--) {  
            for (int b = n; b >= 1; b--) {  
                if (num[max][q] == all[b] && all[b] != -1) {  
                    all[b] = -1;  
                    break;  
                }  
            }  
        }  
        //存入ans数组  
        ans[i] = max + 1;  
    }  
    for (int i = 0; i < k; i++) {  
        printf("%d ", ans[i]);  
    }  
    return 0;  
}  
  
int cmp(int num[], int all[], int n, int len) {  
    int sum = 0;  
    for (int i = len; i >= 1; i--) {  
        for (int j = n; j >= 1; j--) {  
            if (num[i] == all[j]) {  
                sum++;  
                break;  
            }  
        }  
    }  
    return sum;  
}
```
