# Floyd 判圈算法

## 1. 核心概念
- **比喻：** **龟兔赛跑**。
- **场景：** 在一个有很多关卡（节点）的迷宫里。
- **规则：** 兔子（快指针）一次跑 2 步，乌龟（慢指针）一次跑 1 步。
- **原理：**
    - 如果是**直路**：兔子直接跑掉（遇到 `NULL`）。
    - 如果是**圆环**：兔子一定会在圈里**套圈追上乌龟**。
## 2. 算法
- **阶段一（判圈）：**
    - 龟走1，兔走2。
    - **关键点：** 如果 `hare == tortoise`，说明有环。
- **阶段二（找入口）：**
    - **操作：** 兔子退回起点（Head），乌龟留在原地。
    - **变化：** 这一次，兔子**降速**，和乌龟一样**一次走1步**。
    - **结果：** 它们再次相遇的地方，就是**环的入口（Entry Point）**。
## 附：代数推理证明找入口的合理性

**为什么从“起点”出发的乌龟，和从“相遇点”出发的兔子（这次速度一样），一定会在“环的入口”相遇？**
我们可以把这个证明过程像解一道**应用题**一样列出来。
### 第一步：给地图上的路段起名字（定义变量）
拿出一张纸，画好图，我们用字母来代表距离：
1. **$L$ (Linear)**：从**起点**到**环入口**的直线距离。
2. **$X$ (X-factor)**：从**环入口**跑到了**相遇点**的距离。
3. **$C$ (Cycle)**：圆环的总周长。
### 第二步：列出“行程方程”
这里有两个核心事实，我们要把它们写成数学等式：
事实 1：乌龟跑了多少路？
乌龟比较慢，它进圈没多久就被抓住了。所以乌龟走的距离是直线加上在圈里走的一小段：

$$D_{\text{乌龟}} = L + X$$

事实 2：兔子跑了多少路？
兔子跑得快，它可能在圈里转了好几圈（假设转了 $n$ 圈）才追上乌龟。所以兔子走的距离是直线，加上那一小段，再加上它多跑的圈数：
$$D_{\text{兔子}} = L + X + n \cdot C$$

事实 3：速度的关系
这是最关键的！因为兔子速度是乌龟的 2 倍，所以兔子跑的总距离一定是乌龟的 2 倍：
$$D_{\text{兔子}} = 2 \cdot D_{\text{乌龟}}$$
### 第三步：解方程（见证奇迹的时刻）
现在的任务就是要把这两个式子结合起来。你可以让小朋友自己动手化简：
1. 代入公式：$$L + X + n \cdot C = 2(L + X)$$解得
$$L = n \cdot C - X$$
- **等式左边 ($L$)**：这是从**起点**走到**环入口**的距离。
- **等式右边 ($C - X$)**：
    - $C$ 是整圈，$X$ 是已经走过的部分。
    - 所以 $C - X$ 刚好就是“从相遇点继续往前走，走到环入口”剩下的距离！
    - 那个 $(n-1) \cdot C$ 只是代表多转几圈，最终位置不变。
