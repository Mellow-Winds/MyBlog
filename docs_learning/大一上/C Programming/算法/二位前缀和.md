在 C 语言中，**二维前缀和（2D Prefix Sum）** 是一种极其高效的算法技巧，主要用于在 $O(1)$ 的时间内查询一个矩阵中任意子矩形的数值总和。

如果没有前缀和，每次查询子矩阵都需要遍历，复杂度为 $O(N \times M)$；而预处理出前缀和数组后，查询效率会大幅提升。

---

### 1. 核心原理

假设我们有一个原始矩阵 `a[i][j]`，我们定义前缀和数组 `s[i][j]` 表示从左上角 `(1, 1)` 到右下角 `(i, j)` 围成的矩形区域内所有元素的和。

#### 计算前缀和数组（递推公式）

为了计算 `s[i][j]`，我们可以利用已经计算出的相邻状态，并减去重复计算的部分：

$$s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + a[i][j]$$

#### 查询子矩阵和

如果你想求左上角 $(x_1, y_1)$ 到右下角 $(x_2, y_2)$ 的子矩形和，公式如下：

$$\text{Sum} = s[x_2][y_2] - s[x_1-1][y_2] - s[x_2][y_1-1] + s[x_1-1][y_1-1]$$

---

### 2. 代码实现 (C 语言)

在实现时，为了防止索引越界（处理 `i-1` 的情况），通常建议数组下标**从 1 开始**。
```c
#include <stdio.h>
#define MAX 1010
int a[MAX][MAX]; // 原始数组
int s[MAX][MAX]; // 前缀和数组

int main() {
    int n, m, q; // n行, m列, q次询问
    scanf("%d %d %d", &n, &m, &q);

    // 1. 读取数据并预处理前缀和
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            scanf("%d", &a[i][j]);
            // 核心公式
            s[i][j] = s[i - 1][j] + s[i][j - 1] - s[i - 1][j - 1] + a[i][j];
        }
    }

    // 2. 处理查询
    while (q--) {
        int x1, y1, x2, y2;
        scanf("%d %d %d %d", &x1, &y1, &x2, &y2);
        
        // O(1) 得到子矩阵和
        int result = s[x2][y2] - s[x1 - 1][y2] - s[x2][y1 - 1] + s[x1 - 1][y1 - 1];
        printf("%d\n", result);
    }

    return 0;
}
```

---
### 3. 注意事项

- **下标从 1 开始**：这能有效避免处理 `i=0` 或 `j=0` 时下标变为 `-1` 的麻烦，使代码更简洁。
- **内存大小**：对于大型矩阵，要注意 `int` 是否会溢出（可能需要用 `long long`）。
- **应用场景**：
    - 快速求静态矩阵的区域和。
    - 辅助处理二维差分问题（用于区域修改）。
