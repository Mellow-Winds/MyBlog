# 1.结构体是什么
结构体是把多个不同变量打包成一个整体，从而可以操作它

```c
struct xxx{
int a;
char b;
}

struct xxx r ={1,'A'};//此处顺序有要求
也可以：struct xxx r ={.a=1,.b='A'};//此处顺序不做要求

printf("%d %c",xxx.a,xxx.b)
```
tips:
1.这里的`.`是一个运算符，是一种运算
2.结构体中一般不适用取地址，易造成混乱
3.无法通过`==`来判断两个结构体变量是否相同
4.函数中传入的`xxx`不会改变`main`函数中的数值，若改变需传入指针
```c
void function(record *p){
此时两种方式可以访问xxx.a：
(*P).a
p->a
}
```
# 2.结构体操作
- 结构体变量可以作为返回值，但是不建议这么写
- 同类型的结构体可以赋值
# 3.联合
结构变量`s`和联合变量`u`只有一处不同：`s`的成员存储在**不同**的内存地址中，而`u`的成员存储在**同一**内存地址中。
改变一个成员就会使之前存储在任何其他成员中的值发生改变。因此，如果把一个值存储到`u.d`中，那么先前存储在`u.i`中的值会丢失。
