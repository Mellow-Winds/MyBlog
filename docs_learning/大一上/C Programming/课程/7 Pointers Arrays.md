# 1.指针
## 1.1 什么是指针？指针的声明和定义
指针是一个存储内存地址的变量，代表指向某个具体内存的地址
```c
int i = 5;  
int *p;                //指向int变量，所以指针也定义为int  
p = &i;  
printf("%d\n", i);  
*p++;                  //对指针的操作和对i的操作一样  
printf("%d\n", *p);

Output:
5
6
```
`*p`存储了`i`的**内存地址**，所以`*p`就是一个指针
## 1.2 指针的赋值
在上方的代码块中，我们赋值的指针是`int`型（指针的类型），所以它指向的是一个`int`，和`int`一样去解读（4字节）

注意：对指针的赋值，实际上是赋给了指针一个变量的地址，而这个地址不是我们可以控制的，我们不能直接对指针赋值如`int *p =0`

创建指针后应当立刻赋值，否则将会得到一个垃圾值

指针变量的值是具有实际值的变量地址，而普通变量的值就是实际的值

`*p`可以看作是`i`的别名，任何对`*p`的操作和对`i`的操作是类似的（如上方代码块中的`*p ++`其实就是`i++`）

可以多个指针指向同一个变量，但是请注意：同时声明多个指针变量需要每个指针名字都加`*`
```
int *q ,*qq;    (Yes)
int *q ,qq;     (No)
```
指针赋值中的一个辨析：
```
int *p=&i;
int *q=&j;
第一种：
p=q;           //改正的是指针本身，可以让p和q都变成指向j的指针
第二种：
*p=*q;         //改变的是指针指向的东西，其实就是i=j,把j的值赋给了i
```

## 1.3指针是一个单目运算符
指针可以做左值也可以做右值，可以访问指针表达的内存地址的变量
```
int a = 1;  
int *p = &a;  
int k = *p;   //这一步实际上是把a的值赋给了k
```

## 1.4指针运算符杂谈：`&`和`*`
`&`（取地址符号）可以类比为指针`*`的逆运算——取地址实际上是读取了一个“指针”
我们用一个例子来辨析
```
定义一个指向y的指针yptr
*yptr == y
*&yptr   --->   *(yptr的地址)   --->   yptr    (可以看作：*&x == x)
&*yptr   --->   取(*yptr)的地址 --->   取(y)的地址   ---> yptr
```
也即：
在`*p`中，`p`是单独的一个地址，而`*p`和`a`则是可以看作同样一个变量
# 2.指针作为函数参数
## 2.1 从传入数组说开去
在之前我们学习函数时，传入了数组`int a[]`，这其实是传入了一个指向数组的首地址的指针，而不是传入数组本身，函数对于数组的操作，将会直接影响数组
注意区分：而其他的，比如传入整数`int a`，实际上传入了一个等于`a`数，而没有改变`main`函数中a的数值。
那么如何实现在函数中直接对`a`修改呢？答：传入指针即可直接修改`a`

现在我们以swap函数为例，演示一下直接传入`a`和传入`a`的指针有什么区别：
```c
#include <stdio.h>  
  
void swap1(int a, int b) {  
    int t = a;  
    a = b;  
    b = t;  
}  
  
void swap2(int *pa, int *pb) {  
    int t = *pa;  
    *pa = *pb;  
    *pb = t;  
}  
  
int main(void) {  
    int a = 5, b = 10;  
    swap1(a, b);  
    printf("a=%d b=%d\n", a, b);  
    swap2(&a, &b);  
    printf("a=%d b=%d\n", a, b);  
    return 0;  
}

Output:
a=5 b=10
a=10 b=5
```
可见，`swap1`并未真正交换`a`和`b`，而`swap2`则可以，因为它直接修改了`main`函数中的`a`和`b`本身。很多时候用指针作为函数参数，其实就是为了操作原来的对象。

## 2.2 指针的移动
以打印数组的函数为例。
在函数中，我们传入了一个数组，按照之前的逻辑，会写一个循环

```c
#include <stdio.h>  
  
void print(int a[]) {  
    for (int i = 0; i <= 4; i++) {  
        printf("%d\n", a[i]);  
    }  
}  
  
int main(void) {  
    int a[5] = {1, 2, 3, 4, 5};  
    print(a);  
    return 0;  
}
```
但是如果只允许传入指针呢？应该如何实现打印？
首先回忆：`*p`是一个`int`型指针，指向的是4个字节的变量。
那么如果让指针的值往后挪一个，是不是就可以读到下一个数字了呢？确实如此。注意：此时对指针的`++`或`--`是加减4，因为指针是`int`型，指向的内存地址以4为单位递增。
```c
#include <stdio.h>  
void print(int *p) {  
    for (int i = 0; i <= 4; i++) {  
        printf("%d\n", *p);  
        p++;  
    }  
}  
int main(void) {  
    int a[5] = {1, 2, 3, 4, 5};  
    print(&a[0]);  
    return 0;  
}
```
这样也可以实现打印数组。
## 2.3 指针的运算之：`*`和`++`我怎么傻傻分不清
在上面的代码块中，我们先打印`*p`，再让`p++`，可以直接写成`*p++`。
这是因为在C中，`*`的运算优先级没有`++，--`高。
实际上执行过程分成两步：先`p++`，再`*`

| 步骤       | 操作                             | 当前 `p` 的值 | 说明         |
| -------- | ------------------------------ | --------- | ---------- |
| 初始       | `p = &a[0]`                    | 指向 `a[0]` |            |
| 执行 `p++` | 返回旧值 `&a[0]`，然后 `p` 变为 `&a[1]` | 指向 `a[1]` | 表达式值是旧地址   |
| `*` 解引用  | `*旧p` → `*(&a[0])`             | 指向 `a[1]` | 读取到 `a[0]` |
**由此顺便引入一个辨析：`*p++，*(p++),(*p)++,++*p,++(*p),*++p,*(++p)`到底有什么区别？**

**第一个基本原则是：**
**`p++`：先返回原先的`p`，再让`p`前进一格**
**`++p`：先让`p`前进一格，再返回新的`p`值**

我们再结合运算的优先级：
- `*p++`：先用``p``的原值计算`*p`，再让`p`前进一格
- `*(p++)`：和上面一样，有无括号都没有区别
- `(*p)++`：让指针指向的**值本身**自增。譬如若`*p`是指向`i`的指针，此操作实际是让`i`自增
- `++*p`：让指针指向的**值本身**自增，但和上面不同的是，返回的是这个新的值。
- `++(*p)`：同上，因为`++`运算优先级更高，其实没有区别。
- `*++p`：先让`p`前进一格，再返回前进一格后的`p`指向的数值
- `*(++p)`：与上面一种方法等价
我们列表来看的更清楚吧：
（假设初始时：`p=&a[0],a[0]=10, a[1]=20`）

| 表达式      | 操作顺序         | 输出结果     | p 的最终位置 | 数组变化      |
| -------- | ------------ | :------- | ------- | --------- |
| `*p++`   | 先取值，再让指针后移   | 10（旧值）   | → &a[1] | 无变化       |
| `*(p++)` | 同上           | 10       | → &a[1] | 无变化       |
| `(*p)++` | 先取当前值，后让该值自增 | 10（旧值）   | &a[0]   | a[0] → 11 |
| `++*p`   | 先让值自增，再取新值   | 11（新值）   | &a[0]   | a[0] → 11 |
| `++(*p)` | 同上           | 11       | &a[0]   | a[0] → 11 |
| `*++p`   | 先让指针前移，再取值   | 20（a[1]） | → &a[1] | 无变化       |
| `*(++p)` | 同上           | 20       | → &a[1] | 无变化       |
## 2.4 不使用`for`循环实数组的打印
在上述代码块中，我们使用了for循环来实现数组的打印，但是如果不使用for循环应该如何实现呢？

```c
#include <stdio.h>  
  
int main(void) {  
    int a[] = {0, 1, 2, 3, 4};  
    int *p = &a[0];  
    int len = sizeof(a) / sizeof(a[0]);  
    while (p < &a[len]) {                  //注意：此处是p不是*p
        printf("%d ", *p++);  
    }  
}

Output:
0 1 2 3 4
```
如果要反向输出呢？🤓我们再试试
```c
#include <stdio.h>  
  
int main(void) {  
    int a[] = {0, 1, 2, 3, 4};  
    int len = sizeof(a) / sizeof(a[0]);  
    int *p = &a[len];  
    while (p > &a[0]) {  
        printf("%d ", *p--);  
    }  
}

Output:
5 4 3 2 1
```
为什么不对？因为第一步`*p`指向的是`a[5]`，而我们期望打印的是`a[4]`，因此，需要先让`p`往前挪动，再打印。故`*p--`应该改为*`--p`才对！（但是最好不要这么写，因为真的很容易混淆🤣）
## 2.5 谨防指针越界
我们再看一个对上方代码块的改写：
```
    int len = sizeof(a) / sizeof(a[0]);  
    int *p = &a[len-1];  
    while (p >= &a[0]) {  
        printf("%d ", *p--);  
    }  
```
看上去没有问题，好像是打印了数组中的每一个元素。但这个写法是`UB`。因为当两个指针拿来比较的时候，如果是比较某个内存地址比如`a or b`的地址只有指向同一个变量可以通过相等来判断。
而当两个指针比较数组的时候，两个指针必须指向同一个数组内。所以当最后一次`p--`后，它指向了`a[-1]`，此时已越界，比较`a[-1]`和`a[0]`就有风险！
## 2.6 一个小例子：max函数
```c
#include <stdio.h>  
  
int getMax(int *p, int len) {  
    int max = *p;  
    for (int i = 0; i < len; i++) {  
        if (*p >= max) { max = *p; }  
        p++;  
    }  
    return max;  
}  
  
int main(void) {  
    int a[] = {1, 2, 3, 4, 5};  
    int len = sizeof(a) / sizeof(a[0]);  
    printf("%d", getMax(&a[0], len));  
    return 0;  
}

Output:
5
```
注意：此时`return max`传回去的`max`对应的地址在函数`getMax`的内存中，`main`函数中没有`max`的地址。如果下一次调用其他的函数，将很有可能会覆写`max`原本的值，因此如果调用`max`的地址，无法得到正确结果。
因此对于指向局部变量的指针，传出再解引用很容易出现问题，不应该这么传出！⚠️
如果一定要这样，应当把`max`定义在`main`函数中进行操作。



# 3.指针常见错误
## 3.1 指针使用前未指向任何变量
野指针：没有指向任何变量，可能会指向任何初始值，如果直接解引用可能会造成意想不到的后果...
如果指针不用，或者还没有定义那么使用`int *p=NULL`，可以此指针数值变为0（0地址）
此时如果指针`p`被强制转换成地址，指向地址是0的内存，因此可能前往无权限访问的地址，从而报错`SIGSEGV`
# 4.指针的运算
## 4.1 下标运算
指针可以和数组同等取下标运算
```c
int a[10];
int *p=a;
p[0]==a[0];
```
因此：`p[i]==*(p+i)`
## 4.2 算术运算
使用算术运算来代替数组下标进行处理
注意：
- 一般和数组关系密切，指针应该指向连续内存
- `p+1`操作中，`+1`加的是同类型的`sizeof`大小，比如`int`是4个字节，那么`p++`的地址就往后挪4，因此使用指针进行算术运算时，指针的类型应当匹配
## 4.3 指针的赋值
- 不同类型的指针不能相互赋值
- `void *p`表示不知道指向什么类型的指针，可指向任何类型，需要强转后才能解引用，不能做加减运算
- 指针也可以做类型转换
---------
附：指针转换的语法
基本形式是：`(目标类型 *) 指针表达式`
例如，把 `void *` 转成 `int *`：
```c
void *p; 
int *ip = (int *)p;
```

----------
## 4.4 指针的`const`
### 第一种:`const`在`*`后
```
int *const p = &a;
*p = 100;✅
p = &b;❌
```
此时指针不可以更改，只能指向`a`，但是可以通过指针修改`a`的值
## 第二种：`const`在`int`前
```
const int *p = &a;
*p = 100;❌
p = &b;✅
```
此时不可通过指针修改此变量（但是仍然可以直接修改此变量，变量没有变成`const`）
# 5.多维数组和指针
## 5.1 引入
想想：以前在二维数组函数传参的时候为什么要写`int a[][100]`呢？
首先明确，传入的是一个指针。那么传入的是什么样的指针呢？
类比一下，传入的是指向数组的一个长度为`100个int`的指针，即`p`是一个指向一维数组的指针
## 5.2 指针数组和数组指针
这是 C 语言里最容易混淆的一组概念
### 一句话区分：
**指针数组：数组里的每个元素都是“指针”。**
**数组指针：指向整个数组的“指针”。**
### 指针数组：关键是数组

```
int *p[10];
```
这是一个 **数组**，长度 10  ，每个元素都是 **int 型指针**
也即：
```
p: [ * , * , * , * , ... ]   // 每个都是指针
```
### 数组指针：关键是指针
```
int (*p)[10];
```
这是一个**指针**，指向一个包含 10 个 int 的**数组**
也即：
```
p ---> [ int, int, int, ... 10 个 ]
```
### 对比

|名称|声明|含义|类型|
|---|---|---|---|
|指针数组|`int *p[10]`|一个数组，里面放 10 个 int 指针|数组|
|数组指针|`int (*p)[10]`|一个指针，指向包含 10 个 int 的数组|指针|

### 最容易混淆的例子

下面的两个只差一个括号，却差远了：
```c
int *p[5];    // 指针数组
int (*p)[5];  // 数组指针
```
## 5.3如果要取第`i`行的第`j`列，咋办哩？
`p[i][j]`和`*(p[i] + j)`和`*(*(p + i) + j)`都可以。
我们解释一下`*(*(p + i) + j)`如何执行的。
第一步，把它变成指向第`i`行的一个二维的数组指针
第二步，对其解引用得到第`i`行的一维数组，**在`c`中这个数组会自动变成一个指向数组首地址的指针。**
第三步，再加`j`从而使其指向第`j`列
第四步，再次解引用，得到第`i`行的第`j`列的数字
