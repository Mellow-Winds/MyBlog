## 第一题：使用`strtok`函数按指定的分隔符拆分字符串
`strtok` 用来**按指定的分隔符拆分字符串**。
第一次调用
`strtok(s, ",")`
`strtok` 会修改字符串，把遇到的分隔符改成 `\0`
例如：  
`a,b,c` → `a\0b\0c\0`
后续调用
- 用 `strtok(NULL, ",")`
- 继续从上次停止的地方找下一个 token
```c
#include <string.h>  
#include <stdio.h>  
  
int main() {  
    char str[80] = "xx-xxxx-xxxxx-xxxxx";  
    const char s[2] = "-";  
    char *token;  
    // 获取第一个子字符串  
    token = strtok(str, s);  
    // 继续获取其他的子字符串  
    while (token != NULL) {  
        printf("%s\n", token);  
        token = strtok(NULL, s);  
    }  
    return 0;  
}
```
将分开的东西存入新的数组：
```c
char s[] = "cat,dog,pig";
char *token;

char result[10][20];
int count = 0;

token = strtok(s, ",");

while (token != NULL) {
    strcpy(result[count], token); // 把 token 存入二维数组
    count++;
    token = strtok(NULL, ",");
}
```
注意：`while`里面是`token = strtok(NULL, ",");`，这样才能保证在接下来继续从上次分割的地方分割！

## 第二题：使用`strchr`查找某个字符第一次出现的位置
`strchr` 函数是 C 语言里非常常用的字符串处理函数，用来**在字符串中查找某个字符第一次出现的位置，并返回指向它的指针。**
函数原型：
```c
char *strchr(const char *s, int c);
```
### 🌟 基本用法示例
```c
#include <stdio.h>
#include <string.h>

int main() {
    char str[] = "hello world";

    char *p = strchr(str, 'o');

    if (p != NULL) {
        printf("%s\n", p);
    } else {
        printf("NULL\n");
    }

    return 0;
}
```
输出：
```
o world
```
因为 `strchr` 返回的是 `'o'` 第一次出现的位置的指针，所以 `printf("%s", p);` 会从 `o` 开始输出到字符串结尾。
### 🌟 常见用途
#### 1. 查找字符是否存在
```c
if (strchr(email, '@') == NULL) {
    printf("不是有效邮箱\n");
}
```
#### 2. 得到字符后面的内容
```c
char *ext = strchr(filename, '.');
if (ext) {
    printf("文件扩展名是: %s\n", ext + 1); // +1 跳过点
}
```
#### 3. 分割字符串（和 `strtok` 不同，strchr 只是定位）

```c
char *comma = strchr(line, ',');
if (comma) {
    *comma = '\0';  // 把逗号替换成结束符
}
```
### 特别注意
- `strchr` 查找的是 **字符（char）**，不是字符串
- 如果查找的是 `'\0'`，会返回字符串末尾的结束符位置
- 返回的是指向原字符串内部的指针，不要随意 free

## 第四题：已知地址 a 和地址 b，如何把 a 到 b 之间的字符拷贝出来，生成一个新的字符串？
使用`memmove`函数
```c
char* substring_by_addr(char *a, char *b) {
    int len = b - a;            // 计算区间长度
    char *res = malloc(len + 1); // +1 放 '\0'
    if (!res) return NULL;
    memmove(res, a, len);       // 复制内存
    res[len] = '\0';            // 补上字符串结束符
    return res;
}
char s[] = "HelloWorld";
char *a = &s[2];   // 指向 'l'
char *b = &s[7];   // 指向 'o' 的后位置
char *newstr = substring_by_addr(a, b);
printf("%s\n", newstr);   // 输出：lloWo
free(newstr);
```
## 第四题：`memmove`函数使用方法
`memmove` 是 C 标准库 `<string.h>` 中的函数，用来**安全地复制一段内存到另一段内存**。
✨ 和 `memcpy` 最大的区别是：  
**`memmove` 能处理内存重叠（overlap）**，不会出现数据被覆盖导致的错误。
### 1.函数原型
```c
void *memmove(void *dest, const void *src, size_t n);
```
含义：

| 参数     | 含义            |
| ------ | ------------- |
| `dest` | 目标内存地址（复制到这里） |
| `src`  | 源内存地址（从这里复制）  |
| `n`    | 要复制的字节数       |
返回值：`dest`
### 🌟 示例 1：安全的重叠复制

```c
#include <string.h>
#include <stdio.h>

int main() {
    char s[] = "abcdef";

    memmove(s + 2, s, 4);  // 把 "abcd" 移动到 s[2]

    printf("%s\n", s);     // 输出：ababcd
    return 0;
}
```
tips：如果用 `memcpy`，就会出现数据错乱，因为它不考虑重叠问题。

解释：
初始状态是：`s = "a b c d e f \0"`
`memmove` 的参数是：
- `dest = s + 2` → 从下标 **2** 开始
- `src = s` → 从下标 **0** 开始
- `n = 4` → 复制 **4 个字节**：也就是把 `"abcd"` 复制到从 `s[2]` 开始的位置

把 `"abcd"` 移动到 2 号位后：
**原字符串：**`a b c d e f`
**复制的四个字符 `abcd` 放到第 2～5 位：**`a b a b c d`
### 🌟 示例 2：普通内存复制

```c
int a[5] = {1,2,3,4,5};
int b[5];

memmove(b, a, sizeof(a));
```

这样可以把数组 `a` 的内容安全复制到 `b`。

```c
#include <stdio.h>
```
