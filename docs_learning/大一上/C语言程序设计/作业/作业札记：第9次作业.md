# `bsearch`函数如何使用
## 🌟 `bsearch` 是什么？
`bsearch` 是 C 标准库 `<stdlib.h>` 中的 **二分查找函数**  
前提：**数组必须是已排序的**（升序或降序都可以，只要比较函数一致）。
## 🧩 函数原型

```c
void *bsearch(const void *key,
              const void *base,
              size_t nmemb,
              size_t size,
              int (*compar)(const void *, const void *));
```

## ✔️ 参数解释（非常重要）

|参数|含义|
|---|---|
|`key`|要查找的“关键字”的指针|
|`base`|数组的起始地址|
|`nmemb`|数组元素个数|
|`size`|每个元素的大小 (`sizeof(...)`)|
|`compar`|比较函数，告诉 bsearch 元素如何比较|

## 🧠 比较函数 `compar` 怎么写？
**必须返回：**
- `<0`：_元素_ < _key_
- `=0`：相等（找到）
- `>0`：元素 > key
最常用写法（升序 int 数组）：
```c
int cmp_int(const void *a, const void *b) {
    return *(int*)a - *(int*)b;
}
```
## ✨ 示例：查找 int

```c
#include <stdio.h>
#include <stdlib.h>

int cmp_int(const void *a, const void *b) {
    return *(int*)a - *(int*)b;
}

int main() {
    int arr[] = {1, 3, 5, 7, 9, 11};
    int key = 7;

    int *p = bsearch(&key, arr, 6, sizeof(int), cmp_int);

    if (p != NULL)
        printf("找到元素：%d\n", *p);
    else
        printf("未找到\n");

    return 0;
}
```
## 🔍 `bsearch` 返回什么？
找到：  
→ 返回 **指向该元素的指针**
未找到：  
→ 返回 `NULL`
## 📚 示例2：按结构体查找（非常常用）

```c
typedef struct {
    int id;
    char name[20];
} Student;

int cmp_by_id(const void *a, const void *b) {
    return ((Student*)a)->id - ((Student*)b)->id;
}
```
释疑：`((Student*)a)->id`为何可以找到`a`的`id`？
这是指向一个结构体的指针，再在结构体中找到`id`
查找：
```c
Student key = { .id = 3 };
Student *p = bsearch(&key, stu, n, sizeof(Student), cmp_by_id);
```
## ⚠️ 注意
1. **数组必须提前排序好**，比如用 `qsort`。
2. 比较函数 **一定要根据排序规则一致**。
3. 返回的是 `void*`，要**自行强制转换类型**。
4. 有时候数据可能溢出，如果不想报错可以试试以下写法：
```c
 int cmp_student(const void *a, const void *b) {
    int ida = ((const Student*)a)->id;
    int idb = ((const Student*)b)->id;
    if (ida < idb) return -1;
    if (ida > idb) return 1;
    return 0;
}
```
5. 比较函数的值是`const void`
```c
cmp(const void *a, const void *b)
```
而后需要进行类型转换，比如：
```c
int a = *(int*)p1;  
int b = *(int*)p1;
```
才可以进行比较，或者直接`return *(int*)p1-*(int*)p1`也是可以的
## 🤓其他：二分法的标准写法
```c
int a[n];
int find(int x) {
    int l = 1, r = n, ans = -1;
    while (l <= r) {
        int mid = l + r >> 1;
        if (a[mid] <= x) {
            l = mid + 1;
            ans = mid;
        } else {
            r = mid - 1;
        }
    }
    return ans;
}
```

# `qsort`函数如何使用
`qsort` 是 C 标准库 `<stdlib.h>` 里的一个**通用排序函数**，可以对**任意类型**的数据排序，只要你提供好比较函数。
## ✅ **基本原型**

```c
void qsort(
    void *base, 
    size_t nmemb, 
    size_t size,
    int (*compar)(const void *, const void *)
);
```
参数解释：

|参数|含义|
|---|---|
|`base`|要排序的数组起始地址|
|`nmemb`|数组元素个数|
|`size`|每个元素的大小，使用 `sizeof`|
|`compar`|比较函数指针，用来告诉 qsort 如何比较两个元素|

## ⭐比较函数怎么写？
比较函数必须返回：
- **负数 → a < b**
- **0 → 相等**
- **正数 → a > b**
常见写法：
### ✔ 整数升序

```c
int cmp(const void *a, const void *b) {
    return *(int *)a - *(int *)b;
}
```
### ✔ 整数降序

```c
int cmp(const void *a, const void *b) {
    return *(int *)b - *(int *)a;
}
```
如果不知道就试试吧！
## ⭐整数排序
示例：从小到大排序 int 数组
```c
#include <stdio.h>
#include <stdlib.h>

int cmp(const void *a, const void *b) {
    return *(int *)a - *(int *)b;   // 小于0则 a<b
}

int main() {
    int arr[] = {3, 1, 4, 1, 5, 9};
    int n = sizeof(arr) / sizeof(arr[0]);

    qsort(arr, n, sizeof(int), cmp);

    for (int i = 0; i < n; ++i)
        printf("%d ", arr[i]);
}
```
## ⭐排序结构体
假设有结构体：
```c
struct Stu {
    int age;
    double score;
};
```
按 `age` 从小到大排序：
```c
int cmp_age(const void *a, const void *b) {
    return ((struct Stu *)a)->age - ((struct Stu *)b)->age;
}
```
调用：
```c
qsort(students, n, sizeof(struct Stu), cmp_age);
```
## ⭐字符串排序

```c
int cmp_str(const void *a, const void *b) {
    return strcmp((char*)a,(char*)b);
}
```
## ⭐浮点数排序

需要注意浮点数会存在精度损失的问题，所以我们需要通过比较，来返回1或-1，以确定是增序还是降序。

```c
int cmp(const void *a,const void *b) {
return *(double*)a>*(double*)b?1:-1;
}
```
## ⭐常见坑
❌ 1.不能写成这样
```c
return *(int*)a > *(int*)b;   // 只返回 0/1，错误！
```
❌ 2.不要忘记强制类型转换
比较函数的参数都是 `const void*`，需要你自己转成正确类型。
❌ 3.注意不要溢出数据，可以使用安全的比较：
```c
int compare_safe(const void *p1, const void *p2) {
    int a = *(int*)p1;
    int b = *(int*)p2;
    if (a > b) return 1;
    if (a < b) return -1;
    return 0;
}
```

# 如何批量建立结构体？
## 1. 使用结构体数组
如果知道需要的结构体数量，可以使用结构体数组：
```c
#include <stdio.h>
// 1. 定义结构体
typedef struct {
    int id;
    char name[50];
    float score;
} Student;
int main() {
    // 2. 批量创建：定义一个包含 100 个 Student 元素的数组
    Student student_list[100]; // 这就批量建立了 100 个结构体
    // 3. 访问和初始化第一个结构体
    student_list[0].id = 1001;
    strcpy(student_list[0].name, "Alice");
    student_list[0].score = 95.5;
    // 4. 访问和初始化第 N 个结构体（使用循环）
    for (int i = 0; i < 100; i++) {
        student_list[i].id = 202300 + i;
        // 可以根据需要给其他字段赋值...
    }
    printf("第一个学生的ID: %d\n", student_list[0].id);
    return 0;
}
```
## 2. 使用动态内存分配
如果无法在编译时确定结构体的数量，可以使用 `malloc` 或 `calloc` 动态分配内存：
```c
#include <stdio.h>
#include <stdlib.h>

struct Person {
    char name[50];
    int age;
};

int main() {
    int n = 5;
    struct Person *people = (struct Person *)malloc(n * sizeof(struct Person));  // 动态分配内存

    if (people == NULL) {
        printf("Memory allocation failed!\n");
        return -1;
    }

    // 给结构体赋值
    for (int i = 0; i < n; i++) {
        snprintf(people[i].name, sizeof(people[i].name), "Person %d", i + 1);
        people[i].age = 20 + i;
    }

    // 打印结构体信息
    for (int i = 0; i < n; i++) {
        printf("Name: %s, Age: %d\n", people[i].name, people[i].age);
    }

    free(people);  // 释放动态内存
    return 0;
}
```
