把符合下列属性的数组 `arr` 称为 **山脉数组** ：

- `arr.length >= 3`
- 存在下标 `i`（`0 < i < arr.length - 1`），满足
    - `arr[0] < arr[1] < ... < arr[i - 1] < arr[i]`
    - `arr[i] > arr[i + 1] > ... > arr[arr.length - 1]`

给出一个整数数组 `arr`，返回最长山脉子数组的长度。如果不存在山脉子数组，返回 `0` 。

### 1. 考虑枚举

从最简单的情况出发：
1. 遍历每一个数，找到可能的“峰顶”
2. 从峰顶往左右遍历，直到到头或者到达谷底
3. 计算其值，并与max比较
```java
public class LongestMountain {  
  
    public static int longestMountain(int[] arr) {  
        int max = 0;  
        int n = arr.length;  
        //1. 遍历每一个数，找到可能的“峰顶”  
        for (int i = 1; i < n - 1; i++) {  
            //If this is a PeakNum  
            if (arr[i] > arr[i - 1] && arr[i] > arr[i + 1]) {  
                //2. 从峰顶往左右遍历，直到到头或者到达谷底  
                int left = 0;  
                int right = 0;  
                //2.1 count the left  
                for (int j = i; j > 0; j--) {  
                    if (arr[j] > arr[j - 1]) {  
                        left++;  
                    } else {  
                        break;  
                    }  
                }  
                //2.2 count the right  
                for (int j = i; j < n - 1; j++) {  
                    if (arr[j] > arr[j + 1]) {  
                        right++;  
                    } else {  
                        break;  
                    }  
                }  
                //3. 计算其值，并与max比较  
                int thisPeek = left + right + 1;  
                if (thisPeek > max) {  
                    max = thisPeek;  
                }  
            }  
        }  
        return max;  
    }  
}
```

时间复杂度$O(n^2)$，最坏的情况是都遍历。
