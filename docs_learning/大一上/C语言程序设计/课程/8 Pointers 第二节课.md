# 1.温故而知新：一个辨析
```c
#include <stdio.h>  
  
int main(void) {  
    int a[5] = {1, 2, 3, 4, 5};  
    printf("%p\n", a);  
    printf("%p\n", &a);  
    printf("%p\n", a + 1);  
    printf("%p\n", &a + 1);  
}
```
我们看这一串代码，看看它表达的是什么意思？(假设`a`的地址是`0x1000`)
**1.`printf("%p\n", a);`**
- **解释**：`a` 在表达式中会退化为指向首元素的指针，也就是 `&a[0]`。
- **值**：数组首元素的地址 `&a[0]`。
- **示例**：`0x1000`
- **类型**：`int*`
**2.`printf("%p\n", &a);`**
- **解释**：`&a` 是整个数组 `a` 的地址，即“指向数组的指针”。
- **值**：数组的起始地址，与 `a` 相同。
- **示例**：`0x1000`（看起来一样，但类型不同）
- **类型**：`int (*)[5]` （指向 5 个 `int` 的数组的指针）
**3. `printf("%p\n", a + 1);`**
- **解释**：`a` 退化成 `&a[0]`，所以 `a + 1` 是 **指向下一个 `int` 元素** 的地址。
- **计算**：`0x1000 + 1 * sizeof(int)`
- `int` 是 4 字节，则 `a + 1 = 0x1004`
- **类型**：`int*`
**4. `printf("%p\n", &a + 1);`**
- **解释**：`&a` 类型是 `int (*)[5]`，加 1 就是跳过整个数组的大小。
- **计算**：`0x1000 + 1 * sizeof(a)`，其中`sizeof(a) = 20`
- 所以 `&a + 1 = 0x1000 + 20 = 0x1014`
- **类型**：`int (*)[5]`

# 2. 动态内存分配
## 2.1 `malloc`函数和`free`函数
当我们想要有多少个数就开多少大小的数组以此减少内存的浪费，该咋办哩？
⚠️不推荐`int a[n]`的写法
✅我们可以使用`malloc`和`free`函数执行动态内存的分配和释放
`malloc` 用于**动态分配内存**，位于堆上（heap），返回一个`void*`指针，**一般需要强制类型转换。**
```c
#include <stdlib.h>                     // malloc、free需要此头文件

int main() {
    int a[5]={1,2,3,4,5}
    int *p;
    p = (int *)malloc(len * sizeof(int));  // 在堆中分配len个int大小的连续内存
}
```
此处的p是被强制类型转换后的指针，指向堆中的一个内存。
## 2.2 一些注意事项
### 2.2.1如果`malloc`分配未成功会返回`NULL`，这需要检查
```c
if (p == NULL) {                     // 检查是否分配成功
        printf("内存分配失败\n");
        return 1;
    }
```
### 2.2.2申请后需要释放，释放后就不要再使用了
使用`free(p);`以释放内存，而且如果`malloc`和`free`分在不同函数中，还需要保证这些函数要成对出现，保证可以被释放掉。
⚠️不要释放多次！
⚠️`malloc`和`free`应该成对出现。
### 2.2.3 申请`malloc`后，指针`p`就不要再改动了，不然`free`会失败
应该再创建一个指针和`p`相同，用新的指针操作，最后`free(p)`
### 2.2.4 不要对分配的内存进行越界操作

## 2.4 `calloc`函数
在 C 语言中，`malloc` 和 `calloc` 都用于动态内存分配，但是有一定区别：
### 1. 初始化行为不同（最重要）
`malloc`只分配内存 **但不初始化**：分配的内存中内容是 **未定义的**（可能是随机值）。
`calloc`分配内存 **并全部初始化为 0**：更适合需要干净内存的情况，如分配数组。

例如分配 10 个 int：
`malloc`：
```c
int* p = malloc(10 * sizeof(int));
```
`calloc`：
```c
int* p = calloc(10, sizeof(int)); // 自动做乘法，且初始化为0
```
### 2. 内存布局不同
`calloc` 在某些系统中会确保内存是连续的（虽然大多数情况下 `malloc` 也会这样）。
- `calloc` 可能在分配大块内存时更快（操作系统可提供零页，省去手动清零）。
### 3. 使用场景区别
用 `malloc` :
- 会马上给内存写入值（例如 struct 初始化）。
- 不需要一开始就清零。
用 `calloc` :
- 需要清零的内存（如数组、哈希表、DP数组）。
- 避免 uninitialized memory bug。
# 3.字符数组和字符串
```c
char a[]="Hello"
char *p="Hello"
```
有什么区别呢？
`a[0]='M'`✅
`p[0]='M`❌
为什么会这样呢？
因为`p`指针指向的`hello`存储在了只读数据区（不可修改），而不是放在栈中

比较两个字符串是否相同，可以使用`strcmp`函数实现
字符串的copy，使用`strcpy`实现
在其中加入n，形如`strncpy`以实现长度为n的子串复制
