# 排序
在 Python 中，排序是一个非常常见的操作，而 `key` 参数和 `lambda` 表达式是排序功能中的一对黄金搭档。它们能让你的代码更加简洁高效。本文将通过简单的例子和通俗的讲解，带你快速上手。
## 什么是 `key` 参数？

`key` 参数是 Python 的排序方法（比如 `[list.sort()]和[sorted()]`）中的一个可选参数，用于自定义排序规则。

- **默认排序**：如果不指定 `key`，Python 会按照元素的默认大小排序。
- **自定义排序**：通过指定 `key`，可以让排序按照我们定义的规则进行。

举个例子：

```python
nums = [-3, 1, -4, 1, 5, -9]
nums.sort()  # 默认按数值大小排序
```
如果我们想按照每个数字的绝对值排序，就需要用 `key`：
```python
nums = [-3, 1, -4, 1, 5, -9]
nums.sort(key=abs)  # 使用绝对值作为排序依据
print(nums)  # 输出：[1, 1, -3, -4, 5, -9]
```
这里，`abs` 是 Python 自带的绝对值函数，`key=abs` 的意思是“按照元素的绝对值排序”。
## 什么是 `lambda` 表达式？
`lambda` 是 Python 用来创建匿名函数的工具，简单来说，它可以定义一个短小的函数，而无需使用 `def`。
### `lambda` 的语法
```python
lambda 参数1, 参数2, ...: 表达式
```
- **参数**：可以有一个或多个，用逗号分隔。
- **表达式**：只能写一行，结果就是返回值。
比如，我们可以用 `lambda` 创建一个加法函数：
```python
add = lambda x, y: x + y
print(add(2, 3))  # 输出：5
```
### `key` 和 `lambda` 的结合应用
在排序中，`key` 参数常常和 `lambda` 表达式搭配使用，因为 `lambda` 可以快速定义排序规则。
### 按字符串长度排序
```python
words = ["apple", "banana", "cherry", "date"]
words.sort(key=lambda x: len(x))  # 按长度排序
print(words)  # 输出：["date", "apple", "banana", "cherry"]
```
### 按字典的值排序
```python
people = [
    {"name": "Alice", "age": 25},
    {"name": "Bob", "age": 20},
    {"name": "Cathy", "age": 30}
]

people.sort(key=lambda x: x["age"])  # 按年龄排序
print(people)
# 输出：[{'name': 'Bob', 'age': 20}, {'name': 'Alice', 'age': 25}, {'name': 'Cathy', 'age': 30}]
```
### 按多个条件排序
如果我们希望优先按年龄排序，年龄相同时按名字排序：
```python
people = [
    {"name": "Alice", "age": 25},
    {"name": "Bob", "age": 20},
    {"name": "Karen", "age": 20},
    {"name": "Cathy", "age": 30}
]
people.sort(key=lambda x: (x["age"], x["name"]))
print(people)
```
## 实用场景

### 1. 过滤列表元素

和 `filter` 配合，快速筛选符合条件的元素：

```python
nums = [1, 2, 3, 4, 5]
even_nums = list(filter(lambda x: x % 2 == 0, nums))
print(even_nums)  # 输出：[2, 4]
```
### 2. 转换列表元素

和 `map` 配合，对列表元素逐一转换：

```python
nums = [1, 2, 3, 4]
squares = list(map(lambda x: x**2, nums))
print(squares)  # 输出：[1, 4, 9, 16]
```
## 总结

## `lambda` 和普通函数的对比

| 特性       | lambda 表达式 | 普通函数     |
| -------- | ---------- | -------- |
| 是否需要名字   | 不需要        | 需要       |
| 是否适合复杂逻辑 | 不适合，仅限单行逻辑 | 适合多行复杂逻辑 |
| 是否可重复使用  | 通常用于一次性场景  | 可重复使用    |
| 可读性      | 简洁，但可能难以理解 | 可读性较高    |

---

### 注意事项

1. **尽量保持简单**：`lambda` 适合一两行的简单逻辑，复杂的逻辑应该使用 `def`。
2. **多参数组合**：如果需要返回多个值，可以用元组或列表包装。
3. **避免滥用**：如果函数逻辑超过一行，`lambda` 会降低代码的可读性。注意事项
4. lambda只能写一行：如果逻辑复杂，建议用 `def` 定义函数。
5. **函数名不要加括号**：**传递给 `key` 的是函数名**，而不是函数调用。

`key` 和 `lambda` 是 Python 排序中的一对黄金搭档，掌握它们能让代码更加简洁高效。
# 切片
**切片**是 Python 里一个**非常重要、也很好用的小技巧**，用来**从序列中“切出一部分”**。
## 一、什么是切片？
**切片 = 从一个序列中，按规则取出一段连续的元素**
可以切片的对象有：
- 字符串 `str`
- 列表 `list`
- 元组 `tuple`
## 二、切片的基本格式
```python
序列[start : end : step]
```
👉 含义：
- `start`：起始位置（**包含**）
- `end`：结束位置（**不包含**）
- `step`：步长（每次跳几个）
📌 口诀：  
**“左闭右开，步长可省”**
## 三、最常见的切片用法
### 1️⃣ 只写 start 和 end
```python
a = [10, 20, 30, 40, 50]
print(a[1:4])
```
输出：
```text
[20, 30, 40]
```
解释：
- 从下标 1 开始
- 到下标 4 结束（但不包含 4）
### 2️⃣ 省略 start（从头开始）
```python
print(a[:3])
```
输出：
```text
[10, 20, 30]
```
### 3️⃣ 省略 end（到结尾）
```python
print(a[2:])
```
输出：
```text
[30, 40, 50]
```
### 4️⃣ 全部切出来（复制）
```python
b = a[:]
```
📌 这是**浅拷贝列表**，很常用！
## 四、step（步长）的用法
### 5️⃣ 每隔一个取
```python
print(a[::2])
```
输出：
```text
[10, 30, 50]
```
### 6️⃣ 反转序列（经典）
```python
print(a[::-1])
```
输出：
```text
[50, 40, 30, 20, 10]
```
🌟 这个以后会经常见到！
为什么是-1？可以理解为步长指的是下一步往哪边走，所以-1表示往回走。
## 五、负数下标 + 切片
负数表示**从后往前数**
```python
a = [10, 20, 30, 40, 50]
print(a[-3:-1])
```
输出：
```text
[30, 40]
```
解释：
- `-3` → 30
- `-1` → 50（但不包含）
## 六、字符串切片（和列表一模一样）
```python
s = "hello world"
print(s[0:5])
print(s[6:])
```
输出：
```text
hello
world
```
📌 字符串**不能改**，但可以切！
## 七、切片 vs 单个索引

```python
a = [1, 2, 3, 4]

print(a[1])    # 单个元素
print(a[1:2])  # 列表
```
输出：
```text
2
[2]
```
🌟 很容易混淆，一定要注意！
## 八、总结
- 切片用来 **取一段**
- 格式：`[start:end:step]`
- **左闭右开**
- `[::-1]` 可以反转
- 适用于字符串、列表、元组
