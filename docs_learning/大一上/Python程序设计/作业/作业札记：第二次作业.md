## 第九题问题：为什么复制列表a为b后，改动b，a也被改了
这个问题，其实是 Python 中 **“可变对象的赋值和引用”** 的经典坑 😅。
现象示例：
```python
a = [1, 2, 3]
b = a        # 直接赋值
b.append(4)

print(a)     # [1, 2, 3, 4]
print(b)     # [1, 2, 3, 4]
```
想改 `b` 不影响 `a`，但是发现 `a` 也变了！
原因：**赋值只是引用**
- 在 Python 中，列表是 **可变对象（mutable）**
- `b = a` 并不是复制列表，而是 **让 `b` 指向同一个列表对象**
- 所以 `a` 和 `b` 指向的是 **同一个内存中的列表**
- 对 `b` 的修改，自然也会反映在 `a` 上

解决方法：深拷贝
```python
import copy
a = [[1, 2], [3, 4]]
b = copy.deepcopy(a)
b[0].append(99)

print(a)  # [[1, 2], [3, 4]]  <-- 完全独立
print(b)  # [[1, 2, 99], [3, 4]]
```
## 第十题：如何删除列表中的重复元素
1.使用 `set`（最快，但不保留顺序）
```python
lst = [1, 2, 3, 2, 1, 4] 
lst = list(set(lst)) 
print(lst)
```
2.循环 + 判断（保留顺序，不报错）

```python
lst = [[1,2], [3,4], [1,2]] 
new_lst = [] 
for x in lst:     
	if x not in new_lst:
		new_lst.append(x) 
```
## 第十题：如何先按 A 排序，如果 A 相同，再按 B 排序
想要 **列表中的元素是复合信息（例如元组或字典），先按 A 排序，如果 A 相同，再按 B 排序**。在 Python 中可以用 **`sorted` 或列表的 `.sort()`**，结合 **`key` 函数** 来实现。下面详细讲解。
### ✅ 方法
1.使用 `sorted`（生成新列表）

```python
sorted_lst = sorted(lst, key=lambda x: (x[0], x[1]))
print(sorted_lst)
```
2。使用原列表 `.sort()`（就地排序）
```python
lst.sort(key=lambda x: (x[0], x[1]))
print(lst)
```

📌 原理：
- `key=lambda x: (x[0], x[1])` → 按元组 `(A, B)` 排序
- Python 排序默认 **先比较第一个，再比较第二个**
- 可以保证 A 相同的元素按 B 排序
### ✅ 其他
#### 如果 B 要**降序**而 A 升序
```python
lst.sort(key=lambda x: (x[0], -x[1]))
```
- `x[0]` 升序
- `x[1]` 降序（用负号）
#### 列表元素是字典的情况
```python
lst = [
    {"A": 2, "B": 5},
    {"A": 1, "B": 7},
    {"A": 2, "B": 3},
    {"A": 1, "B": 4}
]

lst.sort(key=lambda x: (x["A"], x["B"]))
print(lst)
```
输出：
```
[{'A': 1, 'B': 4}, {'A': 1, 'B': 7}, {'A': 2, 'B': 3}, {'A': 2, 'B': 5}]
```
### 总结
1. **元素是元组** → `key=lambda x: (x[0], x[1])`
2. **元素是字典** → `key=lambda x: (x['A'], x['B'])`
3. **B 降序** → `-x[1]` 或 `-x['B']`
4. **原地排序** → `.sort()`
5. **生成新列表** → `sorted(lst, key=...)`
