# 1.把整数转化为二进制
### 1. 使用内置函数 `bin()` (最常用)
这是最直接的方法。`bin()` 函数接收一个整数，返回该整数的二进制表示字符串，前缀为 `0b`。
- **特点**：简单快捷，带前缀。
- **示例**：
```python
num = 10
result = bin(num)
print(result)  # 输出: '0b1010'
```
### 2. 使用 `format()` 函数 (灵活格式化)
如果你不需要 `0b` 前缀，或者需要填充特定位数的零，`format()` 是更好的选择。
- **去掉前缀**：使用 `'b'` 格式化代码。
- **补零对齐**：使用 `'08b'` 表示输出 8 位二进制，不足部分补零。
- **示例**：
```python
num = 10
# 纯二进制字符串
print(format(num, 'b'))    # 输出: '1010'
# 补齐 8 位
print(format(num, '08b'))  # 输出: '00001010'
```
### 3. 使用 f-string (Python 3.6+)
这是目前最推荐的现代写法，语法简洁，底层调用的也是 `format()` 的逻辑。
- **示例**：
```python
num = 10
print(f"{num:b}")   # 输出: '1010'
print(f"{num:08b}") # 输出: '00001010'
```
### 进阶：如何处理负数？

在计算机底层，负数通常以**补码 (Two's Complement)** 形式存储。Python 的 `bin()` 处理负数时会直接在前面加一个负号（如 `-0b1010`），这可能不是你想要的底层表示。
如果你需要得到负数的补码表示（例如 8 位二进制），可以利用位运算：
Python
```
num = -10
# 通过与掩码 0xFF (11111111) 进行按位与运算来获取 8 位补码
complement = bin(num & 0xFF)
print(complement)  # 输出: '0b11110110'
```

# 2.向上取整函数
在 Python 中，**向上取整**（即返回大于或等于给定数字的最小整数）主要通过 `math` 模块中的 `ceil` 函数来实现。
这是处理向上取整的标准方式。无论正数还是负数，它都会向数轴的**正方向**（右侧）取最近的整数。
- **语法**：`math.ceil(x)`
- **代码示例**：
```python
import math
print(math.ceil(3.1))   # 输出: 4
print(math.ceil(3.9))   # 输出: 4
print(math.ceil(-3.1))  # 输出: -3 （注意：-3 比 -3.1 大）
```
