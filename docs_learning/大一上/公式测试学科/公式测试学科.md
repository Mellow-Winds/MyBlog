## 比例公式：$c:v = 8:2$

行内公式：$c:v = 8:2$，以及变量关系 $x^2 + y^2 = z^2$。

$$
c:v = 8:2
$$

## 含有公式的标题：$x^2 + y^2 = z^2$

## 公式中的井号

下面的公式包含井号，但不应该生成额外的章节导航项：

$$
\#\text{ not a heading}\quad ##
$$

```python
# 代码块里的 $x^2$ 不应被当成公式
def ratio(value):
    return value * 2
```

### 公式与章节共存

当一个标题和公式同时出现时，左侧章节导航应保持一个对应项目。
