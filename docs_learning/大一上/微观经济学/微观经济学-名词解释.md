# Ch1: 导论

## 高频考点
1. **机会成本 (Opportunity Cost)**：为了得到某种东西所放弃的东西（放弃的东西中最宝贵的那个）。
## 其他考点
- **平等 (Equality)**：经济成果在社会成员中平均分配。
- **理性人 (Rational People)**：系统而有目的地尽最大努力实现其目标的人。
- **边际变动 (Marginal Changes)**：对现有行动计划的微小增量调整。
- **实证分析 (Positive Analysis)**：研究任务是回答“是什么”，无预设立场，很多情况下可以验证。
-  **规范分析 (Normative Analysis)**：研究任务是回答“应该是什么”，有预设立场，与价值判断有关，无法验证。
- **效率 (Efficiency)**：社会能从其稀缺资源中得到的最大利益。
- **稀缺性 (Scarcity)**：社会资源的有限性。
- **生产可能性边界 (PPF)**：表示在可得到的生产要素与生产技术既定时，一个经济所能生产的两种产品数量的各种组合的图形。

# Ch2: 需求、供给和价格机制

## 高频考点
1. **需求 (Demand)**：在一段时期内，在消费者收入以及其他条件不变的情况下，特定价格下消费者愿意（be willing to）并且能够（be able to）购买的该商品的数量。
2. **供给 (Supply)**：特定价格下生产者愿意并且能够供给的商品数量。
3. **需求价格弹性 (Price Elasticity of Demand)**：一种商品需求量相对变动相应于该商品价格相对变动的反应程度。
4. **消费者剩余 (Consumer Surplus)**：买者愿意为一种物品支付的量减去其为此实际支付的量。
5. **生产者剩余 (Producer Surplus)**：卖者出售一种物品得到的量减去其生产成本。
6. **替代品**：一种物品价格上升引起另一种物品需求增加。
7. **互补品**：一种物品价格上升引起另一种物品需求减少。
## 其他考点
- **均衡价格 (Equilibrium Price)**：供求相等时的价格。
- **支付意愿 (Willingness-to-pay)**：一个买者愿意为一种物品支付的最高量。
- **税收归宿**：关于税收负担在市场参与者之间如何分配的研究。
- **无谓损失 (Deadweight Loss)**：牺牲了本来附着在产量上的总剩余（消费者剩余加生产者剩余），也被称为社会净损失。

# Ch3: 消费者选择

## 高频考点
1. **效用 (Utility)**：消费者从商品消费中获得的满足，是一个主观的感受。
2. **边际效用 (Marginal Utility)**：每增加一单位商品消费所增加的效用。
3. **无差异曲线 (Indifference Curve)**：表示能给消费者带来相同满足程度（效用）的两种商品的不同数量组合的轨迹。
4. **替代效应**：在效用水平不变时，由于相对价格变动导致的消费者向较便宜商品偏移的倾向。
5. **收入效应**：由于价格变动引起的实际购买力变化，从而导致的需求量变动。
6. **吉芬商品 (Giffen Good)**：价格上升，需求量反而增加的商品（收入效应大于替代效应且方向相反）。
7. **边际效用递减规律**：随着消费者对某种商品消费量的增加，从连续增加的消费单位中得到的效用增量是递减的。
## 其他考点
- **边际替代率 (MRS)**：在维持效用水平不变的前提下，消费者增加一单位某种商品的消费时所必须放弃的另一种商品的消费数量。
- **预算约束线**：在收入和商品价格既定的条件下，消费者所能购买的商品组合。
- **恩格尔曲线**：表示消费者在每一收入水平对某商品的需求量的曲线。

# Ch4: 企业的生产和成本

## 高频考点
1. **边际报酬递减规律**：技术给定时，在其他条件保持不变的条件下，一种可变投入在增加到一定程度之后，所带来的边际产量是递减的。
2. **规模经济**：在企业扩大生产的过程中，如果产量扩大一倍，而生产成本的增加小于一倍，则称企业的生产存在规模经济。
3. **沉没成本 (Sunk costs)**：已经发生而无法回收的成本。

## 其他考点

- **总收益**：企业的销售收入，等于销售产品的价格与销售数量的乘积。
- **显性成本**：企业为生产一定数量的产品购买生产要素所花费的实际支出（会计成本）。
- **经济利润**：企业销售产品获得的收益与经济成本之间的差额（经济利润 = 收益 - 经济成本）。
- **生产函数**：表示在技术水平不变的情况下，生产要素投入量与所能生产的最大产出量之间的关系。
- **隐性成本**：企业使用自己所拥有生产要素的机会成本。
- **利润**：利润 = 总收益 - 总成本。
- **规模不经济**：如果企业的产量扩大一倍，而生产成本的增加大于一倍，则称企业的生产存在规模不经济。
- **企业**：经济学中的企业泛指能够做出统一生产和供给决策的基本单位。
- **总成本**：企业生产过程中的各种有形与无形支出，取决于企业的产出数量。
- **会计利润**：企业销售产品获得的收益与会计成本之间的差额（会计利润 = 收益 - 会计成本）。
- **正常利润**：企业家自有资源的机会成本（企业家自有资源的可能性收入）。
- **固定成本 (FC)**：不随企业产量变动而变动的那部分成本。
- **可变成本 (VC)**：随着企业产量变动而变动的那部分成本。
- **平均成本 (AC)**：总成本除以产量（$AC = TC / Q$）。
- **平均不变成本 (AFC)**：固定成本除以产量（$AFC = FC / Q$）。
- **平均可变成本 (AVC)**：可变成本除以产量（$AVC = VC / Q$）。
- **边际成本 (MC)**：增加一单位产量引起的总成本增加量（$MC = \Delta TC / \Delta Q$）。
- **边际产量 (MP)**：增加 1 单位的劳动投入所带来的产出增加量。
- **等产量线**：表示在技术水平不变时，产生同一产量的所有可能的生产要素投入组合。
- **边际技术替代率 (MRTS)**：在产量不变的前提下，增加一单位某种要素投入所能替代的另一种要素的数量。
- **规模报酬**：所有投入要素同比例变化引起的产出变化。分为规模报酬不变 (CRS)、规模报酬递增 (IRS) 和规模报酬递减 (DRS)。
# Ch5: 完全竞争市场

## 高频考点
1. **完全竞争市场**：具备买卖双方极多、产品同质、进出自由、信息完全特征的市场。
2. **边际收益 (MR)**：增加一单位销售量引起的总收益的变动。
3. **停止营业点**：价格等于平均可变成本最低点（P=AVC）。
## 其他考点
- **平均收益 (AR)**：总收益除以销售量。
- **成本不变行业**：随着行业规模扩大，要素价格不变，导致长期平均成本曲线位置不变的行业。
- **帕累托效率**：指资源配置的一种状态，在此状态下，任何改变都不可能使至少一个人的境况变好而又不使任何人的境况变坏。

# Ch6: 不完全竞争市场
### 高频考点
1. **垄断**：一个卖方——众多的买方；一种商品（没有其他的替代品）；存在着进入壁垒。
2. **价格歧视**：企业以不同价格向不同顾客出售同一种物品的经营做法。
3. **纳什均衡**：在对手策略给定的情况下，每个参与者都选择了自己的最优策略。
### 其他考点
- **自然垄断**：规模经济导致一个行业只能存在一家企业。
- **卡特尔**：联合起来行事的企业集团（通过限制产量来提高价格）。
- **占优策略**：无论其他参与者选择什么，对一个参与者都最好的策略。
- **囚徒困境**：反映个人理性选择可能导致集体非理性结果的典型博弈。

# Ch7: 市场失灵和微观经济政策
### 高频考点
1. **私人物品 (Private Goods)** 既具有排他性又具有竞争性的物品。
2. **公共物品 (Public Goods)** 既不具有排他性也不具有竞争性的物品。
3. **公共资源 (Common Resources)** 具有竞争性但不具有排他性的物品。
4. **俱乐部物品 (Club Goods)** 具有排他性但不具有竞争性的物品（课件中也称为准公共物品）。
5. **市场失灵**：指市场机制不能有效发挥作用，难以实现帕累托效率的状况。
6. **外部性**：一个人的行为对旁观者的福利产生了影响，而他却不为此支付代价或得到补偿。
7. **科斯定理**：只要交易成本为零且产权界定清晰，无论产权归谁，市场机制都能实现资源的有效配置。
### 其他考点
- **公地悲剧**：由于公共资源被过度使用而导致枯竭的现象。
- **排他性**：可以阻止他人使用的特性。
- **竞争性**：一个人使用会减少他人使用的特性。
- **搭便车者**：得到一种物品的利益但避免为此付费的人。
- **寻租**：为获得垄断地位而进行的非生产性寻利活动。
