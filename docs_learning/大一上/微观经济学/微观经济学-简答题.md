# 第一组
### 1. 为什么边际报酬递减规律是短期成本曲线呈 U 形的原因？

- **答案要点**：
    
    - 短期内，技术水平和固定要素投入（如资本）不变，仅增加可变要素（如劳动）。
        
    - 根据**边际报酬递减规律**：起初随劳动增加，边际产量 $MP$ 上升（边际成本 $MC$ 下降）；但当劳动增加到一定程度后，$MP$ 开始下降。
        
    - 由于 $MC = w / MP$（其中 $w$ 为工资），当 $MP$ 递减时，$MC$ 必然递增。
        
    - $MC$ 的变动决定了平均可变成本 $AVC$ 和平均总成本 $AC$ 的走势，从而使它们呈现先降后升的 U 形。
        

### 2. 请解释“停止营业点”的逻辑。为什么厂商在亏损时仍可能生产？

- **答案要点**：
    
    - **定义**：停止营业点发生在价格 $P$ 等于平均可变成本最低点（$P = AVC_{min}$）。
        
    - **逻辑**：在短期内，固定成本 $FC$ 是即使不生产也必须支付的（如租金）。
        
    - 如果 $P > AVC$，虽然总收益不足以覆盖全部成本（亏损），但可以覆盖全部可变成本并偿还一部分固定成本。
        
    - **结论**：此时生产比不生产（净亏 $FC$）亏得更少。只有当 $P < AVC$ 时，生产反而会增加亏损，厂商才会选择关门。
        

### 3. 比较完全竞争和垄断竞争厂商的长期均衡。

- **答案要点**：
    
    - **相同点**：长期内厂商均可自由进出，故**经济利润均为零**（$P = AC$）。
        
    - **不同点**：
        
        1. **均衡位置**：完全竞争在 $AC$ 曲线最低点生产；垄断竞争在 $AC$ 曲线下降段生产。
            
        2. **效率对比**：完全竞争实现了生产效率（成本最低）；垄断竞争存在**过剩生产能力**（产量较低）。
            
        3. **价格关系**：完全竞争 $P = MC$；垄断竞争 $P > MC$（存在价格加成）。
            

### 4. 什么是三级价格歧视？其实施需要具备哪些条件？

- **答案要点**：
    
    - **定义**：垄断者对同一商品在不同的市场上（或针对不同的消费群体）收取不同的价格。
        
    - **实施条件**：
        
        1. 厂商必须具有一定的**市场权力**（垄断地位）。
            
        2. 厂商能够识别消费者的特征并成功**分割市场**（如老人、学生）。
            
        3. 不同市场间**无法转售**（套利），防止低价买入高价卖出。
            

### 5. 简述斯威齐模型（扭折需求曲线）如何解释价格刚性。

- **答案要点**：
    
    - **假设**：寡头厂商“跟跌不跟涨”。
        
    - **图形特征**：需求曲线在现行价格处发生扭折，导致边际收益曲线 $MR$ 出现一段**垂直缺口**。
        
    - **结论**：只要厂商的边际成本 $MC$ 在此缺口范围内变动，利润最大化的产量和价格（$MR=MC$ 的对应点）就不会改变，从而解释了价格的稳定性。
        

### 6. 什么是外部性？为什么负外部性会导致市场失灵？

- **答案要点**：
    
    - **外部性**：指一个经济主体的行为对他人福利产生了影响，且未在市场交易中得到补偿或支付。
        
    - **失灵原因**：在负外部性（如污染）下，**私人成本小于社会成本**。
        
    - 厂商仅根据私人成本决定产量，导致**实际产量高于社会最优产量**。
        
    - **结论**：市场机制无法自发实现资源的帕累托最优配置，需要政府干预（如征税或界定产权）。
    
# 第二组
### 1. 为什么需求曲线通常向右下方倾斜？请用收入效应和替代效应解释。

- **答案要点**：
    
    - **替代效应**：商品价格下降，相对于其他商品变得便宜，消费者会增加该商品消费。
        
    - **收入效应**：商品价格下降，消费者的实际购买力增强，从而增加消费。
        
    - **结论**：对于正常品，两种效应方向相同，总效应使需求量随价格下降而增加；对于低档品，虽然收入效应为负，但通常小于替代效应，总效应依然为正。因此需求曲线向右下方倾斜。
        

### 2. 简述规模经济（Economies of Scale）产生的原因。

- **答案要点**：
    
    - **分工与专业化**：大规模生产允许更细致的分工，提高劳动生产率。
        
    - **技术因素**：大型设备和自动化流水线在达到一定产量后，单位折旧更低。
        
    - **管理效率**：管理人员和职能部门在一定范围内可以服务于更多产出。
        
    - **要素购买优势**：大规模采购原材料往往能获得更低的折扣（议价能力）。
        

### 3. 什么是帕累托最优（Pareto Optimality）？实现帕累托最优需要满足哪些条件？

- **答案要点**：
    
    - **定义**：指资源配置的一种状态，在此状态下，任何改变都不可能使至少一个人的境况变好而又不使任何人的境况变坏。
        
    - **实现条件**：
        
        1. **交换最优**：任意两个消费者对任意两种商品的边际替代率相等（$MRS^A = MRS^B$）。
            
        2. **生产最优**：任意两个生产者对任意两种要素的边际技术替代率相等（$MRTS^X = MRTS^Y$）。
            
        3. **生产与交换最优**：商品的边际替代率等于其边际转换率（$MRS = MRT$）。
            

### 4. 比较完全竞争市场与完全垄断市场的长期均衡特征。

- **答案要点**：
    
    - **利润情况**：完全竞争厂商长期利润为零；垄断厂商通常能获得持久的超额利润。
        
    - **价格与成本**：完全竞争 $P = LMC = LAC$；垄断 $P > MC$ 且 $P > LAC$。
        
    - **效率**：完全竞争在 $LAC$ 最低点生产，资源配置效率最高；垄断存在无谓损失，产量低于社会最优水平。
        

### 5. 为什么说垄断竞争市场存在“过剩生产能力”？

- **答案要点**：
    
    - 由于产品差异，垄断竞争厂商面临的需求曲线向右下方倾斜。
        
    - 在长期均衡点，需求曲线 $d$ 与平均成本曲线 $AC$ 相切。
        
    - 由于 $d$ 线有负斜率，相切点必然位于 $AC$ 曲线最低点的左侧。
        
    - **结论**：实际产量小于平均成本最低点对应的有效产量，这种差距被称为“过剩生产能力”。
        

### 6. 什么是自然垄断（Natural Monopoly）？政府通常采取什么监管政策？

- **答案要点**：
    
    - **定义**：由于显著的规模经济，一家厂商生产全行业产量的成本低于多家厂商生产。常见于公用事业。
        
    - **监管政策**：
        
        1. **边际成本定价法 ($P=MC$)**：实现资源配置效率，但厂商会亏损，需政府补贴。
            
        2. **平均成本定价法 ($P=AC$)**：使厂商获得正常利润，盈亏平衡。
            
        3. **价格上限监管**：设定最高限价以激励厂商降低成本。
            

### 7. 简述科斯定理（Coase Theorem）的主要内容及其对解决外部性的意义。

- **答案要点**：
    
    - **内容**：只要财产权是明确的，并且交易成本为零（或很小），那么无论初始产权如何分配，市场主体的自愿协商都能达到资源的有效配置。
        
    - **意义**：它提供了一种非政府干预（如征税）解决外部性的思路。强调了产权界定在消除外部不经济中的核心作用。
        

### 8. 什么是“道德风险”（Moral Hazard）？它与“逆向选择”有何区别？

- **答案要点**：
    
    - **道德风险**：指交易达成后，信息优势方从事损害信息劣势方利益的行为（如买了保险后不再防火）。
        
    - **区别**：
        
        1. **发生时间**：逆向选择发生在交易前；道德风险发生在交易后。
            
        2. **信息类型**：逆向选择源于“隐藏信息”（产品质量）；道德风险源于“隐藏行为”（努力程度或谨慎程度）。
