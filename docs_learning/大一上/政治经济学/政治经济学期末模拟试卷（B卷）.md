# 模拟试卷（B卷）参考答案及评分标准

### 一、名词解释（20 分）

1. **生产关系**：人们在生产过程中形成的相互关系。狭义指直接生产过程中形成的经济关系（主要是生产资料所有制），广义指再生产过程中的经济关系。
2. **具体劳动**：是一定的具体形式的劳动，它生产商品的使用价值。
3. **可变资本**：是变为劳动力的那部分资本，在生产过程中能创造出大于自身价值的价值（剩余价值）。
4. **资本集中**：指几个资本结合成为一个较大的资本，从而形成个别资本规模的增大。
5. **级差地租**：与土地等级相联系的地租。由于土地肥沃程度、地理位置不同（或对同一土地连续追加投资产生的生产率不同），导致优等地的个别生产价格低于社会生产价格，由此产生的超额利润转化而成的地租。

### 二、单项选择题（15 分）

2. **B** （价值尺度衡量价值大小，只需要观念上的货币）

### 三、简答题（30 分）

1. **生产与消费的关系**：
   * **直接的同一性**：生产直接是消费（生产资料消费），消费直接是生产（劳动力再生产）。
   * **相互作用**：生产决定消费（提供对象和方式）；消费对生产有反作用（是生产的目的和动力）。

2. **绝对剩余价值与相对剩余价值**：
   * **绝对剩余价值**：在必要劳动时间不变的条件下，由于延长工作日的劳动时间而生产的剩余价值。
   * **相对剩余价值**：在工作日长度不变时，通过缩短必要劳动时间，相对延长剩余劳动时间而生产的剩余价值。
   * **区别**：前者靠延长工时，后者靠提高社会劳动生产率。

3. **货币的职能**：
   4. **价值尺度**：衡量其他一切商品价值大小。
   5. **流通手段**：充当商品交换媒介。
   6. **贮藏手段**：退出流通领域，作为社会财富代表被储藏。
   7. **支付手段**：清偿债务或支付赋税、租金、工资等。
   8. **世界货币**：在世界市场充当一般等价物。

### 四、计算题（15 分）

1. **计算流通所需货币量**：
   * 公式：需求量 = (价格总额 - 赊销额 + 到期支付额 - 抵消额) / 流通速度
   * 计算：(1000 - 100 + 200 - 100) / 5 = 1000 / 5 = **200（亿元）**

2. **经济现象分析**：
   * **现象**：通货膨胀（物价上涨）。
   * **理由**：实际发行量（300亿）超过了客观需要的货币量（200亿），导致纸币贬值。

3. **正反比关系**：
   * **正比**：商品价格总额、到期支付总额。
   * **反比**：赊销总额、互相抵消支付总额、货币流通速度。

### 五、论述题（20 分）

1. **剩余价值转化为利润**：当剩余价值被看作全部预付资本的增加额时，便取得了利润这个转化形式。
2. **平均利润的形成**：不同部门资本家通过竞争，使资本从利润率低的部门流向高的部门。这种资本转移引起供求变化和价格波动，最终使各部门利润率趋于平均，形成平均利润。
3. **生产价格的形成**：生产价格 = 生产成本 + 平均利润。
4. **关系论述**：生产价格以价值为基础。资本有机构成高的部门，生产价格高于价值；低的部门则低于价值。但全社会的生产价格总额等于价值总额。
