# 模拟试卷（C卷）参考答案及评分标准

### 一、名词解释（20 分）

1.  **相对剩余价值**
    * 在工作日长度不变的条件下，通过提高全社会劳动生产率，缩短必要劳动时间，从而相对延长剩余劳动时间所生产的剩余价值。
2.  **资本有机构成**
    * 由资本技术构成决定并反映技术构成变化的资本价值构成。通常用 $c:v$ 表示。
3.  **社会必要劳动时间**
    * 在现有的社会正常的生产条件下，在社会平均的劳动熟练程度和劳动强度下，制造某种使用价值所需要的劳动时间。
4.  **虚拟资本**
    * 指能定期带来收入的、以有价证券形式表现的资本形式（如股票、债券），其本身没有价值，是实体资本的纸制复本。
5.  **级差地租 II**
    * 指对同一块土地连续追加投资，由于各次投资的生产率不同而产生的超额利润转化成的地租。

### 二、单项选择题（15 分）

1.  **B**
    * *解析*：
        * 原状态：工作日 10h = 必要 4h + 剩余 6h。$m' = 6/4 = 150\%$。
        * 新状态：工作日 10h = 必要 2h + 剩余 8h。$m' = 8/2 = 400\%$。
        * 故从 150% 上升到 400%。
2.  **B**
    * *解析*：
        * 股票/债券价格 $\approx$ 股息(或利息) / 市场利率。
        * 原价格：$100 \times 5\% / 4\% = 125$ 元。
        * 新价格：$100 \times 5\% / 5\% = 100$ 元。
        * 价格下跌。
3.  **B**
    * *解析*：影响资本周转速度的因素包括生产时间和流通时间。机械制造企业通常劳动期间长（生产周期长），且固定资本占比高（周转慢），因此整体周转速度慢于轻工业。
4.  **D**
    * *解析*：扩大再生产的前提是 $I(v+m) > IIc$。如果 $I(v+m) < IIc$，说明第一部类生产出来的用于工人和资本家消费及积累的生产资料，甚至不够补偿第二部类消耗掉的生产资料，社会连简单再生产都无法维持，更谈不上扩大。
5.  **A**
    * *解析*：
        * 利润率 $p' = m / (c+v)$。
        * $m = v \times m' = 20 \times 100\% = 20$。
        * $p' = 20 / (80+20) = 20 / 100 = 20\%$。

### 三、简答题（30 分）

1.  **劳动力特殊性与剩余价值来源**
    * 劳动力的特殊性在于，它的使用价值就是**劳动**，而劳动本身是价值的源泉。
    * 劳动力的使用不仅能创造出补偿劳动力自身价值（工资）的新价值，还能创造出超过劳动力价值的余额。
    * 这个超过的部分就是**剩余价值**，被资本家无偿占有。

2.  **资本有机构成与相对过剩人口**
    * 资本有机构成 ($c:v$) 提高，意味着在总资本中，用于购买生产资料 ($c$) 的比例增大，用于购买劳动力 ($v$) 的比例相对减少。
    * 随着资本积累，虽然资本总量在增加，但对劳动力的需求是相对减少的（甚至绝对减少）。
    * 与此同时，劳动力供给却随着人口增长和技术排挤而增加，最终导致劳动力的供给超过资本对劳动力的需求，形成相对过剩人口。

3.  **固定资本与流动资本的区别及周转**
    * **区别**：固定资本（机器、厂房）是多次使用、价值逐次转移；流动资本（原料、劳动力）是一次性投入生产、价值一次性全部收回。
    * **周转速度**：流动资本在一年内通常可以周转多次，而固定资本往往需要数年甚至数十年才能完成一次价值周转。因此，流动资本占比越高，企业总资本的周转速度越快。

### 四、综合计算题（15 分）

1.  **计算年预付资本总周转次数 ($n$)**
    * 固定资本周转额 = $800 \div 10 = 80$ 万元。
    * 流动资本周转额 = $200 \times 5 = 1000$ 万元。
    * 年周转总价值 = $80 + 1000 = 1080$ 万元。
    * 预付资本总额 = $1000$ 万元。
    * $n = 1080 \div 1000 =$ **1.08 次/年**。

2.  **计算年剩余价值总量 ($M$)**
    * 首先确定可变资本 ($v$) 的量：
        * 预付总资本 1000 万，其中 $c:v = 9:1$。
        * 所以预付可变资本 $v = 1000 \times (1/10) = 100$ 万元。
    * 确定可变资本的周转次数 ($n'$):
        * 可变资本属于流动资本，题目已知流动资本周转 5 次，故 $n' = 5$。
    * 计算 $M$：
        * $M = m' \times v \times n' = 200\% \times 100 \times 5 =$ **1000 万元**。

3.  **计算年剩余价值率 ($M'$)**
    * $M' = m' \times n' = 200\% \times 5 =$ **1000%**。

### 五、论述题（20 分）

**答案要点：**

1.  **前提条件**：
    * 公式：$I(v+m) > IIc$。
    * 含义：第一部类（生产资料部门）向社会提供的生产资料，除了满足两大部类维持原有生产规模所需的损耗补偿（$Ic$ 和 $IIc$）外，还必须有剩余，才能满足两大部类进行追加投资（$\Delta c$）的需求。

2.  **实现条件（平衡公式）**：
    * 公式：$I(v + \Delta v + m/x) = II(c + \Delta c)$。
    * **$I(v + \Delta v + m/x)$** 代表：第一部类原有的工人（$v$）、新增的工人（$\Delta v$）以及资本家个人消费（$m/x$）对**消费资料**的总需求。
    * **$II(c + \Delta c)$** 代表：第二部类原有的生产资料消耗（$c$）和新增的生产资料需求（$\Delta c$）对**生产资料**的总需求。
    * **含义**：社会扩大再生产的核心问题是市场交换。第一部类对消费资料的需求，必须刚好等于第二部类对生产资料的需求，双方才能通过交换实现各自的产品价值，再生产才能顺利进行。

3.  **比例失调的影响**：
    * 如果比例关系被破坏（例如 $I > II$ 过多），会导致生产资料积压或消费资料短缺；反之则导致生产资料不足。这会引发社会再生产的中断，严重时引发**经济危机**（生产过剩或供给不足的危机）。
