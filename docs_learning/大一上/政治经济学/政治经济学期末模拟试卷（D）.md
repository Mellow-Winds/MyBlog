# 模拟试卷（D卷）参考答案及评分标准

### 一、名词解释（20 分）

1. **抽象劳动**：撇开具体形式的、无差别的一般人类劳动。它是形成商品价值的实体，体现了商品生产者之间的社会关系。
2. **绝对地租**：由于土地私有权的存在，租种任何土地（包括劣等地）都必须缴纳的地租。其来源是农业部门超额利润转化而成。
3. **年剩余价值率**：年剩余价值总量与预付可变资本的比率（$M/v$）。它表示预付可变资本在一年中的增殖程度。
4. **资本集中**：指已经形成的各个资本的合并，即把许多小资本合并成为大资本。它是通过竞争和信用两个强有力的杠杆来实现的。
5. **生产价格**：商品的生产成本与平均利润之和。它是价值的转化形式，是市场价格波动的中心。

### 二、单项选择题（15 分）

1. **C** （根据公式 $M = (P \times Q) / V$，分子分母同时扩大 1.2 倍，结果不变）
2. **B** （固定资本占比越低，流动资本占比越高，总周转速度越快）

### 三、简答题（30 分）

1. **剩余价值与利润的关系**：
   * **本质与现象**：剩余价值是利润的本质，利润是剩余价值的转化形式（表现为全部预付资本的产物）。
   * **观念区别**：剩余价值对应可变资本（$v$），利润对应全部资本（$c+v$）。
   * **数量区别**：社会总剩余价值等于总利润，但具体部门因有机构成不同，二者往往不一致。

2. **资本有机构成提高的动力与影响**：
   * **动力**：追求超额剩余价值的内在动力和应对竞争的外在压力，促使资本家改进技术、增加机器设备（$c$）投入。
   * **影响**：由于不变资本占比上升，可变资本占比下降，在剩余价值率不变的情况下，会导致社会平均利润率有下降的趋势。

3. **扩大再生产基本实现条件**：
   * **公式**：$I(v + \Delta v + m/x) = II(c + \Delta c)$。
   * **交换关系**：体现了第一部类对消费资料的需求与第二部类对生产资料的需求必须在量上相等，社会总产品的价值补偿和实物补偿才能实现。

### 四、计算题（15 分）

1. **各部门剩余价值与利润率**：
   * 甲部门：$v=20, m=20 \times 100\% = 20$, $p'=20/100 = 20\%$。
   * 乙部门：$v=40, m=40 \times 100\% = 40$, $p'=40/100 = 40\%$。
   * 丙部门：$v=60, m=60 \times 100\% = 60$, $p'=60/100 = 60\%$。

2. **全社会平均利润率**：
   * 社会总剩余价值 = $20+40+60 = 120$。
   * 社会总预付资本 = $100+100+100 = 300$。
   * 平均利润率 = $120 / 300 = \textbf{40\%}$。

3. **甲部门生产价格与偏差**：
   * 甲的平均利润 = $100 \times 40\% = 40$。
   * 甲的生产价格 = 成本(100) + 平均利润(40) = **140 亿元**。
   * **比较**：甲的价值为 120。生产价格高于价值。
   * **理由**：甲部门资本有机构成高于社会平均水平，在利润平均化过程中，分得的利润大于其自身创造的剩余价值。

### 五、论述题（20 分）

**逻辑要点**：
1. **资本积累**：资本家为获利和竞争进行积累，将剩余价值转化为资本。
2. **有机构成提高**：积累伴随技术进步，使不变资本（机器）增速超过可变资本（工人），$c:v$ 比例上升。
3. **劳动力供需矛盾**：资本对劳动力需求相对减少，而劳动力供给受人口和技术排挤增加。
4. **结论**：供过于求形成“相对过剩人口”。它是资本主义积累的产物，也是其进一步发展的必要条件（提供产业后备军）。
