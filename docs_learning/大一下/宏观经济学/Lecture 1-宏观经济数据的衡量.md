# 1. 名词解释与计算方式速查
## 1. 国民收入核算指标 (Lecture 1A)

- **支出法 GDP**: $GDP = C + I + G + NX$ 。
    
- **收入法 GDP**: $GDP = 劳动收入 + 资本收入 + 间接税净额 + 折旧$ 。
    
- **GNP 与 GDP 转换**: $GNP = GDP + NFP$（国外净要素支付）。
    
- **生产净值**: $NNP = GNP - 折旧$ ；$NDP = GDP - 折旧$ 。
    
- **国民收入 (NI)**: $NI = NNP - 统计歧视$ 。
    
- **要素收入 (NNFI/GNFI)**:
    
    - **NNFI (净国民要素收入)**: $NI - 非要素费用$（间接税、转移支付等）。
        
    - **GNFI (总国民要素收入)**: $GNFI = NNFI + 折旧$ 。
        
- **个人可支配收入 (DPI)**: $DPI = PI - 个人税收$ 。

## 2. 价格与数量指数 (Lecture 1B)

- **拉氏指数 (L)**: 以 **基期 ($0$)** 为权数。
    
    - $QI^L = \frac{\sum P_0 Q_t}{\sum P_0 Q_0}$ ；$PI^L = \frac{\sum P_t Q_0}{\sum P_0 Q_0}$ 。
        
- **帕氏指数 (P)**: 以 **报告期 ($t$)** 为权数。
    
    - $QI^P = \frac{\sum P_t Q_t}{\sum P_t Q_0}$ ；$PI^P = \frac{\sum P_t Q_t}{\sum P_0 Q_t}$ 。
        
- **费雪指数 (F)**: 拉氏与帕氏的几何平均数 $\sqrt{L \times P}$ 。
    
- **GDP 平减指数**: $\frac{名义 GDP}{实际 GDP} \times 100$ 。
    
- **通货膨胀率 ($\pi$)**: $\frac{P_t - P_{t-1}}{P_{t-1}} \times 100\%$ 。

## 3. 劳动力市场 (Lecture 1B)

- **劳动力 (L)**: $L = 就业 (E) + 失业 (U)$ 。
    
- **失业率 (u)**: $u = \frac{U}{L} \times 100\%$ 。
    
- **劳动参与率**: $\frac{L}{成年人口} \times 100\%$ 。

## 4. 三大恒等式 (Lecture 1A)

- **收入-支出**: $Y = C + I + G + NX$ 。
    
- **经常账户**: $CA = S - \tilde{I}$（$S$ 为国民储蓄，$\tilde{I}$ 为国民投资）。
    
- **储蓄-投资 (封闭经济)**: $S = \tilde{I}$ 。

## 5. 利息与贴现 (Lecture 1C)

- **复利与连续复利**:
    
    - 年复利: $V(t) = P(1+r)^t$ 。
        
    - 连续复利: $V(t) = Pe^{rt}$ 。
        
- **实际利率 ($r$)**:
    
    - 近似关系: $r \approx i - \pi$（名义利率 - 通胀率）。
        
    - 精确关系 (离散): $1 + r = \frac{1+i}{1+\pi}$ 。
        
- **现值 (PV)**:
    
    - 离散: $PV = \frac{FV}{(1+r)^t}$ 。
        
    - 连续: $PV = \int \pi(t) e^{-rt} dt$ 。
        
- **永续年金**: $V = \frac{\pi}{r}$ 。
# 2. 名词解释与计算方法详细说明
### 一、 产出与国民收入核算指标 (Lecture 1A)

#### 1. 国内生产总值 (GDP)

- **定义**：一个经济体在特定时期内生产的所有最终产品和劳务的市场价值 。
    
- **支出法**：$GDP = C + I + G + NX$ 。
    
    - **C (消费)**：居民购买的耐用品、非耐用品和劳务 。
        
    - **I (总私人国内投资)**：非住宅固定投资（厂房设备）、住宅固定投资和存货投资 。
        
    - **G (政府购买)**：政府在产品和劳务上的支出，不包括转移支付和利息支付 。
        
    - **NX (净出口)**：出口减去进口 。
        
- **收入法**：$GDP = 劳动收入 + 资本收入 + 间接税净额（间接税 - 补贴） + 折旧$ 。
    
- **生产法（增值法）**：各生产单位产出价值减去中间投入价值的总和 。
    

#### 2. 国民生产总值 (GNP)

- **定义**：一国常住居民在一定时期内获得的报酬总和 。
    
- **计算方法**：$GNP = GDP + NFP$ 。
- **计算方法2**：$GNP = GDP + 本国公民在国外的要素收入 - 外国公民在本国的要素收入$。
		其实也就是把NFP拆开。
	
    - **NFP (国外净要素支付)**：本国公民在国外的要素收入减去外国公民在本国的要素收入 。

#### 3. 生产净值指标 (NNP & NDP)

- **国民生产净值 (NNP)**：$GNP - 折旧$（固定资本消耗） 。
    
- **国内生产净值 (NDP)**：$GDP - 折旧$ 。
    

#### 4. 国民收入 (NI) 与 要素收入 (NNFI & GNFI)

- **国民收入 (NI)**：$NI = NNP - 统计误差$ 。在马工程观点中，它被定义为工资、利息、租金和利润的总和 。
    
- **净国民要素收入 (NNFI)**：$NNFI = NI - 非要素费用$ 。
    
    - **非要素费用**：包括间接营业税净额、企业转移支付、政府企业盈余 。
        
    - **要素费用构成**：$NNFI = 业主收入 + 个人租金收入 + 净利息 + 企业利润 + 雇员酬金$ 。
        
- **总国民要素收入 (GNFI)**：$GNFI = NNFI + 固定资本消耗（折旧）$ 。
    

#### 5. 个人收入与可支配收入 (PI & DPI)

- **个人收入 (PI)**：个人实际收到的各种收入 。
    
    - **计算公式1**：$PI = NI - (间接税 + 企业转移支付 + 政府企业盈余 + 净利息 + 企业利润 + 社会保险缴费) + (个人转移支付收入 + 个人利息收入 + 个人股利收入)$ 。
    - **计算公式2**：$PI = 所有进入个人口袋的钱 - 个人应缴的税$
        
- **个人可支配收入 (DPI)**：个人在履行纳税义务后可用于消费或储蓄的金额 。
    
    - **计算方法**：$DPI = PI - 个人当期税收支付$ 。


**Tips**：我们在计算公式2中减去了税收，但这和DPI减去的不是一样的。可以从表格中梳理：

|**环节**|**剥离的项目**|**逻辑**|**剩余的结果**|
|---|---|---|---|
|**第一关：从 GDP 到 NI**|间接税、折旧等|剥离**物品的溢价**和**机器的磨损**，剩下纯粹的生产报酬。|**国民收入 (NI)**|
|**第二关：从 NI 到 PI**|**社会保险缴费**、公司利润等|剥离**名义上赚了但根本没发到个人手里**的钱。|**个人收入 (PI)**|
|**第三关：从 PI 到 DPI**|**个人所得税**|剥离**已经发到你手里，但你必须上交给国家**的税收。|**可支配收入 (DPI)**|

### 二、 三个恒等式 (Lecture 1A)

1. **收入-支出恒等式**：$Y = C + I + G + NX$ 。
    
2. **经常账户恒等式**：$CA = S - \tilde{I}$ 。
    
    - 其中 $CA = NX + NFP$ 。（净出口和国外净要素支付）
        
    - $\tilde{I}$ 为国民投资（私人投资 + 政府资本购买 $G^I$） 。
        
    - 国民储蓄 $S = S^{Prv} + S^{Gov}$ 。
        
3. **储蓄-投资恒等式**：在封闭经济中（$CA=0$），则 $S = \tilde{I}$ 。

### 三、 价格与数量指数 (Lecture 1B)

#### 1. 指数 (Indexes)
1. 数量指数
	
	- **拉氏数量指数 ($QI^L$)**：以基期数量为权数，$QI^L_{t,0} = \frac{\sum P_{i0} Q_{it}}{\sum P_{i0} Q_{i0}} \times 100$ 。
	    
	- **帕氏数量指数 ($QI^P$)**：以报告期数量为权数，$QI^P_{t,0} = \frac{\sum P_{it} Q_{it}}{\sum P_{it} Q_{i0}} \times 100$ 。
	    
	- **费雪数量指数 ($QI^F$)**：拉氏与帕氏的几何平均，$QI^F_{t,t-1} = \sqrt{QI^L_{t,t-1} ·  QI^P_{t,t-1}}$ 。
	    
	- **链式加权实际 GDP**：$RGDP^F_{t,0} = (\sum P_{i0} Q_{i0}) \times \frac{QI^F_{t,0}}{100}$ 。
	
2. 价格指数
	
	- **拉氏价格指数 ($PI^L$)**：以基期数量为权数，$PI^L_{t,0} = \frac{\sum P_{it} Q_{i0}}{\sum P_{i0} Q_{i0}} \times 100$ 。
	    
	- **帕氏价格指数 ($PI^P$)**：以当期数量为权数，$PI^P_{t,0} = \frac{\sum P_{it} Q_{it}}{\sum P_{i0} Q_{it}} \times 100$ 。
		
	- 同样也有费雪指数和链式加权。不再赘述。
3. 一些核心指标：
	
	- **GDP 平减指数**：$\frac{名义 GDP_t}{实际 GDP_t} \times 100$ 。
	
	- **CPI (消费者价格指数)**：基于消费者固定篮子的价格水平 。
	
	- **PCE 平减指数**：$\frac{名义个人消费支出}{实际个人消费支出} \times 100$ 。
	
	- **PPI (生产者价格指数)**：衡量国内生产者收到的销售价格水平 。

思考：
- 如果是求“价格指数”，则拉和帕固定的是基期/当期数量。
- 如果是求“数量指数”，则拉和帕固定的是基期/当期价格。
- 总之，这个指标要固定什么，拉和帕就固定什么。
### 四、 劳动力市场 (Lecture 1B)

- **就业人数 (E)** 与 **失业人数 (U)**：失业者定义为没有工作但正在寻找工作的人 。
    
- **劳动力 (L)**：$L = E + U$ 。
    
- **失业率 (u)**：$u = \frac{U}{L} \times 100\%$ 。
    
- **劳动参与率**：$\frac{L}{总成年人口} \times 100\%$ 。
    
- **就业人口比**：$\frac{E}{总成年人口} \times 100\%$ 。

### 五、 利息与贴现 (Lecture 1C)

#### 1. 利息衡量

- **单利**：$V_S(t) = P(1 + rt)$ 。
    
- **年复利**：$V_C^1(t) = P(1 + r)^t$ 。
    
- **连续复利**：$V_C(t) = Pe^{rt}$ 。
    
- **增长率 (Growth Rate)**：
    
    - 离散情况：$\frac{x(t+1) - x(t)}{x(t)}$ 。
        
    - 连续情况：$\frac{\dot{x}}{x}$ 。
        

#### 2. 名义利率与实际利率

- **连续时间关系**：$r(t) = i(t) - \pi(t)$ 。
    
- **离散时间关系**：$1 + r_t = \frac{1 + i_t}{1 + \pi_{t+1}}$；近似为 $r_t \approx i_t - \pi_{t+1}$ 。
    

#### 3. 现值 (PV) 与资产定价

- **离散时间现值**：$V(0) = \sum_{t=1}^{\infty} \frac{\pi_t}{(1+r)^t}$；若现金流恒定为 $\pi$，则 $V(0) = \frac{\pi}{r}$ 。
    
- **连续时间现值**：$V(0) = \int_{0}^{\infty} \pi(t) e^{-rt} dt$；若现金流恒定，则 $V(0) = \frac{\pi}{r}$ 。
    
- **股票定价公式**：$P_t = \sum_{i=0}^{\infty} \beta^{i+1} d^e_{t+i}$，其中 $\beta = \frac{1}{1 + r_f + \alpha}$ 。



# 3. 常见的问题和解答
## 一、 三种方法计算GDP
以习题1.1为例，看看如何用三种方法计算GDP。提示：有的题目数据不全导致无法用某些方法。因此需要确认某方法可以使用。一旦有某些方法可以用，那么这些方法的结果必须相同。

纳尼亚（Narnia）由一家煤炭商、一家钢铁商和消费者组成（无政府） 。
1. **煤炭生产**：煤炭商生产了 1500 万吨煤，售价 \$5/吨 。
2. **钢铁生产**：钢铁商生产了 1000 万吨钢，售价 \$20/吨 。其生产过程中消耗了 2500 万吨煤（售价 \$5/吨），其中 **1500 万吨购自国内，1000 万吨来自进口** 。
3. **最终去向**：国内消费者购买了 800 万吨钢铁，另外 200 万吨用于出口 。
4. **收入分配**：钢铁商支付工人工资 \$4000 万；煤炭商支付工资 \$5000 万 。所有利润均分配给国内消费者 。
分别用**生产法**、**支出法**和**收入法**确定纳尼亚的 GDP 。
#### **1. 生产法 (Value Added Approach)**

核心逻辑：**GDP = 各部门增加值之和** 。（注意：直接看最终产品时，如果过程中涉及进口等操作，必须减去！）
- **煤炭商增加值**：产值 ($5 \times 15) = 75M$；中间投入为 0 。增加值 = 75M 。
- **钢铁商增加值**：产值 ($20 \times 10) = 200M$；中间投入为 25M吨煤 ($5 \times 25 = 125M$) 。增加值 = $200 - 125 = 75M$。
- **结果**：$GDP = 75 + 75 =$ **\$150M** 。
#### **2. 支出法 (Expenditure Approach)**
核心逻辑：**$GDP = C + I + G + (X - M)$** 。$X - M$也就是$NE$。
- **消费 (C)**：居民买钢支出 ($8 \times 20$) = **\$160M** 。
- **出口 (X)**：出口钢收入 ($2 \times 20$) = **\$40M** 。
- **进口 (M)**：进口煤支出 ($10 \times 5$) = **\$50M** 。
- **结果**：$GDP = 160 + 0 + 0 + (40 - 50) =$ **\$150M** 。
#### **3. 收入法 (Income Approach)**
核心逻辑：**GDP = 工资 + 利润** 。
- **工资**：$50 (\text{煤炭}) + 40 (\text{钢铁}) = \$90M$ 。
- **利润**：
    - 煤炭商：$75 (\text{营收}) - 50 (\text{工资}) = \$25M$ 。
    - 钢铁商：$200 (\text{营收}) - 125 (\text{煤炭成本}) - 40 (\text{工资}) = \$35M$ 。
- **结果**：$GDP = 90 + 25 + 35 =$ **\$150M** 。

## 二、计算其他指标
以习题1.1为例，分析如何计算。

**题目要求**：

纳尼亚国（Narnia）拥有以下宏观经济数据。假设不存在统计误差（Statistical discrepancy），且国外净要素支付（NFP）仅包含来自世界其他地区的劳动报酬。

要求计算：(a) GDP（支出法与收入法）；(b) GNP, NNP, NI；(c) GNFI, NNFI；(d) PI, DPI。

**数据表（单位：十亿美元）**：

| **编号** | **项目名称 (Item)**  | **数值** | **编号** | **项目名称 (Item)** | **数值**   |
| ------ | ---------------- | ------ | ------ | --------------- | -------- |
| **1**  | 个人消费支出 ($C$)     | 3000   | **11** | 公司利润 (国内)       | 1400     |
| **2**  | 国内私人总投资 ($I$)    | 2500   | **12** | 雇员报酬 (国内)       | 3000     |
| **3**  | 政府消费支出与总投资 ($G$) | 1000   | **13** | 固定资本消耗 (折旧)     | 200      |
| **4**  | 商品与服务净出口 ($NX$)  | 500    | **14** | 国外净要素支付 ($NFP$) | 100      |
| **5**  | 间接商业税减补贴         | 600    | **15** | 个人利息收入          | 800      |
| **6**  | 企业转移支付 (国内)      | 150    | **16** | 个人分红收入          | 1200     |
| **7**  | 政府企业当期盈余         | 50     | **17** | 个人当期转移支付收入      | 250      |
| **8**  | 业主收入 (国内)        | 300    | **18** | 政府社会保险缴费        | 350      |
| **9**  | 个人租金收入 (国内)      | 400    | **19** | **个人当期税收**      | **1000** |
| **10** | 净利息 (国内)         | 900    |        |                 |          |

#### (a) 计算 GDP = 7000

**1. 支出法 (Expenditure Approach)**

- **逻辑**：加总四个宏观部门的最终产品购买支出。
    
- **选入 Item**：
    
    - `1` 个人消费 ($C$) = 3000
        
    - `2` 私人总投资 ($I$) = 2500
        
    - `3` 政府支出 ($G$) = 1000
        
    - `4` 净出口 ($NX$) = 500
        
- **计算**：$3000 + 2500 + 1000 + 500 =$ **\$7000**
    

**2. 收入法 (Income Approach)**

- **逻辑**：$GDP = \text{国内要素纯收入} + \text{非要素费用} + \text{折旧}$。
    
- **选入 Item**：
    
    - **国内要素纯收入 (6000)**：劳动者赚的 `12` 雇员报酬(3000)；资本/土地赚的 `11` 公司利润(1400) + `8` 业主收入(300) + `9` 租金(400) + `10` 净利息(900)。
        
    - **非要素费用 (800)**：商品价格里没发给要素的钱，包括 `5` 间接税(600) + `6` 企业转移支付(150) + `7` 政府企业盈余(50)。
        
    - **折旧 (200)**：`13` 固定资本消耗(200)。
        
- **计算**：$6000 + 800 + 200 =$ **\$7000**

#### (b) 计算 GNP = 7100, NNP = NI = 6900

**1. 国民生产总值 (GNP)**

- **逻辑**：将核算边界从“国内”变为“国民”。
    
- **选入 Item**：加上 `14` 国外净要素支付（$NFP$）(100)。
    
- **计算**：$GNP = GDP(7000) + 100 =$ **\$7100**
    

**2. 国民净产值 (NNP)**

- **逻辑**：扣除机器设备的磨损。
    
- **选入 Item**：减去 `13` 折旧(200)。
    
- **计算**：$NNP = GNP(7100) - 200 =$ **\$6900**
    

**3. 国民收入 (NI) 

- **逻辑**：在现代美国经济分析局（BEA）的标准中，**国民收入 (NI) = NNP - 统计误差**。因为题目明确“无统计误差”，所以 NI 与 NNP 在数值上完全相等。现代 NI 中是**包含**间接税等非要素费用的！
    
- **计算**：$NI = NNP =$ **\$6900**

#### (c) 计算 GNFI = 6300, NNFI = 6100

这一问的出现，正是为了剥离 NI 中的非要素水分，还原纯粹的“要素报酬”。

**1. 净国民要素收入 (NNFI)**

- **逻辑**：NNFI 衡量的是一国国民提供劳动力和资本真正获得的纯收入。必须从 NI 中扣除那些“由于税收或记账原因产生，但没发给生产要素”的钱。
    
- **选入 Item**：从 NI 中减去非要素费用 `5` 间接税(600)、`6` 企业转移支付(150)、`7` 政府企业盈余(50)。
    
- **计算**：$NNFI = NI(6900) - 600 - 150 - 50 =$ **\$6100**
    
    _(验证：国内纯要素收入 6000 + NFP 100 = 6100，完全一致)_
    

**2. 总国民要素收入 (GNFI)**

- **逻辑**：在净要素收入基础上，把折旧加回来（Gross 代表含折旧）。
    
- **选入 Item**：加上 `13` 折旧(200)。
    
- **计算**：$GNFI = NNFI(6100) + 200 =$ **\$6300**
    

---

#### (d) 计算 PI = 5700, DPI = 4700

这是个人购买力核算的最后冲刺。我们以代表真实要素收入的 **NNFI (6100)** 为起点：

**1. 个人收入 (PI)**

- **逻辑**：$PI = NNFI - \text{赚了但没拿到手的钱} + \text{没赚但拿到手的钱}$。
    
- **选入 Item (减项)**：
    
    - 减 `11` 公司利润(1400)：留在公司，没直接发给个人。
        
    - 减 `10` 国内净利息(900)：企业间流转的利息，并非个人的真实利息收入。
        
    - 减 `18` 社保缴费(350)：还没发工资就被扣走的钱。
        
- **选入 Item (加项)**：
    
    - 加 `16` 个人分红(1200)：公司利润中真正以现金发给个人的部分。
        
    - 加 `15` 个人利息收入(800)：个人账户真正收到的利息（包含国债利息等）。
        
    - 加 `17` 转移支付(250)：政府给个人的无偿福利。
        
- **计算**：$PI = 6100 - 1400 - 900 - 350 + 1200 + 800 + 250 =$ **\$5700**
    

**2. 个人可支配收入 (DPI)**

- **逻辑**：从 PI 中扣除个人必须向政府缴纳的直接税，剩下就是完全可自由支配的钱。
    
- **选入 Item**：减 `19` 个人当期税收(1000)。
    
- **计算**：$DPI = PI(5700) - 1000 =$ **\$4700**
