Lecture 2A 的核心在于理解**长期中的经济运作逻辑**，即古典实体经济模型。其逻辑框架如下：

1. **生产与产出 (Production and Output)**
    - 新古典生产函数 (Neoclassical Production Function)
    - 规模报酬不变 (Constant Returns to Scale) 与欧拉定理
2. **要素市场与收入分配 (Factor Markets & Distribution)**
    - 劳动与资本的需求：由边际产量 (MPN, MPK) 决定
    - 实际工资与实际租金的确定
3. **充分就业 (Full Employment)**
    - 潜在产出 (Potential Output) 与自然失业率
    - 价格与工资的充分柔性假设
4. **可贷资金市场 (Loanable Funds Market)**
    - 储蓄与投资的恒等关系 (S = I)
    - 利率作为调节均衡的价格机制
5. **萨伊定律 (Say’s Law)**
    - “供给创造其自身的需求”及其理论意义
### 1. 导论
本章的研究视域限定在**长期 (Long Run)** 且**封闭 (Closed)** 的实体经济环境下。在这个世界里，价格具有充分的灵活性，能够迅速调整以使市场出清。

本章的学习应围绕以下三个核心命题展开：

- **价格柔性 (Price Flexibility)：** 市场中的工资和价格能自由波动，确保供需平衡。
    
- **货币中性 (Monetary Neutrality)：** 货币仅是遮盖实体经济的“面纱”，其变动不影响实际变量（即所谓的古典二分法）。
    
- **生产决定需求 (Supply Determines Demand)：** 产出的规模由生产能力决定，而非消费意愿。
### 2. 基础假设与变量界定

构建宏观模型如同剥洋葱。古典模型通过一系列简化假设，帮助我们剥离金融迷雾，直视经济运行的实体本质。这些假设看似“脱离现实”，实则是为了聚焦核心逻辑。

根据课程设定，我们采取以下基础假设 (Assumption 1)：

$$GI = 0, NFP = 0, TR = 0, INTG = 0$$
也即
$$政府投资 = 国外净要素支付 = 转移支付 = 政府债务利息 = 0$$
这些公式背后的经济学含义包括：

- **GDP = GNP = Y：** 假设净要素支付 (NFP) 为零，意味着我们忽略了跨国劳动力和资本的收入流动，使分析聚焦于国内生产。
    
- **$Y_{Dis} = Y - T$：** 假设转移支付 (TR) 和政府利息支出 (INTG) 为零，使得个人可支配收入直接简化为总产出扣除税收。
    
- **$G = G_C$ 且 $\tilde{I} = I$：** 简化了政府购买和投资的构成。
    

> **解析 (So What?):** 在本封闭经济模型中，我们通过这些假设有意忽略了国际资本流动，旨在孤立出国内生产、储蓄与实际利率之间的核心关联。这有助于初学者理解，真正的国民财富增长最终取决于“生产了什么”，而非资产的跨期转移或外部盈余。

### 3. 新古典生产函数 (Neoclassical Production Function)

生产函数是古典模型的“心脏”，它描述了经济体如何将投入（资本与劳动）转化为总供给。其通用形式为 $Y = F(K, N, A)$。一个标准的新古典生产函数必须具备以下三个关键性质：

1. **规模报酬不变 (Constant Returns to Scale, CRS)：**
    
    - 定义：$F(\lambda K, \lambda N, A) = \lambda \cdot F(K, N, A)$。
        
    - 经济意义：这是一个一阶齐次函数。如果将资本和劳动同时增加一倍，产出也将精准增加一倍。这保证了生产规模不会因无限扩张或收缩导致市场崩溃。
        
2. **边际报酬递减 (Positive and Diminishing Returns)：**
    
    - 数学表达为 $F_K' > 0, F_N' > 0$ 但 $F_{KK}'' < 0, F_{NN}'' < 0$。即在其他投入不变时，每增加一单位资本 (K) 或劳动 (N)，带来的**额外产出**是下降的。
        
3. **稻田条件 (Inada Conditions)：**
    
    - 当投入趋于 0 时，边际产出趋于无穷大；当投入趋于无穷时，边际产出趋于 0。这确保了均衡点始终存在于坐标系的内部解中。
        

在此基础上，**欧拉定理 (Euler's Theorem)** 扮演了连接生产与分配的桥梁作用：
对等式 $F(\lambda K, \lambda N) = \lambda F(K, N)$ 的两边关于 $\lambda$ 求偏导。
- **左边（链式法则）：**
$$\frac{\partial F(\lambda K, \lambda N)}{\partial (\lambda K)} \cdot \frac{\partial (\lambda K)}{\partial \lambda} + \frac{\partial F(\lambda K, \lambda N)}{\partial (\lambda N)} \cdot \frac{\partial (\lambda N)}{\partial \lambda}$$
$$F_1(\lambda K, \lambda N) \cdot K + F_2(\lambda K, \lambda N) \cdot N$$
- **右边：**
$$\frac{d (\lambda F(K, N))}{d \lambda} = F(K, N)$$
为了回归到初始的生产规模，令 $\lambda = 1$。此时：
- $F_1(K, N)$ 即为资本的边际产出 **MPK**。
- $F_2(K, N)$ 即为劳动的边际产出 **MPN**。
将这些代入上述求导后的等式：

$$MPK \cdot K + MPN \cdot N = F(K, N)$$

由于 $F(K, N) = Y$，我们得到最终公式：

$$Y = MPN \times N + MPK \times K$$

这意味着在 CRS 条件下，总产出刚好等于劳动的报酬加上资本的报酬。换言之，产出的“蛋糕”在长期中会被各个生产要素刚好分配完毕。

### 4. 要素市场：劳动与资本的需求与定价

在古典模型中，要素市场是资源配置的“信号灯”。要素的价格——**实际工资 (W/P)** 和 **实际租金 (R/P)**——由市场的供需共同决定。

厂商的名义利润（$\Pi$）等于总收益减去总成本。在只有劳动和资本两种要素的情况下，公式为：

$$\Pi = P \cdot F(K, N) - (W \cdot N + R \cdot K)$$

其中：

- $P$：产品价格
    
- $W$：名义工资
    
- $R$：名义资本租金
    
- $F(K, N)$：生产函数（总产出 $Y$）
    

为了推导实际变量，我们将等式两边同时除以价格 $P$，得到**实际利润**函数：

$$\frac{\Pi}{P} = F(K, N) - \left( \frac{W}{P} \cdot N + \frac{R}{P} \cdot K \right)$$

为了找到使利润最大的要素投入量，我们需要分别对劳动 $N$ 和资本 $K$ 求偏导数，并令其等于 $0$。
#### (1) 对劳动 $N$ 求偏导：

$$\frac{\partial (\Pi/P)}{\partial N} = \frac{\partial F(K, N)}{\partial N} - \frac{W}{P} = 0$$

由于 $\frac{\partial F}{\partial N}$ 的经济学定义即为劳动的边际产量（**MPN**），整理得：

$$MPN = \frac{W}{P}$$

#### (2) 对资本 $K$ 求偏导：

$$\frac{\partial (\Pi/P)}{\partial K} = \frac{\partial F(K, N)}{\partial K} - \frac{R}{P} = 0$$

由于 $\frac{\partial F}{\partial K}$ 的经济学定义即为资本的边际产量（**MPK**），整理得：

$$MPK = \frac{R}{P}$$
由此得到厂商利益最大化的条件是：
- **一阶导数条件：** $MPN = W/P$ 且 $MPK = R/P$。
    
- **逻辑驱动：** 由于边际报酬递减，要素的边际产出随着投入增加而下降，因此要素需求曲线必然向下倾斜。
    

**对比分析：名义与实际变量的区隔**

|**概念**|**定义**|**古典模型中的地位**|**理论依据**|
|---|---|---|---|
|**名义工资 (W)**|以货币单位计量的报酬|“面纱”，受价格水平 P 波动影响|古典二分法：名义变量不影响实际经济。|
|**实际工资 (W/P)**|货币工资购买商品和劳务的能力|核心信号。厂商和工人仅关注其真实购买力。|价格柔性：确保市场通过 W/P 的调整实现出清。|

通过名义工资和物价的完全灵活调整，要素价格 (W/P 和 R/P) 作为调节阀，确保劳动力市场始终处于**充分就业 (Full Employment)** 状态，不存在非自愿失业。

### 5. 国民收入的分配：谁拿走了蛋糕？

基于欧拉定理和完全竞争假设，国民收入的分配呈现出一种“完美”的数学结构。根据 Source Context，我们需要明确产出的流向：

- **总产出的构成：** $Output\ Y = MPN \times N + MPK \times K = \text{劳动收入} + \text{资本收入} + \text{资本折旧}$
    
    - 这里必须注意：资本的报酬 ($MPK \times K$) 不仅包含资本家的净租金回报，还包含了维持生产能力所需的资本折旧。
        
- **经济利润为零：** 当厂商按边际贡献支付报酬时：$\text{Economic Profit} = P \times Y - W \times N - R \times K = 0$
    

> **深度评价：** “要素按边际贡献取酬”是西方理论认为分配具有公平性的基石。然而，当产出被要素领走后，逻辑随之转入下一步：这些收入是如何被使用的？从分配到支出的跨越，引导我们进入可贷资金市场。

### 6. 可贷资金市场：利率的调节艺术

如果说生产函数决定了“蛋糕”的大小，那么可贷资金市场则连接了实体生产与跨期消费决策。人们在获得分配后的收入后，必须在当前消费与未来储蓄之间做出选择。

**核心均衡等式：**

- **国民储蓄 (S)：** $S = (Y - T - C) + (T - G)$。它由私人储蓄与政府储蓄组成。
    
- **均衡条件：** $S = I(r)$。即储蓄供给等于投资需求。
    

**案例分析：英国战争开支与利率变动**

根据 Robert J. Barro (1987) 对 1730-1919 年间英国历史数据的研究：在八次战争期间，英国国防开支 (G) 显著激增。根据等式，在产出 (Y) 受生产函数约束而给定的长期环境下，政府购买 (G) 的增加导致政府储蓄 (T-G) 骤减，从而使国民储蓄 (S) 曲线左移。这一变动推高了**实际利率 (r)**，并由于投资对利率敏感而“挤出”了私人投资 (I)。这生动地证明了利率作为内生价格，如何确保总支出始终等于总产出。

### 7. 萨伊定律与宏观均衡：供给决定论

古典宏观经济学的灵魂是 **萨伊定律 (Say's Law)**。核心逻辑为：“供给创造其自身的需求”。

- **机制：** 生产过程在创造产品的同时，也产生了等值的报酬。这些收入（工资、租金、利润）必然通过消费或储蓄（经由利率转化为投资）重新回到产品市场。
    
- **充分就业产出：** 既然需求总是能自动匹配供给，那么限制经济增长的唯一因素就是生产要素的数量和技术水平。因此，经济始终运行在由供给方确定的潜在产出 (Potential Output) 水平上。
