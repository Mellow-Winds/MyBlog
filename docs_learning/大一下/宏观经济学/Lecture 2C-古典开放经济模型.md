### 一、 课程大纲框架

本次课程主要分为四个核心板块 ：

1. **汇率与平价理论 (Exchange Rates)**：名义与实际汇率的定义、一价定律、购买力平价 (PPP)、净出口函数、无抛补利率平价及核心模型假设。
    
2. **小型开放经济模型 (Small Home vs. Large Foreign)**：当本国作为价格接受者时，商品市场、可贷资金市场与外汇市场的均衡及政策冲击分析。
    
3. **大型开放经济模型 (Large Home vs. Large Foreign)**：当本国体量足以影响世界利率时，全球均衡的决定机制及政策溢出效应。
### 二、 核心概念与从0到1的推导

#### 1. 名义汇率与实际汇率

- **名义汇率 ($e$)**：用外币表示的本币价格 。
    
    - **间接标价法 (应收标价法)**：马工程教材采用此法，即以1单位本国货币为基准，计算能兑换多少单位外国货币 。在这种标价法下，$e$ 上升代表本币升值，外币贬值 。
        
- **实际汇率 ($\epsilon$)**：用外国商品表示的本国商品的价格 。
    
    - **计算公式**：$\epsilon = e \times \frac {P}{P^*}$，其中 $P$ 为本国价格水平，$P^*$ 为外国价格水平 。
        
    - **经济学直觉**：实际汇率衡量的是两国商品的**相对竞争力**。如果 $\epsilon$ 很高，说明本国商品相对昂贵，外国商品相对便宜 。
        

#### 2. 三大平价理论

- **一价定律 (The Law of One Price)**：如果市场完全竞争且不存在摩擦（如运输成本、关税），同一种商品在不同地区用同一种货币折算后，价格必须完全相同 。
    
- **购买力平价 (Purchasing Power Parity, PPP)**：
    
    - **绝对购买力平价**：基于一价定律，实际汇率 $\epsilon$ 应该等于1 。由此可得名义汇率 $e = P^* / P$ 。
        
    - **相对购买力平价**：转化为增长率形式，名义汇率的变动率等于两国通货膨胀率之差：$\frac{\dot{e}}{e} = \frac{\dot{P}^*}{P^*} - \frac{\dot{P}}{P}$ 。
        
- **无抛补利率平价 (Uncovered Interest Parity, UIP)**：
    
    - 在资本完全流动的前提下，外汇市场均衡要求投资国内和国外的预期收益率相等 。
        
    - **实际利率平价公式**：$1 + r_t = (1 + r_t^*) \frac{\epsilon_t}{\mathbb{E}_t \epsilon_{t+1}}$ 。其中 $r_t$ 是本国实际利率，$r_t^*$ 是外国实际利率，$\mathbb{E}_t \epsilon_{t+1}$ 是预期的未来实际汇率 。
        

#### 3. 净出口函数与核心假设

- **净出口函数 ($NX$)**：由于实际汇率 $\epsilon$ 升高意味着本国商品变贵，该国必然会增加进口、减少出口 。因此，净出口是实际汇率的减函数：$NX = NX(\epsilon)$，且 $NX'(\epsilon) < 0$ 。
    
- **模型的三大核心假设** ：
    
    1. **资本完全流动 (Perfect Capital Mobility, PCM)**：本国居民可以无障碍地进入世界金融市场 。
        
    2. **静态预期 (Static Expectations)**：预期未来的实际汇率等于当前的实际汇率，即 $\mathbb{E}_t \epsilon_{t+1} = \epsilon_t$ 。
        
    3. **购买力平价不总是成立**：允许实际汇率 $\epsilon$ 偏离1 。
        

> **0到1的关键推导**：将假设2（静态预期 $\mathbb{E}_t \epsilon_{t+1} = \epsilon_t$）代入实际利率平价公式 $1 + r_t = (1 + r_t^*) \frac{\epsilon_t}{\mathbb{E}_t \epsilon_{t+1}}$ 中，等式右侧的汇率比值变为1，我们瞬间得出一个极其重要的结论：$r = r^*$ 。即本国利率必然等于世界利率！

### 三、 核心模型一：小型开放经济模型 (Small Open Economy)

**情境定义**：本国是世界市场的一小部分，其净资本流动对世界利率的影响微乎其微。因此，世界利率 $r^*$ 对本国而言是**外生给定**的 。

#### 1. 市场的均衡条件

- **商品与服务市场**：$\overline{Y} = C(\overline{Y} - \overline{T}) + I(r^*) + \overline{G} + NX(\epsilon)$ 。在这里，产出 $\overline{Y}$、消费、投资 $I(r^*)$ 和政府购买 $\overline{G}$ 都是固定的。唯一能变动的内生变量是实际汇率 $\epsilon$，它通过调节净出口 $NX(\epsilon)$ 来确保等式两边平衡 。
    
- **可贷资金市场**：储蓄 $\overline{S} = I(r^*) + NX(\epsilon)$ 。将其移项得到 $\overline{S} - I(r^*) = NX(\epsilon)$ 。
    
    - $\overline{S} - I(r^*)$ 被称为**净国外投资 (Net Foreign Investment, NFI)**，代表国内储蓄满足国内投资后的剩余资金 。
        
- **外汇市场**：$\overline{S} - I(r^*) = NX(\epsilon)$ 。
    
    - 左侧 $\overline{S} - I(r^*)$ 代表**本币的供给**（国内多余的资金要兑换成外币去国外投资） 。
        
    - 右侧 $NX(\epsilon)$ 代表**本币的需求**（外国人需要兑换本币来购买我们的净出口商品） 。
        

#### 2. 几何图解与政策冲击分析：本国储蓄下降 (A Reduction in Home's Saving)

假设政府增加财政赤字或国内消费激增，导致国内总储蓄 $\overline{S}$ 减少。

- **可贷资金市场**：垂直的储蓄曲线 $\overline{S}$ 向左移动。由于 $r^*$ 不变，国内投资 $I(r^*)$ 保持不变。储蓄萎缩导致净国外投资缩小（$NFI$ 下降） 。
    
- **外汇市场**：垂直的本币供给曲线（即 NFI）向左移动 。
    
- **最终结果**：本币供给减少，导致实际汇率 $\epsilon$ 从 $\epsilon_0$ 上升至 $\epsilon_1$（本国货币实际升值） 。实际汇率上升削弱了出口竞争力，导致净出口 $NX$ 顺着需求曲线下滑，贸易收支恶化 。

### 四、 核心模型二：大型开放经济模型 (Large Open Economy)

**情境定义**：本国体量庞大，其储蓄或投资的变动会显著影响世界利率 。我们可以将世界看作由“大型本国 (Large Home)”和“大型外国 (Large Foreign)”组成的**封闭系统** 。

#### 1. 全球均衡机制

- **世界利率的决定**：既然世界总体是封闭的，那么世界总储蓄必定等于世界总投资，即 $\overline{S}^W = \overline{S}^H + \overline{S}^F = I^H(r) + I^F(r) = I^W(r)$ 。这决定了内生的世界利率 $r_0$ 。
    
- **资金流转**：在全球均衡利率下，本国可能出现储蓄大于投资 $\overline{S}^H > I^H(r)$，从而有正的净国外投资 ($NFI^H > 0$) 。由于世界闭合，本国流出的资金必定等于外国流入的资金，因此 $NX(\epsilon) + NX^*(1/\epsilon) \equiv 0$ 。
    

#### 2. 政策冲击分析：大型本国储蓄下降 (A Reduction in Home's Saving)

- **全球可贷资金市场**：本国储蓄 $\overline{S}^H$ 减少，导致世界总储蓄 $\overline{S}^W$ 垂直线向左移动。由于全球资金变少，**世界利率必定从 $r_0^*$ 上升至 $r_1^*$** 。
    
- **对本国 (Home) 的影响**：虽然利率上升会抑制国内投资 $I^H$，但本国储蓄 $\overline{S}^H$ 下降的幅度更大，因此本国的资金流出量减小，即 $NFI^H$ 下降 。在外汇市场上，本币供给减少，促使实际汇率从 $\epsilon_0^H$ 升值到 $\epsilon_1^H$，净出口 $NX$ 随之恶化 。
    
- **对外国 (Foreign) 的溢出效应**：外国并没有调整自身的储蓄 $\overline{S}^F$ ，但全球利率的上升增加了他们的资金借贷成本，导致外国投资 $I^F$ 被挤出而下降 。储蓄不变、投资下降，使得外国多余的资金增加，即 $NFI^F$ 上升 。这表现为外国货币贬值，其净出口改善。
    

> **小结对比**：小型开放经济体的政策只影响自己（汇率和贸易）；而大型开放经济体的政策不仅影响自己，还会通过**抬高或压低世界利率**，对其他国家的投资和贸易产生强烈的溢出效应。
