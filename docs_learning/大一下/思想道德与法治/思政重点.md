## 一、考试总体说明与考场要求
### 1. 成绩占比
- 期末闭卷考试成绩占比60%-70%。
- 整体卷面发挥好按70%折算，发挥一般按60%折算，比例灵活调整。
### 2. 考试题型与时长
- 题型：单选题10道、简答题5道、论述题4道。
- 考试时长：2小时，答题时间非常充足。
### 3. 答题规范要求
- 简答、论述大题不能只写一句话，需要适当展开论述，结合知识点举例作答。
- 可运用黄旭华、袁隆平、宋文聪等人物案例辅助答题。
## 二、第一单元 人生观章节重点
### 1. 人的本质（P14-15）
- 马克思经典论断：**人的本质不是单个人所固有的抽象物，在其现实性上，它是一切社会关系的总和。**
- 核心考点：社会属性是人的本质属性，人的社会关系的总和决定人的本质。
- 认知要求：认识人的本质，必须立足于具体的、历史的社会关系中从事社会实践的人；不能从抽象人性论出发，也不能依靠神的启示。

### 2. 个人与社会的辩证关系（P15）
- 整体关系：个人与社会之间是对立统一的关系，两者互相依存、互相制约、互相促进。
- 根本关系：个人与社会**最根本的是个人利益与社会利益的关系**。二者有机统一、相互制约。

### 3. 人生观构成（P17）
- 三大内容：对**人生目的、人生态度、人生价值**等问题的根本看法
- 核心考点：
	- **人生目的是人生观的核心**
	- 人生目的回答人为什么活着的根本问题，指导人生实践

### 4. 人生价值内涵（P18）
- 定义：人的生命及其实践活动对于社会和个人所具有的作用和意义。
- 两大组成：人生价值内在地包含了**自我价值、社会价值**两个方面。
	1. 自我价值：个人人生活动对自身生存和发展所具有的价值。
	2. 社会价值：个体实践活动对社会、他人所具有的价值。
- 二者关系：相互区别、相互依存。
	  1. **自我价值是个体生存和发展的必要条件**，人生自我价值的实现是个体为社会创造更大价值的前提。
	  2. **社会价值是社会存在和发展的重要条件**，人生社会价值的实现是个体自我完善、全面发展的保障。

### 5. 人生价值评价标准（P27）
- 根本尺度：看一个人的实践活动是否符合社会发展的客观规律，是否促进了历史的进步。
- 具体评价维度：
	  1. 既要看贡献的大小，也要看尽力的程度；
	  2. 既要尊重物质贡献，也要尊重精神贡献；
	  3. 既要注重社会贡献，也要注重自身的完善。

## 三、第二单元 理想与信念章节重点
### 1. 理想的内涵与特点（P43-44）
- 内涵：理想是人们在实践中形成的、有实现可能性的、对未来社会和自身发展目标的向往与追求，是世界观、人生观和价值观在奋斗目标上的集中体现。
- 特点：**超越性、实践性、时代性。**

### 2. 信念的内涵与特点(P45-46)
- 内涵：信念是人们在一定认识基础上确立的对某种思想或者事物坚信不疑并身体力行的精神状态。
- 特点：**执着性、支撑性、多样性。**
### 3. 理想和信念的四大作用（P47-49）
1. **昭示奋斗目标**
2. **催生前进动力**
3. **提供精神支柱**
4. **提高精神境界**
- 答题可结合黄旭华、袁隆平、宋文聪等人物实例。

### 4. 理想与现实的辩证关系(P62)
- 整体属性：对立统一关系。
- 理想受现实的规定和制约，是在对现实认识的基础上不断发展。
- 双向关系：
  1. 现实包含着理想的因素，孕育着理想的发展；
  2. 理想中包含着现实，既包含现实中必然发展的因素，又包含由理想转化为现实的条件。
  3. 在一定条件下，理想就可以转化为未来的现实。

### 5. 理想的实现（P63）
- 三大特性：**长期性、艰巨性、曲折性**。
- 重要条件：**艰苦奋斗是实现理想的重要条件**。
- 答题要点（AI总结）：理想的实现是一个循序渐进的过程，不可能一蹴而就、一帆风顺；要正确看待顺境与逆境，做好攻坚克难的思想准备，自觉砥砺奋斗品格，可结合民族发展案例论述。

## 六、第五单元 道德章节重点
### 1. 道德的定义（P138）
道德是一种特殊的社会意识形态，它是以善恶为基本评价标准，主要依靠社会舆论、传统习俗和内心信念来发挥作用的行为规范总和。

### 2. 马克思主义之前道德起源四种学说（P139）
1. **天意神启论**：将道德起源归于上天意志或神灵启示；
2. **先天人性论**：把道德归为人与生俱来的善良本性或先天良知；
3. **情感欲望论**：认为道德起源于人的情感与自然欲望；
4. **动物本能论**：将人类道德等同于动物群居本能的自然延续。

### 3. 马克思主义道德起源三大条件（P140）
1. **劳动**是道德起源的**首要前提**；（劳动将人与动物区分开来，创造了人、社会、社会关系，也创造了道德）
2. **社会关系**是道德产生的**客观条件**；
3. **人的自我意识**是道德形成的**主观条件**。

### 4. 道德的本质（P141）
马克思主义道德理论在人类思想史上第一次科学而全面地论述了道德的起源问题，强调道德属于上层建筑的范畴，是一种特殊的社会意识形态，为正确认识和理解道德本质奠定了基础。

1. 道德是**反映社会经济关系**的特殊意识形态；
2. 道德是**调节社会利益关系**的特殊规范方式；
3. 道德是一种**实践精神**。

### 5. 道德三大基本功能（P142）
道德的功能，一般是指道德作为社会意识的特殊形式对于社会发展所具有的功效与作用。

最基本的功能是：
1. **认识**功能：反映社会关系（特别是经济关系）的功效与能力；
2. **规范**功能：道德在正确善恶观的指引下，规范社会成员在社会公共领域、职业领域、家庭领域的行为，并规范个人品德养成，引导并促进人们崇德向善。
3. **调节**功能：道德通过评价等方式，指导和纠正人们的行为和实践活动，协调社会关系和人际关系的功效与能力。

### 6. 社会主义道德核心与原则（P146）
- **核心：坚持以为人民服务为核心**
- **原则：坚持以集体主义为原则**

### 7. 吸收和借鉴优秀道德成果（P152）
中华传统美德基本精神
1. **重视整体利益，强调责任奉献**
2. **推崇仁爱原则，注重以和为贵**
3. **注重人伦关系，重视道德义务**
4. **追求精神境界，向往理想人格**
5. **强调道德修养，注重道德践履**

### 8. 中华传统美德的创造性转化和创新性发展（P156）
- 中华民族的道德传统是一个矛盾体，具有鲜明的两重性。
- 中华传统美德是中国传统道德的精华部分。
- **加强对中华传统美德的挖掘和阐发**。把带有阶级和时代局限性的成分剔除出去，把其中具有当代价值的道德精神发掘出来。
- **用中华传统美德滋养社会主义道德建设**。要结合时代要求，按照：

	- 是否有利于建设社会主义道德体系，
	- 是否有利于培育和践行社会主义核心价值观的标准。

### 9. 新时代道德实践四大方面（P165） 
- **遵守社会公德**：社会公德是社会公共生活中应当遵循的行为准则，在维护社会公共秩序方面具有重要作用。
- **恪守职业道德**：职业生活中的道德规范不仅对各行各业的从业者具有引导和约束作用，而且也是促进社会持续、健康、有序发展的必要条件。爱岗敬业、诚实守信、办事公道、热情服务和奉献社会是职业生活中的基本道德规范。
- **弘扬家庭美德**：家庭美德以尊老爱幼、男女平等、夫妻和睦、勤俭持家、邻里互助等为主要内容。
- **锤炼个人品德**：中国古代思想家提出五种道德修养方法：**学思并重、省察克治、慎独自律、知行合一、积善成德。**

## 七、第六单元 法律章节考试重点
#### 1.  **正当防卫成立的条件**
1. **起因**条件：不法侵害现实存在；
2. **时间**条件：不法侵害行为正在进行；
3. **主观**条件：为了使国家、公共利益、本人或者他人的人身、财产和其他权利免受不法侵害；
4. **对象**条件：针对不法侵害者本人；
5. **限度**条件：正当防卫不能超过必要限度，造成重大损害。

#### 2. **简述我国刑法的基本原则并具体进行解释**
1. **罪刑法定原则**：法律明文规定为犯罪行为的，依照法律定罪处刑；法律没有明文规定为犯罪行为的，不得定罪处刑。
2. **适用法律一律平等原则**：对任何人犯罪，在适用法律上一律平等。不允许任何人有超越法律的特权。
3. **罪刑相适应原则**：刑罚的轻重，应当与犯罪分子所犯罪行和承担的刑事责任相适应。

#### 3. **简述我国刑罚的基本措施**
1. **主刑**：管制、拘役、有期徒刑、无期徒刑、死刑；
2. **附加刑**：罚金、剥夺政治权利、没收财产、驱逐出境。

#### 4. **简述犯罪客体的含义并举例说明**
**犯罪客体是指我国刑法所保护，而为犯罪行为所危害的社会关系。**
比如甲通过实施犯罪行为将乙打成重伤，甲的犯罪客体就是乙的生命权、健康权等人身权利。
