
#### 遍历时删除的正确写法

```java
// ✅ 正确：倒序删除
for (int i = list.size() - 1; i >= 0; i--) {
    if (list.get(i).equals("Apple")) {
        list.remove(i);
    }
}

// ✅ 正确：迭代器删除
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    if (it.next().equals("Apple")) {
        it.remove();
    }

// ❌ 错误：增强 for 中删除
```

# 3. ArrayDeque（双端队列）

#### 1. 创建 ArrayDeque

```java
ArrayDeque<Integer> deque = new ArrayDeque<>();
ArrayDeque<String> dequeWithCapacity = new ArrayDeque<>(20);
```

#### 2. 作为栈使用（后进先出）

```java
deque.push(1);      // 压栈
deque.push(2);
int top = deque.pop();      // 弹出栈顶 → 2
int peek = deque.peek();    // 查看栈顶不弹出 → 1
```

#### 3. 作为队列使用（先进先出）

```java
deque.offer(1);     // 入队尾部
deque.offer(2);
int front = deque.poll();   // 出队头部 → 1
int head = deque.peek();    // 查看头部不弹出 → 2
```

#### 4. 双端操作

```java
// 头部操作
deque.addFirst(1);      // 头部添加（如果设定容量并且满了会抛异常）
deque.offerFirst(2);    // 头部添加（返回 false）
deque.removeFirst();    // 删除头部（抛异常）
deque.pollFirst();      // 删除头部（返回 null）
deque.getFirst();       // 获取头部（抛异常）
deque.peekFirst();      // 获取头部（返回 null）

// 尾部操作（方法对称）
deque.addLast(1);
deque.offerLast(2);
deque.removeLast();
deque.pollLast();
deque.getLast();
deque.peekLast();
```

#### 5. 常用方法汇总表

| 操作 | 队列方法 | 栈方法 | 双端方法 | 抛出异常 | 返回 null/false |
|------|----------|--------|----------|----------|-----------------|
| 插入 | `offer(e)` | `push(e)` | `offerFirst/Last(e)` | `addFirst/Last(e)` | `offerFirst/Last(e)` |
| 删除 | `poll()` | `pop()` | `pollFirst/Last()` | `removeFirst/Last()` | `pollFirst/Last()` |
| 获取 | `peek()` | `peek()` | `peekFirst/Last()` | `getFirst/Last()` | `peekFirst/Last()` |

#### 6. 遍历

```java
// 正向遍历
for (int x : deque) {
    System.out.println(x);
}

// 迭代器
Iterator<Integer> it = deque.iterator();
while (it.hasNext()) {
    System.out.println(it.next());
}

// 反向遍历
Iterator<Integer> descIt = deque.descendingIterator();
while (descIt.hasNext()) {
    System.out.println(descIt.next());
}
```

#### 1. 左右指针（对撞指针）

```java

    // 根据条件移动 left 或 right
```

#### 2. 快慢指针

```java

        fast++;
```

```java

    }
}
```

# 5. 单调队列模式

#### 1. 什么是单调队列

```java
// 队列中的元素始终保持单调递增或单调递减
// 常用双端队列（ArrayDeque）实现
// 典型应用：滑动窗口最大值
```

#### 2. 单调队列核心思想

```java
// 维护一个单调递减队列，队首始终是当前窗口的最大值
// 添加元素时：从队尾移除所有比当前元素小的元素
// 移除元素时：如果队首是窗口左边界的元素，则移出
```

#### 3. 手动实现单调队列（双端队列）

```java
class MonotonicQueue {
    private ArrayDeque<Integer> deque = new ArrayDeque<>();
    
    // 添加元素
    public void push(int n) {
        while (!deque.isEmpty() && deque.getLast() < n) {
            deque.removeLast();
        }
        deque.addLast(n);
    }
    
    // 获取最大值
    public int max() {
        return deque.getFirst();
    }
    
    // 移除元素（如果队首是要删除的值）
    public void pop(int n) {
        if (!deque.isEmpty() && deque.getFirst() == n) {
            deque.removeFirst();
        }
    }
}
```

#### 4. 典型应用：滑动窗口最大值

```java
// 题目：给定数组 nums 和窗口大小 k，返回每个窗口的最大值
// 例如：nums = [1,3,-1,-3,5,3,6,7], k = 3
// 返回：[3,3,5,5,6,7]
```

#### 5. 代码框架（滑动窗口最大值）

```java
public int[] maxSlidingWindow(int[] nums, int k) {
    if (nums == null || nums.length == 0) return new int[0];
    
    int n = nums.length;
    int[] result = new int[n - k + 1];
    ArrayDeque<Integer> deque = new ArrayDeque<>();  // 存储索引
    
    for (int i = 0; i < n; i++) {
        // 移除窗口外的元素（队首索引超出窗口）
        if (!deque.isEmpty() && deque.peekFirst() < i - k + 1) {
            deque.pollFirst();
        }
        
        // 移除队尾所有小于当前元素的值（保持单调递减）
        while (!deque.isEmpty() && nums[deque.peekLast()] < nums[i]) {
            deque.pollLast();
        }
        
        // 当前元素入队
        deque.offerLast(i);
        
        // 窗口形成后，记录最大值（队首）
        if (i >= k - 1) {
            result[i - k + 1] = nums[deque.peekFirst()];
        }
    }
    
    return result;
}
```

#### 5. StringBuilder vs StringBuffer vs String

| 特性 | String | StringBuilder | StringBuffer |
|------|--------|---------------|---------------|
| 可变性 | 不可变 | 可变 | 可变 |
| 线程安全 | 安全（不可变天然安全） | 不安全 | 安全（方法加锁） |
| 性能 | 拼接时最差 | 最好 | 较好 |
| 使用场景 | 少量操作/常量 | 单线程大量拼接 | 多线程大量拼接 |

```java
// String 拼接（每次产生新对象，性能差）
String s = "";
for (int i = 0; i < 1000; i++) {
    s += i;  // 不推荐
}

// StringBuilder 拼接（推荐）
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append(i);
}

// StringBuffer 拼接（多线程环境）
StringBuffer sbf = new StringBuffer();
synchronized (lock) {
    sbf.append("data");
}
```

#### 6. 扩容机制

```java
// StringBuilder 扩容规则
// 当前容量 = 16（默认）或指定值
// 需要容量 = 当前 length + 追加内容长度
// 新容量 = max(需要容量, 当前容量 * 2 + 2)
// 最终通过 Arrays.copyOf() 扩容

StringBuilder sb = new StringBuilder();  // 容量 16
sb.append("12345678901234567");          // 长度 17，触发扩容
// 新容量 = max(17, 16*2+2=34) = 34
```

#### 7. 性能优化建议

```java
// 1. 预估容量，避免多次扩容
StringBuilder sb = new StringBuilder(1000);

// 2. 链式调用
sb.append("a").append("b").append("c");

// 3. 避免在循环中使用 + 拼接字符串
// ❌ 错误
String s = "";
for (int i = 0; i < 1000; i++) {
    s += i;  // 隐式创建 StringBuilder 再 toString
}

// ✅ 正确
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append(i);
}
```


# 7. HashMap、HashSet、TreeMap

| 流派  | 核心接口      | 具体实现类                | 底层结构       | 核心特质         | 时间复杂度    |
| --- | --------- | -------------------- | ---------- | ------------ | -------- |
| 散列派 | Map / Set | `HashMap`, `HashSet` | 哈希表        | 无序、唯一、O(1)存取 | O(1)     |
| 树形派 | Map / Set | `TreeMap`, `TreeSet` | 红黑树        | 自动排序、极值查询    | O(log n) |
| 链表派 | Map       | `LinkedHashMap`      | 哈希表 + 双向链表 | 保持插入顺序       | O(1)     |

### 链表流派 (Linked Family)

#### LinkedHashMap：记录插入顺序

```java
Map<String, Integer> map = new LinkedHashMap<>();

map.put("Apple", 10);
map.put("Cherry", 30);

// 遍历顺序 = 插入顺序：Banana → Apple → Cherry

    System.out.println(entry.getKey());
}

// 实现 LRU 缓存（最近最少使用）
class LRUCache<K, V> extends LinkedHashMap<K, V> {
    private final int maxSize;
    
    public LRUCache(int maxSize) {
        // accessOrder = true：按访问顺序排序
        super(maxSize, 0.75f, true);
        this.maxSize = maxSize;
    }
    
    @Override
    protected boolean removeEldestEntry(Map.Entry<K, V> eldest) {
        return size() > maxSize;  // 超过容量则删除最旧的
    }
}
```

# 8. 文件 IO（BufferedReader / BufferedWriter + NIO）

### 核心原理

```java
// 装饰器模式：为底层流添加缓冲区，减少磁盘 IO 次数
// 字符流：专门处理文本文件

// 传统方式
BufferedReader br = new BufferedReader(new FileReader("input.txt"));

// NIO 方式（推荐，更简洁）
BufferedReader br = Files.newBufferedReader(Paths.get("input.txt"));
```

---

### 构造方法

```java
// ========== 传统方式 ==========
BufferedReader br = new BufferedReader(new FileReader("file.txt"));
BufferedWriter bw = new BufferedWriter(new FileWriter("file.txt"));

// 指定缓冲区大小
BufferedReader br = new BufferedReader(new FileReader("file.txt"), 16384);

// 追加模式
BufferedWriter bw = new BufferedWriter(new FileWriter("file.txt", true));

// ========== NIO 方式（推荐）==========
// 默认 UTF-8 编码
BufferedReader br = Files.newBufferedReader(Paths.get("file.txt"));
BufferedWriter bw = Files.newBufferedWriter(Paths.get("output.txt"));

// 指定编码
BufferedReader br = Files.newBufferedReader(Paths.get("file.txt"), StandardCharsets.UTF_8);

// 追加模式
BufferedWriter bw = Files.newBufferedWriter(
    Paths.get("log.txt"),
    StandardCharsets.UTF_8,
    StandardOpenOption.APPEND
);
```

---

### BufferedReader 核心方法

```java
// 读取一行（不包含换行符）→ 到达末尾返回 null
String line = br.readLine();

// 读取单个字符 → 返回 int（-1 表示末尾）
int ch = br.read();

// 读取到字符数组
char[] buf = new char[1024];
int len = br.read(buf);  // 返回实际读取字符数

// 跳过 n 个字符
br.skip(100);

// 标记与重置（需先调用 markSupported() 确认支持）
br.mark(100);   // 标记当前位置，参数为读取限制
br.reset();     // 回到标记位置

// 关闭流（自动 flush）
br.close();
```

---

### BufferedWriter 核心方法

```java
// 写入字符串
bw.write("Hello World");

// 写入字符数组
char[] chars = {'H', 'i'};
bw.write(chars);

// 写入单个字符
bw.write('A');

// 换行（写入系统换行符，跨平台）
bw.newLine();

// 强制刷新缓冲区（将数据真正写入磁盘）
bw.flush();

// 关闭流（自动先 flush）
bw.close();
```

### 标准读写模板

```java
// ========== 按行读取并写入 ==========
try (BufferedReader br = Files.newBufferedReader(Paths.get("input.txt"));
     BufferedWriter bw = Files.newBufferedWriter(Paths.get("output.txt"))) {
    
    String line;
    while ((line = br.readLine()) != null) {
        // 处理每一行
        bw.write(line);
        bw.newLine();  // 写入换行符
    }
    
} catch (IOException e) {
    e.printStackTrace();
}
// try-with-resources 自动关闭，无需手动 close
```
