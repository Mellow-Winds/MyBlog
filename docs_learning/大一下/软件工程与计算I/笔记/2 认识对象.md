# 1. 类和对象
类是创建对象的模板。
```java
class students{  
    int height;  
    String name;  
}
```
写好了类以后，创建对象就有了模板。

然后就可以建立对象并存储对象的一些变量。
```java
class StudentsTest{  
    public static void main(String[] args){  
        students stu1 = new students();  
        stu1.name = "MellowWinds";  
    }  
}
```
# 2 对象的声明、创建、赋值
 ```java
 students stu1 = new students();
 ```
 先声明一个引用变量（`students`）并命名为`stu1`，再创建对象`students`，最后使用`=`连接。
