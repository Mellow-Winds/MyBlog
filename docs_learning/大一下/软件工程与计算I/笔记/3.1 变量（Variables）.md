# 1. 变量的分类
可以分为两种：基本主类型(Primitive Variable)，引用变量(Reference Variable)
# 2. 8种`primitive`类型

| 类型        | 大小      | 值域（范围）               | 示例声明                     |
| --------- | ------- | -------------------- | ------------------------ |
| `byte`    | 8 bit   | −128 ~ 127           | `byte a = 10;`           |
| `short`   | 16 bit  | −32,768 ~ 32,767     | `short b = 1000;`        |
| `int`     | 32 bit  | −2³¹ ~ 2³¹−1（≈ ±21亿） | `int c = 100000;`        |
| `long`    | 64 bit  | −2⁶³ ~ 2⁶³−1         | `long d = 10000000000L;` |
| `float`   | 32 bit  | ±1.4E−45 ~ ±3.4E38   | `float e = 3.14f;`       |
| `double`  | 64 bit  | ±4.9E−324 ~ ±1.8E308 | `double f = 3.14159;`    |
| `char`    | 16 bit  | 0 ~ 65535（Unicode编码） | `char g = 'A';`          |
| `boolean` | JVM实现相关 | `true` / `false`     | `boolean h = true;`      |
- `int` 是 **默认整数类型**
- `double` 是 **默认浮点类型**（后面讲）
- `char` 本质是 **无符号整数（Unicode编码）**
## 2.1 隐含展开（Implicit Widening）
Java 数字`long`和`float`需要后缀：

| 类型       | 后缀       |
| -------- | -------- |
| `long`   | `L`      |
| `float`  | `f`      |
```java
long a = 10000000000L;  
float b = 3.14f;  
double c = 3.14;
```

可是，为什么呢？为什么一定要这么写呢？
可以理解为，Java的类型有一定的规则：`byte → short → int → long → float → double`
小范围可以自动扩大，但是大范围无法手动缩小。任何 **向右转换** 都允许自动发生。
例如：
```java
double x = 10;   // int → double  
float y = 10;    // int → float  
long z = 10;     // int → long
```
危险转换（必须强制）：
```java
double → float  
long → int  
int → short
```

必须写：
```java
float f = (float)3.14;
float f = 3.14f;
```

譬如：
```java
int a = 10;        // OK
long b = 10;       // OK (int → long 自动)
byte c = a;        // 不OK
float d = 3;       // OK (int → float)
float e = 3.14;    // ❌ double → float 不允许
```
如何纠正？使用强制类型转换以替换之。譬如：
```java
byte c = (byte) a;
float e = 3.14f;
```

# 3. 引用变量（Reference Variable）
## 3.1 什么是引用变量
**引用变量**是一种 **存储“对象地址”的变量**。  它本身不保存对象的数据，而是 **指向对象在内存中的位置**。引用变量不包含对象，但可以 **访问对象的数据和方法**。primitive 变量存“值”，reference 变量存“地址”。
```java
int a = 10;  
String s = "hi";
```  
在内存中是这样的：
```java
a = 10  
s ───→ "hi" (heap)
```
## 3.2 引用变量赋值（重要）
```java
students stu1 = new students();
stu1.age = 18;
students stu2 = new students();
stu2.age = 18;
students stu3 = stu1;
```
内存中：
```java
stu1 ──┐
       ├──→ students object A
stu3 ──┘         age = 18

stu2 ─────→ students object B
               age = 18
```
- `stu1` 和 `stu3` **指向同一个对象**，`stu1`和`stu2`指向不同对象
- 修改对象会影响所有引用
这也就解释了为什么对于b的修改也会作用于a。
# 3. 其他
## 3.1 变量修饰符`final`
`final` 作为一种 **修饰符（modifier）**，可以作用在 **primitive 变量** 或 **reference 变量** 上。
- **primitive 类型**：作用后无法改变值。类似于`const`
```java
final int x = 10;
x = 20;  // ❌ 编译错误
```
- **reference 类型**：作用后无法重新引用除此以外的其余事物。但是可以改变对象的内容（如果对象可以更改的话）。
```java
final StringBuilder sb = new StringBuilder("hi");
sb.append("!");  // ✅ 可以修改对象内容
sb = new StringBuilder("bye"); // ❌ 不能改变引用指向
```
## 3.2 `var`和变量推测
在 Java 中，`var` 是 **一个局部变量类型推断关键字**，它的作用是让编译器根据右边的值 **自动推导出变量类型**。理解它可以更清楚地看到 **类型、引用和 primitive** 的关系。
```java
var x = 10;           // 编译器推断 x 是 int
var s = "hello";      // 编译器推断 s 是 String
var list = new ArrayList<String>(); // 编译器推断 list 是 ArrayList<String>
```
特点：
- **必须初始化**，编译器才能推断类型
- 一旦推断出来，类型就是固定的，**不是动态类型**
- 仅适用于 **局部变量**，不能用于字段、方法参数或返回值

## 3.3 `Integer`和`int`

### 1️⃣ 基本区别

| 特性      | int             | Integer                            |
| ------- | --------------- | ---------------------------------- |
| 类型      | 基本类型（primitive） | 引用类型（对象）                           |
| 存储      | 栈上存值            | 栈上存引用，堆上存值                         |
| 方法      | 无               | 有（如 `intValue()`, `compareTo()` 等） |
| 泛型      | ❌ 不能用           | ✔ 可以用，如 `ArrayList<Integer>`       |
| 自动装箱/拆箱 | —               | 可以自动装箱/拆箱与 int 互转                  |

---

### 2️⃣ 自动装箱和拆箱

```java
int x = 10;
Integer y = x;   // 自动装箱：int → Integer
int z = y;       // 自动拆箱：Integer → int
```
- **装箱**：基本类型 → 包装类对象
- **拆箱**：包装类对象 → 基本类型
### 3️⃣ `Integer` 的缓存机制（关键点）
Java 对 **-128 到 127** 的整数做了 **Integer 缓存**，即：
- 当你创建 `Integer` 对象时，如果值在 `[-128, 127] `范围内，JVM 会复用已有对象
- 超出这个范围，会创建新的对象
示例：

```java
Integer i1 = 127;
Integer i2 = 127;
System.out.println(i1 == i2); // true（引用相同）

Integer i3 = 128;
Integer i4 = 128;
System.out.println(i3 == i4); // false（引用不同）
```
✅ 原理说明：
- `i1` 和 `i2` 指向同一个缓存对象
- `i3` 和 `i4` 超出缓存范围，分别指向堆上不同的对象
- 注意：用 `==` 比较 **Integer 对象** 比较的是 **引用地址**
- 如果想比较值，应该用 `i3.equals(i4)` 或拆箱 `i3.intValue() == i4.intValue()`
### 4️⃣ 注意事项

1. **引用比较与值比较**

```java
Integer a = 1000;  
Integer b = 1000;  
System.out.println(a == b);        // false  
System.out.println(a.equals(b));   // true
```

- `==` → 比较引用（地址）
- `.equals()` → 比较对象里的值
2. **泛型中必须用包装类**
    
    ```java
    ArrayList<Integer> list = new ArrayList<>();
    list.add(5); // 自动装箱为 Integer 对象
    ```
