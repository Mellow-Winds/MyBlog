# 大作业 Project 02 — Lexer（词法分析器）  
  
## 背景  
  
在解析程序的终极目的上，我们想要得到的是程序的语法结构。但在最开始时，我们所拥有的只是一个字符串，如 `(+ 1 2)`。想要分析这个表达式的结构，首先需要把字符串切分成有意义的词法单元（Token），这就是**词法分析**。  
  
例如，`(+ 1 2)` 经词法分析得到：  
```  
左括号  符号(+)  整数(1)  整数(2)  右括号  
```  
  
本次作业在 Project 01 REPL 的基础上，实现词法分析器的核心逻辑，以及两个扩展功能。

## Token 类型规范  
  
| Token 类型 | 示例 | 正则描述 |  
|-----------|------|---------|  
| **整数** | `5`、`-42`、`007` | `^-?[0-9]+$` |  
| **字符串** | `"hello"`、`"a\"b"` | `^"(?:[^"\\]|\\[\\"])*"$` |  
| **左括号** | `(` | — |  
| **右括号** | `)` | — |  
| **符号** | `+`、`foo`、`let*`、`default-queue-size` | `^(?!-?[0-9]+)[^"() ]+$` |  
  
解析规则均为**贪心匹配**，即尽可能长地匹配每个 Token。

## CharLookaheadStream 说明  
  
`CharLookaheadStream` 提供三个方法：  
  
| 方法                   | 说明                 |     |
| -------------------- | ------------------ | --- |
| `input.eof()`        | 流是否已到达结尾           |     |
| `input.consume()`    | 读取并消耗下一个字符（位置向后移动） |     |
| `input.lookahead(1)` | 预览下一个字符，不消耗（不移动位置） |     |

package edu.nju.software.token;  
  
import edu.nju.software.stream.CharLookaheadStream;  
import org.apache.commons.text.StringEscapeUtils;  
  
import java.util.ArrayList;  
  
public class Lexer {  
  
    private static boolean isSpecialCharacter(char c) {  
        return c == '(' || c == ')' || c == '"' || Character.isWhitespace(c);  
    }  
  
    /**  
     * 词法分析：将字符流解析为 Token 列表。  
     *  
     * TODO: YOUR CODE HERE  
     *  
     * 实现步骤提示：  
     *   1. 循环读取字符，跳过空白字符  
     *   2. 遇到 '(' → 加入 LeftParen.create()  
     *   3. 遇到 ')' → 加入 RightParen.create()  
     *   4. 遇到 '"' → 继续读取直到遇到未转义的 '"'，处理 \\ 和 \" 转义，  
     *      用 StringEscapeUtils.unescapeJava() 处理转义序列，加入 StringToken.create(...)  
     *   5. 遇到数字或负号+数字 → 贪心读取所有数字字符，加入 IntegerToken.create(...)  
     *   6. 其他字符 → 贪心读取直到遇到特殊字符，加入 SymbolToken.create(...)  
     *     * 可用工具：  
     *   - input.eof()          判断流是否结束  
     *   - input.consume()      读取并消耗下一个字符  
     *   - input.lookahead(1)   预览下一个字符（不消耗）  
     *   - Character.isWhitespace(c)  判断空白  
     *   - Character.isDigit(c)       判断数字  
     *   - Integer.parseInt(str)      字符串转整数  
     *   - StringBuilder              逐字符构建字符串  
     *   - isSpecialCharacter(c)      判断是否为特殊字符（已实现）  
     *  
     * 注意：需要在 pom.xml 中添加 commons-text 依赖后才能使用 StringEscapeUtils  
     */    public static ArrayList<Token> lex(CharLookaheadStream input) {  
        ArrayList<Token> tokens = new ArrayList<>();  
        while(!input.eof()){  
            char c = input.lookahead(1);  
            //1.跳过空白字符  
            if(Character.isWhitespace(c)){  
                input.consume();  
                continue;  
            }  
            //2. 遇到 '(' → 加入 LeftParen.create()            else if (c == '('){  
                tokens.add(LeftParen.create());  
                input.consume();  
            }  
            //3. 遇到 ')' → 加入 RightParen.create()            else if (c == ')'){  
                tokens.add(RightParen.create());  
                input.consume();  
            }  
            //4. 遇到 '"' → 继续读取直到遇到未转义的 '"'，处理 \\ 和 \" 转义  
            else if (c == '"') {  
                input.consume(); // 吃掉开头的 "                StringBuilder sb = new StringBuilder();  
  
                while (!input.eof()) {  
                    char ch = input.consume();  
  
                    if (ch == '"') {  
                        break; // 遇到结尾引号  
                    }  
  
                    if (ch == '\\') {  
                        if (!input.eof()) {  
                            char next = input.consume();  
                            sb.append('\\').append(next); // 原样加，后续 unescape                        }  
                    } else {  
                        sb.append(ch);  
                    }  
                }  
  
                String value = StringEscapeUtils.unescapeJava(sb.toString());  
                tokens.add(StringToken.create(value));  
            }  
            //5. 遇到数字或负号+数字 → 贪心读取所有数字字符，加入 IntegerToken.create(...)            else if (Character.isDigit(c) || (c == '-' && Character.isDigit(input.lookahead(2)))) {  
                StringBuilder sb = new StringBuilder();  
                // 处理负号  
                if (c == '-') {  
                    sb.append(input.consume()); // 吃掉 '-'                }  
                while (!input.eof() && Character.isDigit(input.lookahead(1))) {  
                    sb.append(input.consume());  
                }  
                // 转换并加入 token                int value = Integer.parseInt(sb.toString());  
                tokens.add(IntegerToken.create(value));  
            }  
            //6. 其他字符 → 贪心读取直到遇到特殊字符，加入 SymbolToken.create(...)            else {  
                StringBuilder sb = new StringBuilder();  
  
                while (!input.eof() && !isSpecialCharacter(input.lookahead(1))) {  
                    sb.append(input.consume());  
                }  
                tokens.add(SymbolToken.create(sb.toString()));  
            }  
        }  
        return tokens;  
    }  
  
    /**  
     * 扩展 1：统计 Token 列表中各类型的数量。  
     * 返回格式：`整数:N 符号:N 字符串:N 左括号:N 右括号:N`  
     *     * TODO: YOUR CODE HERE  
     *

     *   - 遍历 tokens，用 instanceof 判断每个 Token 的类型  
     *   - 维护五个计数器：integers, symbols, strings, leftParens, rightParens  
     *   - 返回格式严格按照：`整数:N 符号:N 字符串:N 左括号:N 右括号:N`  
     */    public static String countTokens(ArrayList<Token> tokens) {  
        // TODO: YOUR CODE HERE  
        int integers = 0, symbols=0, strings=0, leftParens=0, rightParens=0;  
        for (Token t : tokens) {  
            if (t instanceof IntegerToken) {  
                integers++;  
            } else if (t instanceof SymbolToken) {  
                symbols++;  
            } else if (t instanceof StringToken) {  
                strings++;  
            } else if (t instanceof LeftParen) {  
                leftParens++;  
            } else if (t instanceof RightParen) {  
                rightParens++;  
            }  
        }  
        return "整数:" + integers + " 符号:" + symbols + " 字符串:" + strings  
                + " 左括号:" + leftParens + " 右括号:" + rightParens;  
    }  
  
    /**  
     * 扩展 2：将 Token 列表转换回字符串形式，Token 之间用空格分隔。  
     * IntegerToken → 数字字符串；StringToken → "value"；SymbolToken → 符号名；  
     * LeftParen → "("；RightParen → ")"  
     *     * 示例：[LeftParen, SymbolToken(+), IntegerToken(1), IntegerToken(2), RightParen]  
     *       → "( + 1 2 )"     *     * TODO: YOUR CODE HERE  
     *  
     * 提示：  
     *   - 使用 StringBuilder 拼接结果  
     *   - Token 之间用单个空格分隔（第一个 token 前无空格）  
     *   - 访问 IntegerToken 的值：((IntegerToken) t).value  
     *   - 访问 StringToken 的值：((StringToken) t).value  
     *   - 访问 SymbolToken 的名字：((SymbolToken) t).name  
     */    public static String tokensToString(ArrayList<Token> tokens) {  
        StringBuilder sb = new StringBuilder();  
        boolean first = true;  
        for (Token t : tokens) {  
            if (!first) sb.append(' ');  
            if (t instanceof IntegerToken) {  
                sb.append(((IntegerToken) t).value);  
            } else if (t instanceof SymbolToken) {  
                sb.append(((SymbolToken) t).name);  
            } else if (t instanceof StringToken) {  
                sb.append("\"").append(((StringToken) t).value).append("\"");  
            } else if (t instanceof LeftParen) {  
                sb.append('(');  
            } else if (t instanceof RightParen) {  
                sb.append(')');  
            }  
            first = false;  
        }  
        return sb.toString();  
    }  
}

# 笔记
## 1. Lexer 实现流程
1. 跳过空白字符。
2. 遇到 `'('` → `LeftParen.create()`。
3. 遇到 `')'` → `RightParen.create()`。
4. 遇到字符串（`"` 开头）：
    - 贪心读取直到未转义的 `"`。
    - 处理转义字符 `\\`、`\"`。
    - 使用 `StringEscapeUtils.unescapeJava()`。
    - 构造 `StringToken.create(value)`。
5. 遇到数字或负号+数字：
    - 贪心读取连续数字。
    - 处理负号。
    - 构造 `IntegerToken.create(value)`。
6. 其他字符 → 贪心读取直到遇到特殊字符 → `SymbolToken.create(value)`。
### 1.1 细节处理和我碰到的问题
1. **没有正确消耗字符（consume）**
    
    - 问题：在处理 `(`、`)` 或字符串开头的 `"` 时，如果只看了字符但没有调用 `input.consume()`，下一个循环会重复读取同一个字符，导致死循环或错误 token。
        
    - 解决：每次确认当前字符属于某种 token 类型后，立即用 `input.consume()` 吃掉它，再继续处理后续字符。例如处理 `'('` 时：
        
        ```java
        if (c == '(') {
            tokens.add(LeftParen.create());
            input.consume(); // 必须吃掉 '('
        }
        ```
        
2. **负号处理不当**
    
    - 问题：直接遇到 `-` 就认为是负数，可能出现 `-abc` 这种情况，导致 `Integer.parseInt("-a")` 报错。
        
    - 解决：遇到 `-` 时，需要先检查后面紧跟的字符是否是数字：
        
        ```java
        else if (Character.isDigit(c) || (c == '-' && 
        Character.isDigit(input.lookahead(2)))) {
            // 只有 '-' 后面是数字，才当作负号
        }
        ```
        
3. **数字贪心读取逻辑**
    
    - 问题：只读取一次数字或忽略负号，可能导致多位数或负数解析错误。（譬如`-abc`会被误解读）
        
    - 解决：使用 `while` 循环持续读取连续数字字符，并结合负号处理：
        
        ```java
        StringBuilder sb = new StringBuilder();
        if (c == '-') sb.append(input.consume());
        while (!input.eof() && Character.isDigit(input.lookahead(1))) {
            sb.append(input.consume());
        }
        tokens.add(IntegerToken.create(Integer.parseInt(sb.toString())));
        ```
        
4. **字符串转义符处理错误**
    
    - 问题：写成 `if (ch == '\')` 会报错，因为 `\` 本身需要转义写作 `'\\'`。
        
    - 解决：在读取字符串时遇到 `'\\'`，先把它和下一个字符原样加入 `StringBuilder`，最后再用 `StringEscapeUtils.unescapeJava()` 统一处理：
        
        ```java
        if (ch == '\\') {
            if (!input.eof()) {
                char next = input.consume();
                sb.append('\\').append(next);
            }
        } else {
            sb.append(ch);
        }
        ```
        
5. **字符串结束判断**
    
    - 问题：没检查未转义的 `"` 结尾，可能读取到文件末尾导致错误。
        
    - 解决：循环条件为 `while(!input.eof())`，遇到非转义 `"` 时立即 `break`，保证字符串正确结束。
        
6. **SymbolToken 贪心读取**
    
    - 问题：如果不判断特殊字符，会把空格、括号或引号也包含进去，导致 token 错误。
        
    - 解决：使用 `isSpecialCharacter(c)` 判断，遇到特殊字符立即停止：
        
        ```java
        while (!input.eof() && !isSpecialCharacter(input.lookahead(1))) {
            sb.append(input.consume());
        }
        tokens.add(SymbolToken.create(sb.toString()));
        ```

### 2.1 `instanceof` 基础用法
`instanceof` 是 Java 中判断对象类型的关键字，用于检测某个对象是否是某个类或其子类的实例。语法：

```java
if (obj instanceof SomeClass) {
    // 如果 obj 是 SomeClass 或其子类实例，就进入这里
}
```

特点：

1. **安全类型检查**：在进行强制类型转换（cast）前，用 `instanceof` 可以避免 `ClassCastException`。
    
    ```java
    if (t instanceof IntegerToken) {
        int value = ((IntegerToken) t).value;
    }
    ```
    
    这里先判断 `t` 是否是 `IntegerToken`，再安全地访问 `value`。
    
2. **支持继承关系**：如果某类 `B` 继承自 `A`，`b instanceof A` 返回 `true`。
    
    - 对应到 Token 类型：`IntegerToken`、`StringToken` 等都继承自 `Token`，所以可以先写 `t instanceof Token`，但要精确判断类型时需指定子类。
        
3. **避免写错顺序**：判断多个子类时，必须从**最具体的子类开始判断，再判断父类**，否则子类会被父类提前捕获。
    
    ```java
    if (t instanceof Token) { ... } 
    else if (t instanceof IntegerToken) { ... } // 永远不会到这里
    ```
    
4. **返回布尔值**：`instanceof` 本身返回 `true` 或 `false`，不能用 `==` 比较：
    
    ```java
    if (t instanceof IntegerToken) { ... } // 正确
    if ((t instanceof IntegerToken) == true) { ... } // 可以，但多余
    if (t instanceof IntegerToken == true) { ... } // ❌ 会报错
    ```
## 3. 扩展2札记

### 3.1 使用 `.value` / `.name` 获取 Token 的内容

在扩展2中，我们需要把 `Token` 列表转换回字符串形式。每种具体 Token 类型都有自己的成员变量保存实际内容：

1. **IntegerToken**
    
    ```java
    int value = ((IntegerToken) t).value;
    ```
    
    - `IntegerToken` 中保存了整数值，类型为 `int`。
        
    - 使用强制类型转换 `(IntegerToken) t`，将 `Token` 对象转换为 `IntegerToken`，然后访问 `.value`。
        
    - 例如，`IntegerToken.create(42)` 对应的 `.value` 就是 `42`。
        
2. **StringToken**
    
    ```java
    String str = ((StringToken) t).value;
    ```
    
    - `StringToken` 保存字符串内容。
        
    - `.value` 是 `String` 类型，存储字符串本身，例如 `"hello"`。
        
    - 在生成最终字符串时，需要加上双引号：`"\""+str+"\""`。
        
3. **SymbolToken**
    
    ```java
    String name = ((SymbolToken) t).name;
    ```
    
    - `SymbolToken` 保存符号名，例如 `+`、`-`、`abc`。
        
    - `.name` 是 `String` 类型，直接表示符号名称。
        
    - 用于拼接输出或其他逻辑处理。
        

### 3.2 注意事项

- **强制类型转换前必须用 `instanceof` 判断**：
    
    ```java
    if (t instanceof IntegerToken) {
        int value = ((IntegerToken) t).value;
    }
    ```
    
    避免 `ClassCastException`。
    
- **区分类型**：
    
    - `.value` 用于保存具体的数值或字符串内容（IntegerToken、StringToken）。
        
    - `.name` 仅用于符号类（SymbolToken）。
        
- **拼接输出时处理格式**：
    
    - 数字直接输出。
        
    - 字符串加上双引号。
        
    - 符号、括号直接输出符号字符。
