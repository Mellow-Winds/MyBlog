## 一，数据类型

1. **基本数据类型（Primitive Data Types）**：共有 8 种。它们直接存储数值，在内存中占用固定大小的空间。
	- 数值型：`byte`、`short`、`int`、`long`、`float`、`double`
	- 字符型：`char`
	- 布尔型：`boolean`
2. **引用数据类型（Reference Data Types）**：除了基本数据类型之外的所有类型。它们存储的是对象的引用（即内存地址），而不是对象本身。
	- 包括：类（`Class`，如 `String`、自定义类）、接口（`Interface`）、数组（`Array`）等。

## 二、 `main` 方法
1. `main` 方法一定要用 `psvm`（`public static void main`）修饰吗？
	是的。
	`main`方法需要psvm修饰。为了使一个方法成为标准 Java 应用程序的入口点，JVM 规范要求该方法必须被声明为 `public static void`。如果不使用这些修饰符，程序可以编译，但 JVM 将无法运行该类
	
2. `main` 方法的参数名必须是 `args` 吗？
	不是。
	`args` 只是一个普通的变量名（Identifier），你完全可以写成 `public static void main(String[] arguments)`。

## 三、多态

1. 多态只能用方法重写实现吗？
	不是。
	多态不仅可以通过**方法重写**（Override，实现动态多态/运行时多态）来实现，还可以通过**方法重载**（Overload，实现静态多态/编译时多态）以及**接口实现**（Interface Implementation）来实现。
	
2. 父类引用可以指向子类对象吗？
	可以
	父类引用**可以**且经常指向子类对象，这是面向对象中实现多态的核心前提机制，被称为“向上转型”（Upcasting）。例如：`Animal a = new Dog();` 是绝对合法的。

## 四、静态与实例

1. 静态方法可以调用非静态变量吗？
	不可以。
	静态方法**不可以**直接调用非静态（实例）变量。因为静态方法属于类级别，在类加载时就分配了内存，此时可能还没有创建任何实例对象；而非静态变量是依赖于具体的对象实例存在的。在静态方法中没有隐含的 `this` 引用。
## 五、λ 演算（Lambda 演算）

1. 什么是 α 规约（α-conversion）？
	大意：把$\lambda x$的变量x替换一个字母。
	$\alpha$-conversion 是一种变量重命名规则，用于安全地更改绑定变量（Bound Variable）的名称，以避免名称冲突。例如将 $\lambda x.x$ 等价替换为 $\lambda y.y$。
	
2. 什么是 β 规约（β-reduction）？
	对$\lambda$演算进行化简。
	$\beta$-reduction 描述的是**函数应用**的过程：即将传入的参数代入到函数体中，去替换掉对应的绑定变量。其形式化规则为：$(\lambda x.M)\ N \rightarrow M[x := N]$。
	
3. 请解释 `SUCC ONE` 的含义和结果。
	在邱奇数编码中，数字 $1$ （`ONE`）被定义为函数 $\lambda f.\lambda x.f\ x$。后继函数（`SUCC`）定义为 $\lambda n.\lambda f.\lambda x.f\ (n\ f\ x)$。`SUCC ONE` 的含义是将后继函数作用于数字 $1$。经过 $\beta$ 规约后，得到的结果是邱奇数 `TWO`，其标准表达式为 $\lambda f.\lambda x.f\ (f\ x)$。

## 七、`String` 内存分析

给定以下代码：

```java
String str1 = "abc";
String str2 = new String("abc");
String str3 = "abc" + str1;
String str4 = "abcabc";
```

1. 几个 `str` 分别存在哪里（堆、栈、常量池等）？
	堆。因为`String`对象指向堆。（不够准确）
	- `str1`、`str2`、`str3`、`str4` 这四个作为**变量引用**（局部变量），均存放在线程栈的**局部变量表**中。
	- 字面量 `"abc"` 和 `"abcabc"` 的对象存放在**字符串常量池**中（JDK 8及以后常量池移至堆内存中）。
	- `new String("abc")` 会在**堆**中开辟一块全新内存来存放字符串对象（不属于常量池）。
	- `"abc" + str1` 在编译和运行期会通过 `StringBuilder` 拼接（或 `invokedynamic`），产生的新字符串对象同样存在于**堆**中。
3. 使用 `==` 和 `equals()` 比较时，哪些结果是 `true`，哪些是 `false`？
	 - `==`：都不输出`true`。
	 - `equals()`：`str1`和`str2`、`str3`和`str4`。

## 十二、操作数栈与局部变量表

给定以下代码：

```java
int a = 1;
int b = 2;
int c = a + b;
```

请解释以下字节码指令在操作数栈与局部变量表中的执行过程：

`iconst`、`istore`、`iload`、`iadd`

>- **`iconst_1`**：将常量 1 压入**操作数栈**的栈顶。
>- **`istore_1`**：将操作数栈顶的 1 出栈，并将其存入**局部变量表**索引为 1 的位置（也就是给变量 a 赋值）。
>- **`iconst_2`**（隐藏在此代码逻辑中）：将常量 2 压入操作数栈。
>- **`istore_2`**：将栈顶的 2 出栈，存入局部变量表索引为 2 的位置（给变量 b 赋值）。
>- **`iload_1`**：从局部变量表索引 1 处提取数据（即变量 a 的值 1），压入**操作数栈**。
>- **`iload_2`**：从局部变量表索引 2 处提取数据（即变量 b 的值 2），压入**操作数栈**。
>- **`iadd`**：将操作数栈顶的两个元素（1 和 2）全部出栈并执行加法运算，随后将运算结果（3）重新压回**操作数栈**的栈顶。
