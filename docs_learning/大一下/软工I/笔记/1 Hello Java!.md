# 1. 标准控制台输出 (Standard I/O)
这是最基础、最常用的方式，通过 `System.out` 对象实现。
- **`System.out.println()`**：最常用。输出内容并自动换行。
- **`System.out.print()`**：紧凑输出。输出后不换行，适合拼接字符串。
- **`System.out.printf()`**：源自 C 语言的格式化输出，通过占位符（如 `%d`, `%f`, `%s`）精准控制数字精度、对齐方式。
    - 例子：`System.out.printf("PI ≈ %.2f", Math.PI); // 输出 PI ≈ 3.14`

# 4. Println的拼接字符串（+）用法
Java 处理 `+` 的规律是：**从左往右计算。只要碰到一个字符串，后面的所有内容都会被当成字符串处理。**
### 场景 A：纯数值加法
如果 `+` 两边都是数字，它就是标准的算术加法。
- `System.out.println(5 + 5);`
- **输出：** `10`
### 场景 B：字符串拼接
如果 `+` 只要有一边是 `String`，Java 就会将非字符串转换为字符串再连接。
- `System.out.println("Result: " + 5 + 5);`
- **输出：** `Result: 55`
### 场景 C：括号
如果想在拼接前先算加法，必须用小括号强行提升优先级。
- `System.out.println("Result: " + (5 + 5));`
- **输出：** `Result: 10`

# 5. 关于长度
## 1. 数组的 `.length` (属性)
对于数组来说，`length` 是一个**不可变的 final 属性**。
- **语法**：`int size = array.length;` （注意：**没有括号**）
- **底层逻辑**：当你 `new` 一个数组时，JVM 会在内存中分配一块连续空间，并把这个空间的容量信息直接记录在数组对象的“头信息”里。
- **特性**：它是只读的。你不能通过 `array.length = 10` 来扩容，那是违背 Java 内存管理的。
## 2. 字符串的 `.length()` (方法)
对于 `String` 对象，获取长度必须调用**方法**。
- **语法**：`int len = str.length();` （注意：**带括号**）
- **底层逻辑**：`String` 的底层是一个 `byte[]`（或 `char[]`）。当你调用 `.length()` 方法时，它实际上是返回了内部存储数组的长度。
- **为什么带括号？** 因为 `String` 是一个类，它封装了数据。出于开闭原则，它通过方法提供数据，而不是直接暴露内部属性。
## 3. 集合的 `.size()` (方法)
- **语法**：`list.size();`
- **战略复盘**：集合的长度是**动态**的。`size()` 并不代表内存分配的大小，而是代表当前容器里“装了多少个元素”。
 
|**对象类型**|**获取方式**|**本质**|**记忆点**|
|---|---|---|---|
|**Array (数组)**|`x.length`|**属性 (Field)**|它是固定容器，尺寸是天生的。|
|**String (字符串)**|`x.length()`|**方法 (Method)**|它是对象，需要打个招呼（调用）才告诉你长度。|
|**List/Set (集合)**|`x.size()`|**方法 (Method)**|它是动态的，随时在变。|
