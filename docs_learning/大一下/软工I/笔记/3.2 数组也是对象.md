# 1.数组对象的创建
首先明确：数组也是对象。我们可以创建一个类的数组变量。例如：
```java
class students{  
    int height;  
    String name;  
}  
class StudentsTest{  
    public static void main(String[] args){  
        students[] Stus = new students[7];  
    }  
}
```
我们实际上做的是：
1.声明`students[] Stus`这样的一个数组变量。（可以和C语言的`int a[n]`区分一下）
2.创建了大小为7的数组 `Stus = new students[7]` 
# 2. 数组对象的赋值

**创建好后，我们是否可以写`Stus[1].name = "MellowWinds";`去赋值了呢？**
答案是：不行！会输出的是以下结果。
```java
Exception in thread "main" java.lang.NullPointerException: Cannot assign field "name" because "Stus[1]" is null at StudentsTest.main(Main.java:8)
```

为什么呢？因为数组创建后默认指向的是`null`。我们需要对每一个数组的元素分配对象！
```java
for (int i = 0; i < Stus.length; i++) {
    Stus[i] = new students(); // 给每个元素分配对象
}
Stus[1].name = "MellowWinds";
```

也可以写：
```java
int x = 0;
while(x < Stus.length){
	Stus[i] = new students();
	x += 1;
}
```
## FYP：隐含展开（Implicit Widening）
不同类型的数组一般来说是不能合并的。一般来说可以合并的行为被称为**隐含展开（Implicit Widening）**，在之前学习primitive variable的时候有过接触。可以参考[[3.1 变量（Variables）#2.1 隐含展开（Implicit Widening）|此处]]进行理解。
