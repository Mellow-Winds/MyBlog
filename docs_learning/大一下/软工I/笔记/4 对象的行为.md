可以把类所描述的分为两种：实例变量（instance variables）和方法（methods）。

```java
public class NumberChecker {
	int number; //实例变量
	public static int sumProperDivisors(int n) {  
	    int sum = 0;  
	    for (int d = 1; d < n; d++) {  
	        if (isDivisor(n,d)) {

	        }  
	    }
```

# 1. 状态（实例变量）
状态是对于类的描述。譬如上面的number就是一个状态。
可以在方法里直接调用状态的数据。

# 2. 方法
## 2.1 方法可以传入参数
方法可以定义需要传入的参数，这个时候叫做形参。当调用方法时，我们进行了值传递，此时就有了实参。
我们以上一题为例。
```java
	public static int sumProperDivisors(int n) {  
	    int sum = 0;  
	    for (int d = 1; d < n; d++) {  
	        if (isDivisor(n,d)) {  
	            sum += d;  
	        }  
	    }  
	    return sum;  
	}//方法：求所有除自己本身外的因数之和
```
这里的`(int n)`就是形参。
## 2.2 Java是值传递(Pass-by-value)，通过拷贝传递
> 方法里可以修改“引用指向的对象内容”，也可以修改“形参引用本身”，但这个修改不会影响外部的引用变量，因为传进去的是副本。

## 2.3 方法可以返回值
```
[修饰符] 返回类型 方法名(参数) {
    方法体
}
```
这是一个方法的基本模型。这里就有返回类型，是指方法可以返回的类型。如果方法不返回，就可以写`void`，如果返回值，那么写的就是返回值的类型。

**一个方法只能声明单一的返回值。** 如果有多个返回值，可以考虑使用数组或ArrayList。

# 3. 封装
为了避免错误的修改和数据泄露等问题，考虑使用封装将对象进行修缮。

> 封装的基本原则是：将实例变量标记为`private`，并提供`public`的`getter`和`setter`进行读取和修改。

先看一个未封装的`class`
```java
class NJUStudent {
    // 属性公开
    String name;
    int age;
    String major;

    // 方法
    void study(String subject) {
        System.out.println(name + "正在学习" + subject);
    }

    void introduce() {
        System.out.println("我叫" + name + "，今年" + age + "岁，专业是" + major);
    }
}

// 测试
public class TestStudent {
    public static void main(String[] args) {
        NJUStudent stu = new NJUStudent();
        // 直接操作属性
        stu.name = "MellowWinds";
        stu.age = 20;
        stu.major = "软件工程";

        // 调用方法
        stu.study("Java");
        stu.introduce();

        // ❌ 未封装时：可以随意改年龄
        stu.age = -5;
        System.out.println("年龄被改成：" + stu.age);
    }
}
```

我们现在可以进行封装操作。
```java
class NJUStudent {
    // 1️⃣ 属性私有化
    private String name;
    private int age;
    private String major;

    // 2️⃣ 提供访问方法（getter/setter）
    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name; // 可以加校验，例如非空
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        if (age >= 0 && age <= 150) { // 校验合法性
            this.age = age;
        } else {
            System.out.println("非法年龄：" + age);
        }
    }

    public String getMajor() {
        return major;
    }

    public void setMajor(String major) {
        this.major = major;
    }

    // 方法保持不变
    void study(String subject) {
        System.out.println(name + "正在学习" + subject);
    }

    void introduce() {
        System.out.println("我叫" + name + "，今年" + age + "岁，专业是" + major);
    }
}

// 测试
public class TestStudent {
    public static void main(String[] args) {
        NJUStudent stu = new NJUStudent();

        // 使用 setter 安全修改
        stu.setName("张三");
        stu.setAge(20);
        stu.setMajor("软件工程");

        stu.study("Java");
        stu.introduce();

        // ❌ 尝试非法操作
        stu.setAge(-5); // 被拦截，保证数据安全
        System.out.println("年龄还是：" + stu.getAge());
    }
}
```

一般`setter`的写法是：
```java
public void setXxx(类型 参数) {
    this.xxx = 参数;
}
```

一般的`getter`写法是：
```java
public 类型 getXxx() {
    return this.xxx;
}
```
