# 1. 继承
## 1.1 创建子类
我们以一个代码块为例，指出如何创建父类的子类
```java
// 父类：基础方块  
class Block {  
    public void breakBlock() {  
        System.out.println("方块碎裂了！");  
    }  
}  
  
// 子类：钻石方块。
class DiamondBlock extends Block {  
    public void dropItem() {  
        System.out.println("掉落了一颗闪闪发光的钻石！");  
    }  
}  
  
public class Main {  
    public static void main(String[] args) {  
        // 实例化一个子类对象  
        DiamondBlock myBlock = new DiamondBlock();  
        // myBlock 调用从父类继承来的破坏方法  
        myBlock.breakBlock();  
        // 调用子类自己的方法  
        myBlock.dropItem();  
    }  
}
```
创建子类的时候是这样的：`class DiamondBlock extends Block`，其中`extends Block`说明了子类的继承对象。

## 1.2 注意
1. 父类和子类的方法（包括覆写），传入的参数必须都要一样。否则就是方法的重载。**永远在覆写的方法上添加 `@Override` 注解。**
2. 父类和子类的方法（如果覆写）应该有权限限制。子类权限不可高于父类。
	- 如果父类是 `protected`，子类可以是 `protected` 或 `public`。
	- 如果父类是 `public`，子类**必须**是 `public`。
3. 形如`Block diamond_block = new DiamondBlock();`这样`父类 变量名 = new 子类();`的方法是合理的（也即多态），但是注意此时会有以下限制：

| **动作**         | **结果**        | **原因**                |
| -------------- | ------------- | --------------------- |
| **调用父类独有方法**   | ✅ 正常运行        | 引用类型支持                |
| **调用子类独有方法**   | ❌ 编译报错        | 引用类型不支持（除非强制转型）       |
| **调用被子类重写的方法** | ⚡ **执行子类逻辑**  | 动态绑定（Dynamic Binding） |
| **访问成员变量**     | 🏠 **访问父类变量** | Java 中变量不具备多态性，只看引用类型 |
所以此时如果要访问子类自己的变量，我们可以执行以下操作（这里用方块id来举例）：既然**方法支持多态**，那我们就把对属性的访问封装进方法里。
```java
class Block {
    int id = 0;
    public int getId() { return id; }
}

class DiamondBlock extends Block {
    int id = 57; // 钻石的 ID
    @Override
    public int getId() { return id; } // 重写父类的方法
}

// 调用时：
Block b = new DiamondBlock();
System.out.println(b.getId()); // 结果是 57！
```
# 2. 多态

其实在上面的1.2.3我们已经讲到多态。有**继承**关系、有**方法重写**（Override）、父类引用指向子类对象，就可以被认为是多态。多态上方已经介绍，下面讲解`super`的继承。

# 3. `super` 关键字
`super` 代表父类空间的引用，主要解决“子类覆盖父类后如何回头”的问题。
1. **`super()` 构造调用**：
    - **必须放在子类构造函数第一行**。
    - 用于初始化父类定义的属性。
    - **匹配规则**：根据 `super(args)` 传入参数的**数量、类型、顺序**自动匹配父类对应的构造器。
2. **`super.方法名()` 逻辑复用**：
    - 在重写方法时，先用 `super.method()` 执行父类的通用物理规则，再写子类的特有奖励逻辑。极大地降低了代码重复率。

我们以一道MC的模拟题为例：
```java
import java.util.Scanner;  
  
class Tool {  
    private String name;  
    private int level;  
    private int durability;  
  
    public Tool(String name, int level, int durability) {  
        this.name = name;  
        this.level = level;  
        this.durability = durability;  
    }  
  
    public void consumeDurability(int cost) {  
        this.durability = durability - cost;  
    }  
  
    public int getDurability() {  
        return this.durability;  
    }  
  
    public int getLevel() {  
        return this.level;  
    }  
  
    public String getName() {  
        return this.name;  
    }  
}  
  
class Block {  
    private int requiredLevel;  
    private int baseExp;  
  
    public int getBaseExp() {  
        return this.baseExp;  
    }  
  
    public Block(int requiredLevel, int baseExp) {  
        this.requiredLevel = requiredLevel;  
        this.baseExp = baseExp;  
    }  
  
    public int harvest(Tool t) {  
        System.out.println("【物理引擎】开始挖掘...");  
        if (t.getLevel() >= requiredLevel) {  
            t.consumeDurability(1);  
            return baseExp;  
        } else {  
            t.consumeDurability(2);  
            return 0;  
        }  
    }  
}  
  
class AncientDebris extends Block {  
    public AncientDebris() {  
        super(4, 500);  
    }  
	@Override // 建议加上
public int harvest(Tool t) {
    int exp = super.harvest(t);
    if (exp > 0) {
        if (t.getName().equals("合金镐")) {
            exp *= 2; 
        }
        System.out.println("【远古残骸】掉落了下界合金碎片！获得经验：" + exp);
        return exp;
    } else {
        System.out.println("【远古残骸】火花四溅，方块完好无损。");
        return 0;
    }
}
}   
public class Main {  
    public static void main(String[] args) {  
        Scanner scanner = new Scanner(System.in);  
  
        // 读取玩家手里的工具信息 (名字 等级 耐久度)  
        String toolName = scanner.next();  
        int toolLevel = scanner.nextInt();  
        int toolDurability = scanner.nextInt();  
  
        // 1. 实例化参数对象  
        Tool myTool = new Tool(toolName, toolLevel, toolDurability);  
  
        // 2. 向上转型实例化远古残骸  
        Block targetBlock = new AncientDebris();  
  
        // 3. 多态调用，不仅传入了对象，还接收了重写方法处理后的返回值  
        int finalExp = targetBlock.harvest(myTool);  
  
        // 4. 验证程序的严密性：查看返回值和内存中对象状态的改变  
        System.out.println("最终结算经验：" + finalExp);  
        System.out.println("工具剩余耐久：" + myTool.getDurability());  
  
        scanner.close();  
    }  
}
```

这里的`下界合金块AncientDebris`继承父类`Block`的方法如代码所示。这样就可以继承父类的Block设定。
```java
public AncientDebris() {  
        super(4, 500);  
    } 
```
在挖掘的部分，我们进行了如下操作：
```java
public int harvest(Tool t) {  
    int exp = super.harvest(t);
}
```
这实际上就使用`super`调用了父类的那个方法，使得可以得到经验值了。
