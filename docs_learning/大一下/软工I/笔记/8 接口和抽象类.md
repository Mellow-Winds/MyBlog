# 抽象类
那么抽象类又是啥？抽象类是一种无法初始化的类。这样的类就不能创建任何类型的实例。设计抽象类，只需要在前面加上`abstract`即可。

下面用一个代码块介绍
```java
// 抽象类：规定了“方块”的模板
abstract class Block {
    String name;

    // 普通方法：所有方块碎裂时都冒烟（共性逻辑）
    public void emitParticles() {
        System.out.println(name + " 冒出了一些灰色颗粒...");
    }

    // 抽象方法：没有方法体！强制子类必须实现具体的掉落逻辑
    public abstract void dropLoot();
}

// 子类：必须实现父类的抽象方法，否则自己也得是抽象类
class GrassBlock extends Block {
    public GrassBlock() { this.name = "草方块"; }

    @Override
    public void dropLoot() {
        System.out.println("掉落了 1 个泥土块。");
    }
}

public class Main {
    public static void main(String[] args) {
        Block b = new Block(); // ❌ 报错！抽象类不能直接 new
        
        Block myBlock = new GrassBlock(); // ✅ 多态：父类引用指向子类对象
        myBlock.emitParticles();         // 调用父类的共有逻辑
        myBlock.dropLoot();              // 调用子类实现的特有逻辑
    }
}
```

报错会显示：`'Block' is abstract; cannot be instantiated`
