# 1. 把字符转换为`int`的方法
### **1️⃣ 获取字符的 Unicode / ASCII 值**

```java
char ch = 'A';
int code = (int) ch;   // 强制类型转换
System.out.println(code); // 输出 65
```

或者：

```java
int code = ch; // 自动类型转换
```

> 这种方式得到的是字符在 Unicode 表中的整数值，比如 `'0'` → 48，`'A'` → 65。

### **2️⃣ 将字符数字（'0'~'9'）转换为对应整数**

如果有 `'5'`，想得到整数 `5`，可以用：

```java
char digit = '5';
int number = digit - '0';
System.out.println(number); // 输出 5
```

> 原理：字符 `'5'` 的 ASCII 是 53，`'0'` 是 48，53 - 48 = 5。

或者使用 Java 内置方法：

```java
int number = Character.getNumericValue(digit);
System.out.println(number); // 输出 5
```

> `getNumericValue` 更通用，还可以处理 `'Ⅰ'`、`'二'` 等 Unicode 数字字符。

---

### **3️⃣ 字符串形式转整数**

如果你的字符在 `String` 中，也可以先转成 `String` 再用 `Integer.parseInt`：

```java
char ch = '7';
int number = Integer.parseInt(String.valueOf(ch));
System.out.println(number); // 输出 7
```

> 注意：这个方法只适用于字符确实是数字字符，否则会抛出 `NumberFormatException`。

# 2. 增强循环
Java允许写增强循环。可以通过`for (int x : y)`来写
```java
int[] arr = {1, 2, 3, 4, 5};

for (int x : arr) {
    System.out.println(x);
}
```

# 4. 关于长度
## 1. 数组的 `.length` (属性)
对于数组来说，`length` 是一个**不可变的 final 属性**。
- **语法**：`int size = array.length;` （注意：**没有括号**）
- **底层逻辑**：当你 `new` 一个数组时，JVM 会在内存中分配一块连续空间，并把这个空间的容量信息直接记录在数组对象的“头信息”里。
- **特性**：它是只读的。你不能通过 `array.length = 10` 来扩容，那是违背 Java 内存管理的。
## 2. 字符串的 `.length()` (方法)
对于 `String` 对象，获取长度必须调用**方法**。
- **语法**：`int len = str.length();` （注意：**带括号**）
- **底层逻辑**：`String` 的底层是一个 `byte[]`（或 `char[]`）。当你调用 `.length()` 方法时，它实际上是返回了内部存储数组的长度。
- **为什么带括号？** 因为 `String` 是一个类，它封装了数据。出于开闭原则，它通过方法提供数据，而不是直接暴露内部属性。
## 3. 集合的 `.size()` (方法)
- **语法**：`list.size();`
- **战略复盘**：集合的长度是**动态**的。`size()` 并不代表内存分配的大小，而是代表当前容器里“装了多少个元素”。
 
|**对象类型**|**获取方式**|**本质**|**记忆点**|
|---|---|---|---|
|**Array (数组)**|`x.length`|**属性 (Field)**|它是固定容器，尺寸是天生的。|
|**String (字符串)**|`x.length()`|**方法 (Method)**|它是对象，需要打个招呼（调用）才告诉你长度。|
|**List/Set (集合)**|`x.size()`|**方法 (Method)**|它是动态的，随时在变。|
