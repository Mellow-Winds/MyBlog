## 先看乘车顺序

买票并确认出票 → 带好证件和行李 → 到正确的车站 → 实名核验、安检 → 找检票口候车 → 检票去站台 → 找车厢和座位 → 到站下车 → 出站或换乘。

车票上的开车时间是列车离开你所购乘车站的时间。车站会提前停止检票，不能按开车时间才赶到站门口。具体提前多久，查看该站公告和现场提示。

## 买票：车站、日期、车次和席别

### 1. 使用铁路12306购票

手机使用“铁路12306”官方App，电脑使用12306官网。先注册、登录，按实际乘车人的证件填写姓名、证件类型和号码，完成身份核验；替别人买票时，乘车人应选对方。不会使用手机也可以持有效证件到车站售票窗口办理。不要把账号密码、验证码交给陌生人代操作。

### 2. 选择出发站、到达站和日期

输入城市名后，还要核对具体车站。例如“北京”“北京南”“北京西”是不同车站；到达站也要结合住宿、学校或目的地的位置选择。不要仅因为某一班票价便宜就忽略去车站的路程。日期按你上车那一站的出发日期选择，跨夜列车还要看清到达日期。

### 3. 比较用时和席别

以查询页实际显示的全程用时、价格、出发和到达时刻作比较。高铁、动车常见二等座、一等座；普速列车常见硬座、硬卧、软卧，实际以该车次可售席别为准。短途可先比较座席，长途过夜可比较卧铺。“无座”表示没有为你分配固定座位，购买前要考虑站立时间和体力。

### 4. 看起售时间，完成支付后再确认

通常预售期为15天，各车站起售时刻不同，可以在12306查询“起售时间”并设置提醒；具体可售日期看当前查询页。提交订单后，应在页面倒计时内付款，随后确认订单已购票成功。只提交订单、只扣了候补预付款，都不等于已经拿到可乘车的车票。

### 5. 没票时使用候补

在可候补的车次和席别处提交需求，按提示完成核验、支付预付款，并检查兑现截止时间。可以加入自己能接受的其他车次、席别或日期，但不要勾选无法出行的方案。候补成功后核对实际分配的车票；未兑现的订单按规则取消、退回预付款。候补不保证成功，出发前仍未兑现就不能凭候补订单上车。

### 6. 保存真正需要的信息

购票后记下乘车日期、出发站、车次、开车时间、到达站、车厢号和座位或铺位号。可以截图备查，但截图只是帮助你找路，不能替代身份证明。若改签成功，要重新保存新车票信息，避免拿旧截图找错车。检票口尚未显示时不用着急，到站再看现场屏幕。

## 学生票：先核验，再购买

学生票需要符合学生身份、优惠区间和可用次数等条件，并非选择“学生”就可以用于所有旅行。购票前在12306的“学生优惠资质核验”入口检查信息、核验状态和剩余次数；在校学生每学年乘车前应按规定完成核验，线上无法完成时可咨询车站窗口。

现行常规学生优惠每学年为4次单程，学年按10月1日至次年9月30日计算，可在学年内使用，已不限于寒暑假。动车组优惠席别已扩大至一等座和卧铺等，不能再照旧攻略理解为“只有二等座”；具体适用席别和折后价格看订单。

入学新生按12306的新生办理要求操作，出发时带好身份证和录取通知书。已在线购买新生学生票但未完成线下资质核验的，按官方指引持录取通知书走人工检票通道；遇到核验问题提前找窗口处理，别等到临近开车才解决。

## 出发前：证件、行李和到站时间

### 1. 把证件放在方便拿取的位置

携带购票时使用的有效身份证件原件。居民身份证购票通常可以直接刷证完成实名核验和进出站检票，无需为了乘车专门换纸质票；其他有效证件按可识读情况走自助或人工通道。证件不要压在箱底，也不要只带照片。

### 2. 准备途中用品

带好手机、充电线、饮用水、纸巾及自己需要的日常用品；长途或过夜可增加轻便外套、眼罩等。贵重物品放随身小包，给相似的行李箱加一个明显标记。手机提前充电，出发与到达信息另存一份，避免网络不好时反复翻找订单。

### 3. 核对行李重量和尺寸

普通成年旅客免费随身携带品总重量为20千克，每件也不得超过20千克。普通物品每件长、宽、高之和不超过160厘米；乘坐动车组列车不超过130厘米。杆状物品等另有规定。大箱子不要只凭“多少寸”判断，带轮子和把手量外部尺寸；可能超限时提前咨询铁路，不要默认到了车站一定能办托运。。

### 4. 检查充电宝、喷雾和危险物品

充电宝、锂电池须标志清晰，单块额定能量不超过100Wh，含锂电池的电动轮椅有例外。含易燃成分的非压力容器香水、花露水等，单个容器不超过100毫升、每种限1件；自喷压力容器如发胶等，单个不超过150毫升、每种限1件、合计不超过600毫升。这里看的是容器容积，不是瓶内剩余量。酒精、刀具等需按具体种类查禁限带目录，有疑问出发前问12306。

### 5. 提前到正确的进站口

首次去陌生车站，建议预留开车前约60分钟到站的时间；节假日、超大车站或需要窗口办事时再增加。这是行程安排建议，不是铁路统一规定。导航应选乘车进站口，留意南北广场和不同楼层；抵达附近地铁站、停车场，并不等于已经到达铁路候车厅。

### 6. 看清凌晨车票的日期

例如车票是10月2日00:30开，通常要在10月1日深夜就出发去车站，而不是等到10月2日晚上。提前查清晚间交通和车站开放安排；若是跨日到达，也要按到达的实际日期安排接站或住宿。

## 到车站：进站安检和候车

### 1. 找“进站”或“候车”方向

先核对车站名称，再跟随铁路乘车标识前进。不要跟着出站人流、地铁入口或接站人流走。看不懂时直接出示车票信息询问工作人员：“我坐这趟车，从哪里进站、去哪个检票口？”

### 2. 完成实名核验和安检

拿出购票证件，按设备提示刷证、看摄像头或接受人工核验。将行李放入安检设备，随身小物品按工作人员要求处理；通过后清点手机、小包和箱子。不同车站可能把验证和安检安排在不同位置，按现场顺序走即可。

### 3. 按车次查检票口

进入候车区域后，在大屏上找与你订单一致的车次，再核对开车时间、检票口和状态。屏幕显示的终到站可能比你要去的站更远，所以主要按车次查找，不要只盯目的地名称。手机信息与现场不一致时，向工作人员核实最新安排。

### 4. 在对应区域等候

找到检票口后可以在附近坐下，留意屏幕和广播，先确认卫生间、饮水处的位置。戴耳机、睡觉或去买东西时要特别留意检票时间。不要因为队伍长就跟着排：同一检票口可能先后服务不同车次，只有轮到自己的车才通过闸机。

### 5. 停止检票前完成检票

“开车时间”和“停止检票时间”不同，过闸机后还需要走到站台和车厢。不要按“全国统一提前几分钟”估算最后时限；本站公告、检票屏幕和工作人员提示才是本次出行的依据。发现已停止检票，应立即问工作人员如何处理，不能强行通过。

## 检票后：找站台、车厢和座位

### 1. 刷证通过检票口

确认正在检自己的车次，再按提示刷购票证件。闸机无法识别时退到旁边找人工通道，核对车次、日期、证件和检票状态。不要尾随别人过闸机，也不要默认必须重新买票或换纸质票。

### 2. 顺着指引去站台

通过检票口后看指示牌、屏幕和工作人员引导，确认站台方向。拿重箱子时优先找直梯，使用扶梯注意站稳扶好；不要为了赶时间跨越隔离栏或进入轨道区域。到站台后留在安全线内侧，先确认将要乘坐的列车。

### 3. 先找车厢，再找座位

订单中的“05车08A号”可以理解为第5车厢、第8排A座，不能直接在任意车厢找8A。站台可能有多种颜色的车厢地标，先看屏幕或听工作人员说明本车使用哪一组；最终核对车身、车门附近的车厢号和车次。找不到时把订单给站台工作人员看。

### 4. 等车停稳，先下后上

从工作人员开放的车门上车，注意站台与车门间的缝隙。不要在车门附近停下翻整箱行李，也不要试图用身体或箱子阻挡关门。临近发车却离自己的车厢很远时，先问工作人员如何上车；部分编组之间不能穿行，不要假定上了车就一定能走到。

### 5. 按号码入座或找铺位

常见动车组二等座一排为A、B、C与D、F，A、F在窗侧，C、D在过道侧，B在中间；以车厢实际标识为准。卧铺要同时核对车厢、铺位号码和上中下铺。发现有人坐在自己的位置，先共同核对车次、车厢和号码，仍有争议就请乘务员处理。座位编号

## 乘车途中

行李放在指定行李架或大件行李处，重物放稳，小包和贵重物品自己看管。不要把箱子留在过道、车门口或占用其他人的座位。抬不动时请人协助，不要勉强把重箱举过头顶。随身携带品由旅客自行看管，并应避免影响公共空间使用。

接热水时先看出水标识，杯子不要装太满；厕所、饮水设备、充电插口的位置随车型不同，可看车内标识或询问乘务员。使用小桌板、调节椅背时留意后排乘客，手机声音尽量使用耳机。

留意广播和车内屏幕中的“下一站”。中途停车不代表到目的地，停站时间也可能很短，不建议无事下车。按自己的下车站设置提前提醒，睡卧铺也不要只依赖别人叫醒。

感到明显不适、发现冒烟或其他异常时，立即找乘务员说明车厢和具体情况，并按指引处理。不要随意操作紧急设备。列车上的禁烟等要求按车内标识执行。

## 到站：下车和出站

### 1. 提前收拾，核对站名

建议在预计到站前10至15分钟开始整理随身物品，结合广播确认是否晚点。这是准备建议，不是要求提前堵在车门口。检查行李架、座位缝、充电插口和铺位，带齐证件、手机和箱子。

### 2. 列车停稳后下车

确认确实是自己的到站，再从开放车门下车。下车后离开车门附近，给其他乘客让出通路；不要因为落了东西又冒险冲回正在关门的车内，应立即找工作人员。

### 3. 按“出站”方向通过闸机

跟随出站标识走，不要进入下一班车的检票队伍。准备购票证件完成出站检票，闸机有问题走人工通道处理。手机没电但仍带有购票身份证时，可按刷证流程办理，遇到异常请工作人员核查。

### 4. 再选择地铁、公交或接站点

出站后看公共交通指引。和接站人说清车站全名、出口或广场名称；乘网约车时看清指定上车区和楼层，并核对车牌。不要把铁路出站口与地铁出口编号混在一起。

## 需要换乘另一趟火车

购票时先看清是否同一个车站换乘。“同城换站”还要出站乘车去另一座站，再进站安检；“同站换乘”也需要步行、核验和下一班检票。第一次换乘，建议选择时间宽裕的方案，并额外考虑行李、同行人和晚点风险，不把地图上的最短步行时间当作保证。

同站换乘时，下车后先找“便捷换乘”或“中转换乘”标识，向工作人员确认通道是否开放，准备身份证和下一程车票信息。通过核验返回候车区域后，重新查下一程的检票口；没有可用换乘通道时按站方指引出站再进站。不要默认必须出站，也不要自行沿站台去找下一班车。

若前一程晚点可能影响接续，尽早向乘务员或车站服务台说明两段车次和日期，询问接续安排及退改签办理。不要仅凭一条“晚点消息”自行判断所有关联车票都能免费退，具体处理以铁路核实为准。

## 退票、改签和没赶上车

### 1. 行程变了，尽早打开原订单

在12306找到对应订单，选择退票或改签，先看可办理范围、费用和新车次，确认后再提交。改签成功要重新核对日期、车站、车次、车厢及座位。已经确定不走，就尽早办理，不要拖到开车后才尝试普通退票。

### 2. 普通自愿退票的费用

一般未改签的普通车票，距开车8天及以上退票免退票费；不足8天但至少48小时通常收票价5%，至少24小时但不足48小时收10%，不足24小时收20%。收费还涉及尾数处理、最低收费，以及改签后退票等例外，最终金额看办理页面。列车停运等非旅客原因按相应安排办理。

### 3. 刚买错，检查误购免费退票条件

2026年新增了限时服务：通过12306以电子支付或积分支付购买适用车票，支付成功后30分钟内且距离开车4小时以上，符合条件时可线上免费退票。同一购票人每个自然日限1个订单，改签、预约或候补购票等不适用；该政策针对乘车日期为2026年2月2日及以后的适用车票。发现错误就立即查看订单，别等过了时间再处理。

### 4. 已停止检票或错过开车

先向工作人员确认是否还能按正常流程乘车；不能乘车时立即查询改签。列车开出后通常不能按普通自愿退票处理，但不代表车票必然只能作废：符合条件时仍可改签。官方规则允许开车后在当日24时前改签至票面乘车日期之后、预售期内的列车，并收取相应改签费。能否改、改到哪一班及金额，以原订单和余票情况为准。

## 常见问题：证件、坐错车和遗失物品

没带身份证：使用中国居民身份证购票的旅客，可在铁路12306App申请电子临时乘车身份证明，按页面要求操作；也可到车站铁路公安制证口咨询办理临时乘车身份证明。证件照片不能直接当作临时证明使用。申请不成功时找工作人员，并预留办理时间。

走错车站：立即确认去正确车站还要多久，并查看原订单的退改签选项。不要认为同一个城市的所有站都可以刷同一张车票上车，也不要只看车次会经过某站就自行改变上车站。

上错车、下错站或坐过站：一发现就向乘务员或车站工作人员说明原票到站和实际位置，请他们按误乘、误降规则处理，尽量在出站前提出；官方规则对出站后才提出的情况不予按该误乘、误降处理受理。不要擅自搭另一班车返回。

想坐到更远的站：应在原票到站前向乘务员提出，能否补票继续乘坐取决于运输能力。不能把“买短乘长、上车一定能补票”当作购票方案；没有获准时，应按原票到站下车。

东西落在车上或车站：尽快找现场工作人员，或通过12306的遗失物品服务、12306客服电话登记。提供乘车日期、车次、车厢座位、遗失位置、物品外观和联系方式，描述越准确越方便查找。列车已离站时不要闯回站台追车。
