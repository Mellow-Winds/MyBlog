# 2. 第二步：发给AI【附件】+【提示词】
提示词如下：
```
我为你发送了题目的附件和参考资料附件。请你根据附件内容及常识，回答下列所有问题。作答要求如下：
一、逐题作答
我发送了「题目附件」和「参考资料附件」。请仅依据附件内容及下述允许使用的常识范围，回答题目附件中的全部问题。

【总原则】
1. 必须先完整读取题目附件和参考资料附件。
2. 作答前，在内部完整扫描题目附件，建立原卷全部题号的有序序列；作答完成后逐题核对该序列，确保无跳题、漏题、重复题。此内部检查过程不得输出。
3. 必须区分「题目附件」与「参考资料附件」：
   - 只有题目附件中的题目需要作答；
   - 参考资料附件仅用于寻找答案依据；
   - 不得把参考资料中的习题、题号、答案或例题误认为当前试卷内容并追加作答。
4. 附件按其在当前对话中的出现顺序编号为「附件 1」「附件 2」……；内部保持编号与文件的一一对应关系，不得中途改变。
5. 除规定格式外，不输出解释、分析过程、客套话、总结或其他内容。

一、逐题作答

- 严格按照原卷题目出现顺序输出；
- 每道题独占一个段落，题与题之间空一行；
- 题号必须逐字沿用原卷编号，如「3.」「（2）」「二、」，不得重新编号、转换编号格式或自行合并、拆分；
- 原卷存在题号但题干缺失或无法识别时，仍必须保留该题位置，并写：
  「第 X 题：题干缺失，无法作答」
- 不得因为无法作答而跳过任何已识别题号。

二、每题固定输出格式

每道题严格按照以下顺序输出：

第一行（仅在触发提示条件时输出）：
【提示】本题【超出知识库范围／参考信息不足／需经演绎推理或延伸假设作答／选项不完全／题干不完备／内容识别不清】，答案可能存在幻觉，建议二次核查；

如同时满足多个条件，在同一对【】中并列填写。

第二行：
【原卷题号（题型）】题干前四个字 + 选项摘要

例如：
【1.（单选）】下列说法 A. 一切 B. 个人
【（2）（填空）】马克思主
【二、（判断）】社会主义

规则：
- 原卷题号必须保持原样；
- 题型按「单选」「多选」「判断」「填空」「简答」等实际类型填写；
- 题干摘要取题干正文开始后的前四个可识别文字字符；
- 标点、括号、空格、下划线不计入四字；
- 不足四字则全部保留；
- 有选项时，依原顺序列出「选项字母 + 选项前两个可识别文字字符」；
- 若两个或多个选项前两个字完全相同，则逐字向后扩展，直到能够相互区分；
- 无选项则不输出选项摘要；
- 选项缺失时，只列实际识别出的选项，并在该行末尾注明「（选项缺失）」。

第三行：
答案：……；

答案格式：
- 单选题：仅填写选项字母；
- 多选题：填写全部正确选项字母，严格按原卷选项顺序排列；
- 判断题：填写「正确」或「错误」；
- 填空题：直接填写答案；
- 简答题：直接填写答案内容；
- 无法可靠确定：填写「无法确定」；
- 图片或扫描内容无法可靠识别并影响答案时，在答案后注明「（内容识别不清）」。

第四行（必须输出可靠来源）：
（来源：附件 1）
或：
（来源：附件 1；附件 3）
或：
（常识判断）

三、答案依据优先级

严格按照以下优先级确定答案：

1. 第一优先级：附件中能够直接支持答案的内容；
2. 第二优先级：允许范围内的常识；
3. 附件内容与常识冲突时，无条件以附件内容为准；
4. 附件与允许范围内的常识均无法可靠确定答案时，填写「无法确定」，不得猜测或编造。

「常识」仅限：
- 需权威外部检索才可确定
- 长期稳定
- 广泛公认
- 不依赖具体时间、版本、地区或特殊语境的基础事实

涉及下列内容时，不得仅凭模糊记忆作为「常识判断」，必要时开启联网搜索：
- 具体年份、日期、统计数字；
- 政策法规及具体条文；
- 特定人物的原话、著作表述；
- 具体历史事件细节；
- 专业领域中的精确数据、定义或特殊结论；
- 可能随时间、版本、地区发生变化的信息。

附件未覆盖且上述信息无法可靠确定时，一律填写「无法确定」。

四、提示触发条件

出现以下任一情况时，必须在该题第一行输出【提示】：

- 超出已有可靠知识范围；
- 附件提供的信息不足以支持确定答案；
- 必须经过演绎推理才能从附件内容得到答案；
- 必须引入附件未给出的假设才能作答；
- 题干不完整；
- 选项不完整；
- 图片、扫描件或文字内容识别不清；
- 存在未知、歧义或无法可靠确定的信息。

不得将推断结果伪装为附件中的直接结论。

五、来源要求

- 每道能够确定答案的题目都必须具有可追溯来源；
- 使用附件内容时，题尾必须注明对应附件编号；
- 同一题使用多个附件时全部列出；
- 完全依靠允许范围内常识作答时注明「（常识判断）」；
- 同时使用附件和常识时写：
  「（来源：附件 X；常识判断）」
- 无可靠来源支持的结论不得输出为确定答案；
- 严禁引用、参考或采信个人社交媒体、论坛账号、自媒体等缺乏机构背书的信息。

六、语言与识别要求

- 答案与原题使用同一种语言；
- 不擅自翻译题目；
- 对图片或扫描件不得根据模糊字形猜测关键文字；
- 若关键文字无法可靠识别，必须触发【内容识别不清】提示；
- 若识别问题导致答案无法确定，则答案填写「无法确定（内容识别不清）」。

七、最终自检

输出前必须在内部执行以下检查，但不得输出检查过程：

1. 将最终答案中的题号与作答前建立的原卷题号序列逐一比对；
2. 确认没有跳题、漏题、重复题或自行新增题目；
3. 确认所有题号保持原卷格式；
4. 确认每道题都有「答案：」行；
5. 确认所有需要【提示】的题目均已提示；
6. 确认所有确定性答案均具有附件来源或「常识判断」标记；
7. 确认没有把参考资料中的题目误作为原卷题目；
8. 确认没有使用无法追溯的信息补全答案。

完成自检后，只输出最终逐题答案。
```
# 3.	完成作答

【特别注意】
本方法仅用于辅助整理和作答，不保证答案、题目识别、选项识别、附件引用或格式输出绝对正确。即使已提供完整题目与参考资料，AI仍可能出现误读题干、OCR识别错误、漏题或重复作答、选错选项、错误理解参考资料、引用附件错误、将推断误认为原文结论，以及未完全遵守提示词等情况。
**使用者应至少人工核对：题目是否全部覆盖、题号与题干是否对应、选择题字母是否对应正确选项、否定词是否被正确识别、附件来源是否确实支持答案，以及存在【提示】的题目是否需要进一步查证。**
对于准确性要求较高的场景，应以原始资料、教材、课程要求或其他权威来源进行最终复核，不应将AI输出直接视为标准答案。AI输出是基于所提供材料与模型能力生成的辅助结果，可能犯错。
